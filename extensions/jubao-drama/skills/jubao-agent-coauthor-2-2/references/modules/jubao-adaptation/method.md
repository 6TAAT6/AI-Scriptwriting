# 平替方向与机制重创

> 本篇是同一主Agent的内部方法，使用 [宿主流程](references/host-workflow.md) 与 [资料映射](references/host-records.md)。方法和历史案例不另起执行者、审稿轮次或用户长期要求；当前明确用户要求优先，全部包内路径相对于技能根目录。

读取原作完整分析、核心期待、人物动力/权力关系、逐集保留资产及用户偏好。没有 G1 记录但用户明确独立要求探索时，可以给标注假设的方向草案；不能把草案当已确认新设定。

1. 按 [机制设计与候选方法](references/modules/jubao-adaptation/mechanisms.md) 同时考虑人物、世界和事件，默认保留人物性别、核心动力及权力关系，避免先换名字再套原事件。
2. 默认提出 **三个** 有实质差异的方向。用户可全部重新生成、选择后修改、混合兼容要素，或完全自供。用户已明确提供选定方向时尊重其决定，不为凑三个而替换或重问；用户明确要求其他数量时按其要求。
3. 每个方向呈现新处境与简要梗概、年代/世界及核心规则、主线、核心期待兑现机制、人物功能骨架、关键冲突的新行动路径与代价。区分目标市场、输出语言、故事地域和幻想规则；当前默认中文输出，不因面向海外强制英语。
4. 展示原新故事层短卡、代表人物和事件对照，让用户能判断选择；此时的新人物是明确标注的功能骨架，不伪称已经完成完整新小传。
5. 做去标签比较、动机/制度因果核验和方向互相比对。保留每集戏剧目的、情绪曲线和关键卡点功能；确需改变既定保留资产时先明确取舍，不用新方案暗中绕过。
6. 交付候选与区别，等待用户选定或修改。对合并后的方案复查兼容性，总控记录 G2 及其有效方向版本。**方向确定后才进入三个全剧简纲候选；不把三方向各扩三套大纲。**

交付：三个方向阅读版、代表性原新对照、人物功能与世界机制、选定后可继承的方向基线。未选方案保持候选身份，不能混入后续事实；原作事实不被新设计覆盖。本 skill 可在设计阶段重创因果，正文阶段则须服从已经确认的新因果。
