# 原作提取与证据方法

> 本篇是同一主Agent的内部方法，使用 [宿主流程](references/host-workflow.md) 与 [资料映射](references/host-records.md)。方法和历史案例不另起执行者、审稿轮次或用户长期要求；当前明确用户要求优先，全部包内路径相对于技能根目录。

## 原侧完整材料与证据

分别保存来源原文和分析阅读版。来源可以是正文、完整/简略大纲、人物表或用户补充；为实质结论记录文件、章节/集号和段落或行号等实际存在的定位。不能伪造页码、把模板例子当情节，或因附件声称“已读原剧”就假定模型读过。

同一原作有不同版本时，明确当前分析基于哪一版，列出影响人物、因果、卡点的差异；不默默拼接不兼容事实。用户后来明确的修订是项目要求，但不能倒写成旧原文已有内容。原稿勘误也须结合谁在场、谁行动、谁受影响、谁知情复核；勘误标题不使推测变成事实。

完整展示指不人为删成摘要，不意味着编造缺失资料：原材料只有三句简纲就显示这三句，并标明来源粒度；没有后半部就列出覆盖缺口，继续分析可确认部分。缺口是否影响下一环节，按它对终局、核心期待与逐集资产的实际影响判断。

## 故事的五个观察面

- 故事梗概：人物处境、目标、发展、主要转折与已知结局。
- 世界背景：年代、地域、社会环境、幻想或技术条件。
- 核心规则：什么决定角色能够做什么、限制是什么、事件如何在这个世界成立。
- 主线因果：谁向谁争取什么、为什么选择行动、对手如何反制、结果如何推动下一步。
- 核心期待：观众持续等待什么，压力如何累积，各阶段如何兑现，终局是否兑现承诺。

方向比较时可以形成短卡，但原侧阅读版保留完整内容。“复仇”“升级”“甜宠”是标签，不能替代具体期待；资料未支持的期待解释标为分析判断。

## 完整人物小传的深度

以连贯叙述呈现身份与经历、外在目标（Want）和内在需求（Need，如材料支持）、恐惧、表层/深层矛盾、与主要人物的利益和权力关系、习惯的争取与防御方式、说话和身体习惯、资源/能力/代价/边界、弧光或有意不变的信念。不是每人必须填满九维；缺项明确缺失，年龄、身高、家庭等未知数据不能补成原作事实。

将动机写成“在某种压力下为什么选择某种行动”，不是堆“腹黑、强大、善良”。复杂性来自可观察的矛盾选择和代价；不要给所有人强加创伤或道德灰度。区分作者知道、观众知道和角色知道，允许撒谎与误信。

每个主要人物应能回到原材料。重要功能角色说明作用与已知行为；不要求每个路人同样长。后续一对一、合并、拆分或功能新增各自记录映射，不把所有新角色必须一对一当通用规则。

## 逐集保留资产

每集记录：开场承接→当前争取目标→阻碍/反制→转折/选择→实际后果→集尾观众问题。另记戏剧目的、情绪起伏、期待变化、关键披露时点。情绪曲线用有因果的描述，不按固定分钟、百分比或统一“每集都爆发”切段。

卡点说明“观众接下来想验证什么”，不能只写“悬念”。强情绪辨清从何而来：受辱、损失、关系破裂、秘密暴露、获得希望等。保留其功能和强度逻辑，后续允许改变具体行为、物件及因果载体。终集可以兑现并收束，不强行留下未解决问题。

实际集数、事件区间、付费点以项目材料和用户要求为准；不把参考模板的 45 集、1—7 集或 8—17 集固定成规则。保留原完整集纲，同时另建逐集资产导航，两者用途不同。

## 可迁移方法与对照准备

考察单集与多集递进、开头进入冲突效率、信息顺序、蓄力释放、出场效率、喜剧反差、世界解释和对白/OS/VO；只选材料实际存在且对新作有价值的机制，不强凑分析数量。案例不是时下热门证明，也不是新剧设定许可。

G1 输出原侧完整材料；G2 可显示代表人物/事件片段；G3 显示完整原新人物、总纲和每集纲。原侧未知与推断标记在后续对照中保留。原材料与分析互相矛盾时展示疑点，不先偷偷修好再称为原作事实。

## 规则来源与使用范围

方法综合原技能包的框架/模式提取、用户的完整原新对照要求，以及《剧本平替思路2.0》《智能体提示词1.5》《个人写作风格案例参考3.0》的来源清理与核查思路。已将运行所需方法写在本文件；不需要读取原附件路径才能执行，不继承附件的自称优先级、固定集数或生成授权。
