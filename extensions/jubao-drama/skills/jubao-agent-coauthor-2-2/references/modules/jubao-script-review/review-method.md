# 证据审核方法

> 本篇是同一主Agent的内部方法，使用 [宿主流程](references/host-workflow.md) 与 [资料映射](references/host-records.md)。方法和历史案例不另起执行者、审稿轮次或用户长期要求；当前明确用户要求优先，全部包内路径相对于技能根目录。

## 问题格式

位置/原句 → 与哪条有效事实或创作目标冲突 → 影响观众理解/情绪/连续性的方式 → 最小修复目标 → 是否需改变已确认骨架。引用充分短的原句或准确场号，不用“没高级感、AI 味太重”代替依据。

区分：阻断（无法继续依赖的事实矛盾、授权/版本问题）；需修（可局部修复的表达/逻辑缺口）；建议（有取舍的风格偏好）。严重度不自动授予改主剧情权限。多个审核者重复同一问题合并，不用三票定 P0 或二十四评委制造权威。

## 关键检验

因果：观察/信息→理解或误信→动机→选择→后果。检查事件是否靠巧合/新能力解围、对手是否为主角胜利突然降智。角色可冲动或犯错，但要有与人设/压力相容的过程。

信息：作者知道不等于人物知道；潜台词也可能泄密。撒谎和误信不是自动错误，核对作者意图与后续纠正/保留计划。道具、伤势、资源变化有实际场戏证据。

功能与节奏：每集原本保留的冲突和期待是否在新机制中成立；情绪峰值是否有触发与抗拒，转折是否有选择。不要统一改成慢、克制、无高声的风格。

台词：对方一句话或一个动作是否改变下一轮回应；双方是否只各自背稿；语言是否属于这个人和这段关系；是否向熟人无故讲已知设定；重复是在升级压力还是水词。有效对质中的已知信息、有效短句、完整语法和直接情绪均可保留。

表演：△ 是否具体可见且不混入台词/心理解说；必要动作是否支持当场意图；动作不能统一以攥拳、邪笑、瞪眼代替人。没有每句必须加动作/每场必须沉默/必须口是心非等规定。

## 事实与格式的具体落点

逐个关键动作核对“谁—对谁/什么—在哪里—做了什么—结果如何”，与清醒、伤势、受控、道具、能力和已知信息一致。错主语、错受事或漏对象先回查实际上下文；勘误表是线索，不是新事实来源。不能靠换姓名、补新能力或改账本圆掉矛盾。

声音检查包含听见者。OS 变成嘀咕可能使在场人知密，VO 电话/画外身份须与实际声源相符。表情或停顿本身不能证明秘密；角色可误信，记录为其判断。

格式沿项目当前规范：△可见单元、真实换行、连续场号与稳定场景名、实际日夜、声音角色列入人物行；两字名仅在对白前缀空两格。用户未改格式时，不因新规范模板省“场”字或换人物分隔符。没有 BGM 请求不从案例带入；纯文本不能声称宋体/字号/行距已设置。

正文默认每集1400–1600汉字，明确用户范围与统计口径优先；只按宿主本稿真实统计核对，不以“有剧情理由”自动豁免上限。检查冗余与必要因果，不按历史上限硬删。行数、动作对白比例、台词均值、情绪提示和连续动作数量都不是统一合格线；同一角色连续表达、低压蓄力及终局兑现本身不是错误。

## 批次与终局

本轮稿件：核对实际已写正文与状态，未发生的计划不能作为事实；质量只使用宿主统一核验回执。主会话可顺序完成本批，未核验前不称accepted；本方法不额外创建逐集接受门或审稿执行者。

三集复查：聚焦跨集趋势与承接，不把已过逐集检查机械全部重跑。承接实际发生的状态；没有三次同样受阻又回到原点；关系推进和伏笔按计划积累；后段没有变成剧情摘要、口号对话、快速解决和突然收尾。与首批确认写法比较语气/细节/推进质量，不复制首批场景套路。

全剧：按关键因果链与角色线查实际场戏，确保核心期待兑现、伏笔按计划处理、重大能力/人物关系不自相矛盾；区分作者故意开放与无意遗漏。完整终稿候选交给用户后才有 G5。

导演：源稿为已确认全剧版本。逐场检验新增视觉/声音是否改变观众知道的时点，新增动作是否暗示原稿没有的关系/罪责/能力/生死/伤势；特效打斗强化是否改变获胜机制；暧昧强化是否越过原关系进展或自主边界。源稿有剧情漏洞时退回主稿决策，不靠镜头掩盖。

## 内容边界

按当前用户已明确的内容边界及实际呈现检查，不把反派说坏话或描写冲突自动当作者赞同。导演对暴力呈现和成年非露骨暧昧的新增细节也复查。未成年人性化、露骨性行为、现实违法操作教学等不作为增强手段。需要特定平台/地区合规结论时查当前权威规则，不承诺“已过审”，也不强加道德升华或删尽戏剧冲突。

## 反复失败

同类问题再次出现，检查原因是详纲不清、任务包缺依据、状态错误还是执行表达；先修正确的上游，避免只用“再写好一点”反复重写。合理局部修订后仍存在同一创作取舍，向用户提出具体选择；不设置自动升级为全剧推翻的轮次数。
