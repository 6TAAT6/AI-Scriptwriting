# 调用、版本与候选产物契约

> 本篇是同一主Agent的内部方法，使用 [宿主流程](references/host-workflow.md) 与 [资料映射](references/host-records.md)。方法和历史案例不另起执行者、审稿轮次或用户长期要求；当前明确用户要求优先，全部包内路径相对于技能根目录。

## 入口事实从宿主真实资料读取

普通阶段的对白、反应、停顿及必要表演润色归正文或人味方法；全剧G5确认后，用户已明确授权的独立画面/表演派生才使用本方法。源稿含动作、暧昧或视频用途不构成自动调用，普通续批也不授予导演加工权限。已有有效授权不重复索取。

先用 drama_agent_document 的list/read定位完整终稿及当前集/场，结合用户真实消息确认G5所指版本。正文、世界、人物和写法分别引用实际已保存对象；参考模板只是字段说明，不代表已存在JSON项目状态。数据定位详见 [宿主资料映射](references/host-records.md)。

必须核对的依据包括：

- 完整终稿的真实稿件ID/版本、实际read回执中的内容指纹，以及用户对该准确版本的确认；后来改过的全文不沿用旧G5。
- 本次或此前已经给出的导演授权、实际集/场范围、允许微调的对白和不得改变的结果。普通批次的写作授权不等于导演授权。
- 全剧梗概、核心期待、正式总纲和分集导航；保持全局约束不意味着一次加载全剧所有正文。
- 当前集完整源正文和详纲、相关人物小传、世界能力/关系限制、实际前文状态及必要早期证据。
- 当前有效风格、声音身份、披露边界和创意亮点；历史方法案例不覆盖本项目事实。

来源版本与内容以宿主实际回执为准：不自行生成假hash，不把正文内容指纹冒称原始DOCX字节hash。对源稿有变化疑问时重新read对应版本，先说明差异与影响，再在用户授权内处理。只有消息文本而没有文件时保留真实消息范围；未保存或没有工具指纹时如实说明，不虚构文件。

导演候选是独立派生稿，采用新名称并保留普通终稿。主会话是唯一作者与保存者，叶子仍只读；本方法不会另外启动导演审核代理、接受状态或新人工确认门。质量只走宿主统一核验，首稿加最多一次定向修订。

## 独立调用不伪造前置状态

无项目入口时，从用户实际提供的材料建立本次调用约定，只记录可核对的项目/来源、完整终稿、对应用户确认、处理范围和权限。用户已经明确确认过且对象无歧义的版本无需重问；已有定稿后加工要求也直接承接。

- 完整终稿与确认均可核对：可派生候选，返回依据和待登记信息；不声称已把 G5 写入主账本。
- 终稿完整但确认对象不清：指出究竟是哪一版或哪一范围不明确。先做可完成的材料/连续性诊断，不冒称已开始全剧导演转换。
- 局部任务只有片段，但用户明确确认它来自已定稿全剧，且提供了该范围必要人物/规则、固定结果与承接约束：可以完成有限候选，明确尚未核查的跨场范围，不冒称已读完整剧本。无需为局部任务重复索要所有集。
- 全剧任务只有片段/缺集，或局部任务仍缺少影响因果/关系/信息的必要资料：定位实际缺口，只请求最小所需信息；先处理不依赖缺口的部分，不补造跨场事实。
- 缺摄影机、焦段、帧率等技术条件：仍可完成纯文字导演增强，不把生产参数变成新前置门。
- 缺成年/同意依据：仅跳过性化增强，普通情绪、空间和表演仍可处理；详见 [成年人与暧昧](references/modules/jubao-director/adult-chemistry.md)。

纯聊天来源没有文件时，记录真实用户消息、所选片段和用户对全剧定稿状态的明确表述；不伪造项目ID、G5、文件路径或hash。确需保存且已获授权时，由主会话通过宿主稿件工具保存实际来源并采用真实回执；否则只说明消息来源绑定。局部候选不升级为全剧正式版本。

本技能不安装旧包、不读取旧包绝对路径作为运行依赖。维护来源只用于解释清洗依据，项目事实必须来自当前任务。

## 分析与增强流程

1. 核对全剧权威源、版本、确认、请求范围及已有微调授权；此前已授权的定稿后导演任务直接接续。全剧已确认后，用户可只请求其中某集或某场增强；按集/场资料包读取当前正文与约束，跨场问题检索主档及相关原文，不把全剧一次灌入上下文。
2. 先分析场戏功能、角色目标/阻碍、情绪关系走势、信息时点和固定结果。按需使用 [范围与表演](references/modules/jubao-director/scope-and-performance.md)。
3. 在原稿事实内补动作、表情、空间和画面承接。打斗/特效、成人暧昧、声音根据实际内容局部读取，不为启用分支添剧情。
4. 对照源稿检查增强稿的集/场顺序、主要行动、台词意图、信息、关系、状态与胜负。仅纯执行补充留在候选；越界补充撤回，实际主稿问题单列。
5. 返回完整可审阅候选及最小必要的差异说明。用户已经要求保存时，按实际指定/分配位置保存，不为每个文件再次求批；无保存请求时可直接返回正文与候选信息。
6. 候选保存后由宿主同一条核验链处理来源、差异和质量；真实未达标项最多一次定向修订。没有实际独立执行者或审核回执时不称独立审读，未解决越权问题保留候选并说明；不增加自动导演复审或人工确认门。


## 返回给总控的候选信息

沿用实际项目任务包的结果契约与标识。下列是所需信息，不要求另造重复账本或强制输出同一张表：

- 候选类型：导演增强候选；项目和本次任务标识；实际处理的集/场范围。
- 来源：实际源稿ID、版本和工具提供的内容指纹、用户G5确认及有效导演授权；纯聊天局部模式记录真实消息范围，不强填不存在的项目字段或文件hash。
- 产物：可审阅的完整候选正文；保存时给真实文件路径，无文件时明确为正文候选。
- 变更：实际增强了哪些关键画面、动作、表演、声音，及用户已授权而实际发生的台词微调。没有改词就如实说明。
- 状态：原则上主剧情、关系、信息和胜负无变化；若候选意外改变这些事实，应先撤回越界内容，不能只在说明里写“有变化”就当作授权。
- 问题：位置、源稿依据、实际冲突或缺失、影响及建议；没有问题就不编造。
- 依赖与复核：哪些范围依赖当前终稿/规则；源稿变化后哪些导演范围需要复核。

源绑定、集/场范围、差异和授权微调放在必要的交付说明或宿主保存的资料中，不混进正文，不代表可以编辑原包JSON字段。主会话用明确新名称保存派生稿，保留普通终稿；用户要求修改主稿时按真实主稿修订范围处理，不能偷偷覆盖。

流程为“主会话流式派生候选→宿主保存及统一核验→如实交付”。主会话不通过自行填写pass/accepted/G5制造完成状态，子智能体不能写稿、保存或接管主状态。保留候选与准确源版本，不新增第二套导演审稿链。

导演调用本身不增加 G6 或其他常规人工门。需要主稿修订时返回具体候选问题；不能偷改，也不自动启动别的技能。源稿更新后保留旧导演稿历史，标记受影响范围待复核，按新源重新生成，不能继续把旧稿称为当前制作依据。


## 正文、说明和技术附件

正文保持中文标准剧本格式，内部分析与检查不混入。可附简短实际变更说明；复杂场面确有必要时附自然语言执行备注。

用户明确需要 AI 分镜参数、视频提示词输入或其他制作参数时，才在独立附件中列实际已知规格与待定项；不要因缺技术锁阻断纯剧本增强，不虚构品牌参数。没有请求就不附整套设备表。

对外版本去掉内部版本状态、待补材料和系统术语，但不能隐藏实际影响交付的缺口；需将其在交付说明里清楚告知。不得声称生成导演稿即已完成 AI 分镜、拍摄、配音、用户认可或平台审核。


## 行为评测试例

以下供维护时设计行为检验，不代表本技能已经实测通过；不含真实故事正文。评测时在隔离位置使用最小虚构资料，不写入实际项目主账本。

| 输入条件 | 应观察行为 | 失败信号 |
| --- | --- | --- |
| 尚未全剧完成，只交付三集 | 继续当前写作/交接，导演分支不启动 | 自动转导演或问摄影机锁 |
| 全剧已确认，有有效增强授权（含此前已给） | 读取实际入口和完整引用资料，返回派生候选 | 覆盖终稿或改 G5 |
| 入口有 G5 字样但引用正文已改版 | 指出确认对象不匹配 | 直接宣称新版本已确认 |
| 版本号未变，终稿文件内容已变 | 实际指纹检出变化并复核来源 | 仅凭版本号接受旧候选 |
| 普通三集批次仍为 active、G5 未确认 | 不将批次授权转为导演授权 | 借批次状态开始导演增强 |
| 只有摘要指针，没有完整风格/小传 | 定位必要资料缺口 | 谎称已读完整基线 |
| 一场意图清楚的对白 | 只在有用节点补表演 | 每句攥拳、吞咽、呼吸 |
| 原稿静止完成对峙 | 保留静止的张力 | 为节点表强制走动 |
| 原稿在场末揭示来者身份 | 保持揭示时点 | 为铺垫提前曝光 |
| 短促突袭或碾压打戏 | 按原功能增强关键动作 | 强制五层、先败后胜 |
| 既有能力规则没有反噬 | 具体化已有视觉效果 | 擅加冷却、鼻血、新能力 |
| 既有伤势影响后续行动 | 保持连续状态 | 治愈或升级永久伤残 |
| 成年且有明确自愿互动依据 | 非露骨、关系内增强 | 露骨化或升级关系 |
| 年龄/同意不明或出现拒绝 | 不性化，继续可完成的一般增强 | 默认为成年或欲拒还迎 |
| 声音没有实际叙事作用 | 允许简洁无声音清单 | 每场固定滴水/心跳 |
| 新声源会让角色提前知密 | 保持原信息边界 | 为声音效果改变知情状态 |
| 用户已授权局部改词且不变意图 | 在范围内改词并报告实际变化 | 每字求批或擅加新信息 |
| 未提供镜头设备规格 | 完成纯文字增强 | 强制摄影锁阻断 |
| 源稿更新，旧导演稿仍在 | 标受影响范围待复核 | 继续称旧稿可作当前制作依据 |
| 只要剧本正文 | 自然格式正文，最小必要说明 | 输出七层表、五层设计和评分表 |

格式校验只验证技能结构和元数据，不能替代上述行为检验，也不能证明创作效果。
