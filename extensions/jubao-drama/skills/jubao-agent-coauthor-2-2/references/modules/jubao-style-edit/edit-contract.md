# 定向写作与编辑契约

> 本篇是同一主Agent的内部方法，使用 [宿主流程](references/host-workflow.md) 与 [资料映射](references/host-records.md)。方法和历史案例不另起执行者、审稿轮次或用户长期要求；当前明确用户要求优先，全部包内路径相对于技能根目录。

## 先确定用户要什么

- 写前设计：根据指定本场任务与人物资料设计口吻、当前欲望/策略、信息和情绪重点；未确认的是候选。
- 只读诊断：只给有原句依据的问题与目标，不另写完整新稿。
- 定向润色：只处理授权范围，保留未受影响的内容和用户有效改法。

仅粘贴剧本、附材料、说“记录要求”不等于授权全量改写。用户已经明确要改时不用再索取固定开始口令；只问真正影响结果的缺口。既有已认可材料直接承接，不为使用一个独立 skill 要用户重复 G1—G4。

## 改稿边界

在原意和已锁剧情内可改用词、句式、气口、冗余重复、必要动作/表情提示、功能性对白。修改后核对：谁想让谁做什么，是否新增承诺/同意/拒绝，谁知道什么，何时让观众知道，关系有没有被重新定义。

对照原段实际结束状态：已经发生的离场、交物、收起武器等动作，不能仅改成“同意去做”或“打算去做”就停笔。决定、开始行动和完成行动分别会给下场留下不同事实；用户只要求润色时保留原段达到的进度，除非用户明确改变这一出口。

同一句新措辞可能改变角色策略、信息或关系，不按字数少就认定低风险。需要改变主线因果、主要人物动机/关系、世界规则、胜负与结果、关键证据或揭示时点时，先列变更及影响交用户决定。内部严重度或多位审核者同意不产生改写权限。

正文由主会话按当前已确认版本统一保存，子智能体只返回只读发现。参考模板不授予创建JSON账本、写入有效状态或G4/G5确认的权限；改稿涉及实际事实变化时同步说明并核对依赖，不能改记录来遮盖正文矛盾。

## 当前中文格式与个人写法

使用项目已确认中文拍摄稿：集标题、`X-X场  场景名  日/夜  内/外`、人物行、`△`动作、每条台词分别成段，段间空行；对白冒号在括号前，无必要不加括号。两字中文姓名在台词前缀中间两个空格，三个字及以上正常展示；人物栏和 △ 中不在姓名内加空格。OS 为内心独白，VO 为实际画外/电话发声；台词前不加△，画面以△呈现。

台词简短、口语、有人物和情绪目的；主要在场人物有必要反应，普通路人不硬凑台词。动作辅助剧情与表演，少过量成语、华丽辞藻、小说式心理、价值升华、夸张 AI 惯用动作。△画面不写“当、咻、哐当、轰隆”等拟声形容，改写具体声源/动作/结果；少“就在这时、千钧一发”等万能桥接。不得把画面拟声限制扩大为所有人物对白的禁词表。

一行/一行半只表示简洁倾向，不用屏幕折行当硬门。正文默认每集1400–1600汉字，用户明确范围和统计口径优先；不使用历史硬上限，也不以软参考豁免当前区间。场景停留与表达长度服务因果和情绪，不为达数强搬地点；不固定压缩30%，不按形容词、句长、感叹号或潜台词层数一刀切。

当前全中文，不内部英文先写、不默认双语。欧美世界的制度、关系、称谓和行动条件当下要合理，不能用中文载体替换成中式因果，也不把当前漏洞推迟到未来翻译。

格式只修实际问题。一个 △ 可包含必要的多人互动；长动作移出台词括号，连续动作按过程分段，不强插对白。场景名、时间与日夜按真实剧情一致，不将凌晨一律归日。没有用户要求不新增 BGM；字体、字号、行距的完成结论只来自实际文档导出和核验。

改 OS 为嘀咕前检查听见者、隐瞒意图和后续反应；若改变知情或揭示时点，不以口语化为由直接改。局部修订核对主语、受事、动作对象与实际状态，不盲从勘误表。一处格式问题不触发全篇重写；修复问题和受影响下游即可。

## 个人内容边界

内容边界按当前用户真实要求和宿主规则执行。原包列举的儿童/动物虐待、过度歧视、严重侮辱等属于风险参考，不能冒称本用户已经声明这些个人禁区或据此新增长期要求；也不扩大成所有成人冲突禁令。样本里的过度暴力、性化羞辱、BGM、指代错误或突然救场不作为风格标准。

不为增强情绪或人味而自动新增性化、亲密接触、秘密关系或连续虐待。既有成人非露骨情感表达按剧情目的与已确认关系处理；普通编辑不运行导演成人增强分支。G5 后已有导演加工授权可以接续执行，不重复索取同一许可。

## 输出和复核

诊断只列实际问题。授权改稿提供完整指定范围候选正文，报告另放正文之外：原句位置、改动目标、为什么更符合此刻人物/关系/信息/情绪、保留项、任何越权风险。不强制每条改写凑三项维度依据，不输出分数或病症配额。

候选稿不等于用户认可的写法。首批实际稿件交用户作G4决定，之后不逐集逐句新增采纳门；默认三集交付后等下一批，明确到结尾则在授权范围内继续，仍保留G4/G5。主会话完成本批并使用宿主统一核验；人味方法不另开逐集审核、接受状态或全文重写链。

检查可以在合理范围内默读可说性，但没有实际音频、工具输出或用户反馈时，不宣称试听、真人验证或人类验收通过。保存、统计、导出只报本次真实结果，未实际全剧检查不能称全剧完成。
