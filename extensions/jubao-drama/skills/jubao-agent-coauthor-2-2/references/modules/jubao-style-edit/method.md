# 人味、情绪与口语

> 本篇是同一主Agent的内部方法，使用 [宿主流程](references/host-workflow.md) 与 [资料映射](references/host-records.md)。方法和历史案例不另起执行者、审稿轮次或用户长期要求；当前明确用户要求优先，全部包内路径相对于技能根目录。

从角色当场欲望和说话策略写对白，使每次回应接住对方与现场变化。正文作者在写前与写中同时使用本技能，也可独立润色指定稿件；不能只靠写完后删形容词来补救人物没有目的的问题。

## 输入和适用范围

用户要求“人味/情绪/口语”“设计人物口吻”“这段台词像说明书”“删水词但保情绪”或主控派发相关写作任务时使用。仅收到参考文本或只读要求，不自动改写。

有项目时先通过 drama_agent_document 的 list/read 读取实际已保存资料及当前稿件，结合用户真实决定核对版本。完整正文创作同时读取梗概、核心期待、全剧总纲、分集导航、本批详纲、人物、实际前文/状态及写法基准；独立局部润色只读支撑当前范围的资料，不强索整套档案。不能把参考模板或历史案例当成当前确认。

项目的梗概、期待、总纲、导航、契约、世界、写法、披露、人味和亮点资料按 [宿主资料映射](references/host-records.md) 定位到真实稿件或用户消息；原schema字段只作索引参考。首三集写法必须对应真实G4反馈及其准确稿件版本，不声称已经维护原包JSON字段。

最低需要：指定文本或本场情境、角色身份与关系、此刻目标/冲突、必须保留的信息和剧情结果，以及用户要只诊断还是改写。已有信息直接使用；未给而能从文本确定的，说明依据后使用；只有缺项会改变说话意图、主要关系、核心因果或世界规则时问具体问题。

独立处理局部对白不要求先补全全剧档案、风格锁符号或重走五个人工点。没有必要上下文时可给候选改法并标出不确定范围，不能声称已完成全剧语言一致性核查。用户只要求诊断时只诊断；要求改写时在授权范围内给可直接审阅的改稿。

## 阅读与操作

- 新作者先阅读本技能，并按当场任务在 [人味对白方法](references/modules/jubao-style-edit/human-dialogue.md) 中选择 H01—H12 及具体反差/喜剧方法。人物策略与反应链是写作的共同基础，其他方法按问题选用；不重复加载无关案例，不机械计数。
- 执行诊断、润色或输出时读取 [编辑契约](references/modules/jubao-style-edit/edit-contract.md)，守住格式、个人边界和改稿权限。

1. 先找本场任务、角色当场要什么、怕暴露什么、采用什么语言策略，以及双方/观众已知与未知。
2. 沿现场反应检查：上一句或动作改变了什么，下一句怎样回应；辨认策略切换、情绪高低和关系压力。
3. 选最影响本场的一到几种方法处理，不逐句输出十二维分析。保住明确的信息、有效情绪与人物声音；普通自然句也可以合格，不强加结巴、反话、闲聊或动作。
4. 把内容本身的问题和表达问题分开。能在原意内修的直接按授权修；需新证据、主要动机/关系或世界规则变化才能成立的，单列主稿变更建议，不用一句新台词偷偷补设定。
5. 用原句和改稿核对功能、人物、信息来源、承诺、潜台词、情绪走向及揭示时点。只指出实际发现的问题；没有问题可以保留原文并说明适用范围。

“简洁”不是把所有句子改成独词；“强情绪”不是堆辱骂和感叹号；“人味”不是无意义闲聊与不合理行为。保持付费短剧清楚、直接、有压力、有口语行动力的写法。

## 权限与当前工作流

当前正文和台词全中文，不先写英文，不默认输出双语。已确认的欧美世界、时代、制度、生活关系与称谓仍须成立，不能等未来翻译再修因果。

可润色保持原意的词句、气口、重复、短反应与必要表演提示，可在本场授权范围补功能性对白；不能改变主线因果、主要人物动机/关系、世界规则、胜负/结果、关键信息来源或揭示时点。语言策略也可能改变人物立场或承诺，不能把它伪装成微小改词。

全剧G3确认后，主会话在当前批次内运用正文与人味方法连续执笔，默认三集、明确更小范围优先。本模块只处理具体表达问题，不另开全文润色代理或逐集审读。质量并入宿主唯一核验链，首稿加最多一次定向修订。首批承担G4；默认交付后等下一批，明确到结尾则在已有范围内继续，仍保留G4/G5。不增加逐句采纳会、风格锁或新的人工门；单独润色片段不扩成整批。

普通阶段“暧昧加强”若只是已确认关系内的对白、反应、停顿和必要表演润色，可以在本技能处理；若新增关系进展，交总控处理主稿变更。独立派生画面增强留全剧 G5 后，不能只按关键词路由。

普通阶段不输出或例行推荐导演分支，不要求镜头/摄影设备。必要动作和发声提示是正文方法；全剧 G5 后的独立导演增强另行处理。

## 输出

按用户需求选择：

- **写前语言基线**：核心人物的口语/称谓/策略倾向、情绪变化方式和本场注意点。只保留有用信息，用户确认的首三集样稿才是 G4 风格基准；候选设想不能冒称已确认。
- **只读诊断**：具体场次/原句、问题、对当场功能的影响、建议目标。没有必要不逐句展开，不打分。
- **授权改稿**：完整指定范围的中文候选稿；另附简短差异说明、保留的意图与信息、任何需要决定的主稿变化。不把报告塞进正文。

只读子智能体仅返回有依据的问题与建议，不产生可直接交付的改稿、不保存状态或确认。主会话按用户授权完成候选表达及必要差异说明，并统一保存；未经真实工具回执和用户决定，不声称独立审读、人类认可、配音试听、全剧检查或文件生成已经完成。
