# 北美市场题材规律库（海外付费短剧 / AI 漫剧）

适用：目标市场为北美、欧美或“海外付费短剧”的项目，包括把国产短剧改编成海外版。北美项目用本文件代替 `02.md` 的华语 DNA 卡；`03.md` 通用规律区只借节奏、钩子与结构，不借世界观元素。

## 一、市场共识（2026 年公开行业资料，数据多为平台或媒体自述，引用时说明“据报道”）

- 北美是海外短剧收入最高的市场；纯翻译国内剧本的转化在下降，本土化原创更受欢迎。
- 头部题材：霸总 / 亿万富豪言情、狼人与吸血鬼等西方奇幻、大女主复仇、婚恋家庭悬疑；言情占头部收入的大头，惊悚增长最快。
- 主力观众为 25—54 岁女性（言情）；惊悚观众更年轻、男女更均衡。
- 古装宫斗、乡土题材、中式修仙玄幻在北美普遍水土不服；中式神话修仙类 AI 漫剧的成绩主要在东亚、东南亚与二次元平台。
- AI 漫剧在北美的头部作品以豪门言情、替身新娘和美漫画风的超自然题材为主。

## 二、北美题材卡（只借规律，人物、事件与细节按本项目重造）

### N01 隐藏身份的亿万富豪丈夫（Secret Billionaire Husband）
- 例：*The Double Life of My Billionaire Husband*（ReelShort，据报道播放 5 亿以上），奠定北美富豪言情模板。
- 钩子：女主为了急事与看似普通的男人闪婚；婚后被娘家、前任或同事羞辱，观众知道丈夫真实身份而她不知道（戏剧讽刺）。
- 推进：每集一次“差点暴露”或“暗中出手”；身份揭示分层释放，最终在公开场合（董事会、婚礼、慈善晚宴）当众揭晓。

### N02 契约婚姻 / 替身新娘（Contract Marriage / Substitute Bride）
- 例：AI 漫剧《亿万富翁花花公子的替身新娘》（据报道全球播放约 6.3 亿，北美付费平台榜首）。
- 钩子：被迫替姐姐或替真新娘出嫁、或签下一年期婚姻合同；规则清单（不许动心、不许过问过去）制造违约张力。
- 推进：假戏真做，原主或前任回归制造危机；合同到期前的抉择作为高潮。

### N03 真假千金（True Heiress vs. Fake）
- 例：*True Heiress vs. Fake Queen Bee*（ReelShort）。
- 钩子：被抱错的真千金回到豪门，被冒牌千金和偏心家人排挤；DNA 报告、遗嘱、信托是关键证据。
- 推进：真千金凭本事（学业、事业、医术、设计）逐步赢回尊重，假千金的谎言一层层被揭穿。

### N04 被背叛的妻子复仇 / 前夫追悔（Betrayed Wife's Revenge）
- 钩子：结婚纪念日撞见丈夫出轨或被夺走公司、孩子；离婚协议签字一刻反击开始。
- 推进：她重启被埋没的身份（律师、投资人、继承人），前夫与第三者步步失势；“前夫后悔”是持续爽点。
- 本土化：离婚财产、婚前协议、监护权听证、公司股权按北美语境写，不编造具体法条。

### N05 破镜重圆 / 第二次机会（Second Chance Romance）
- 对 30 岁以上女性观众表现稳定。钩子：多年后在婚礼、葬礼或家乡小镇重逢，当年分手另有隐情。
- 推进：误会逐步澄清，现任或家族阻力制造选择题。

### N06 隐婚怀孕与萌宝（Secret Baby / Pregnancy）
- 钩子：一夜之后怀孕独自离开，多年后带着孩子与富豪父亲重逢；孩子是揭开真相的推动者。
- 推进：亲子鉴定、抚养权、继承权制造冲突；萌宝的聪明与真情作为情绪点。

### N07 狼人与命定伴侣（Werewolf Alpha & Mate）——仅在用户要奇幻时使用
- 体系：狼人族群（pack）、Alpha / Beta / Luna 等级、命定伴侣（mate bond）、被拒绝的伴侣（rejected mate）、满月变身、银器伤害。
- 钩子：被 Alpha 当众拒绝的“无狼”女主，觉醒稀有血统后归来；或人类女主误入族群纷争。
- 规则：力量来源、代价与等级只用西方狼人体系，不混入修仙境界、灵根、丹药、宗门。

### N08 吸血鬼与超自然（Vampire / Witch）——仅在用户要奇幻时使用
- 例：AI 漫剧《愤怒的吸血鬼》（据报道北美播放破亿，美漫画风）。
- 体系：吸血鬼家族、血契、日光与银器禁忌、女巫议会（coven）、猎人组织；契约与禁忌是冲突核心。

### N09 黑帮与暗黑言情（Mafia / Dark Romance）
- 例：*Bound by Honor*（据报道播放约 3.7 亿）。钩子：为偿还家族债务或目睹罪行被卷入黑帮继承人身边，危险与保护并存。
- 推进：家族势力对抗、忠诚考验；节奏要紧，避免冗长的打斗与追逐戏（竖屏不好拍）。

### N10 守护者 / 年龄差（Guardian-Protector）
- 例：*How to Tame a Silver Fox*（ReelShort，据报道约 3.56 亿播放）。成熟、有权势的男主保护处于困境的女主，克制与越界的张力。

### N11 家庭悬疑与心理惊悚（Domestic Thriller / Gaslighting）
- 例：*Who TF Did I Marry*（TikTok 系列，手机拍摄，单集约数百万播放）。威胁来自最亲近的人：丈夫、闺蜜、婆婆、保姆。
- 结构：可以开场直接给出“谁做的”，悬念放在如何揭穿；用不可靠信息、紧贴主角视角制造压迫感；声音与色调比打斗更有效。

### N12 敌对转恋人 / 职场权力差（Enemies-to-Lovers / CEO & Assistant）
- 钩子：新来的助理当众顶撞冷面 CEO，或商业对手被迫合作；冲突写在设定里，关系推进自然有戏。
- 提醒：题材饱和，胜负在执行——台词要利落、反应镜头要准、集尾要有情绪钩子。

## 三、改编国产剧本时的中式设定 → 北美等价物

| 中式设定 | 北美等价物（按项目选择，不必一一对应） |
|---|---|
| 龙王 / 战神 / 兵王归来 | 隐藏身份的亿万富豪继承人、退役特种兵、黑帮继承人、科技公司创始人 |
| 赘婿 | 婚前协议下被看不起的丈夫（隐藏富豪）、为还债住进女方家的丈夫 |
| 豪门世家、家族长辈 | 老钱家族、家族企业董事会、信托与遗嘱、家族晚宴 |
| 婆媳矛盾、小姑子 | 富豪婆婆、社交名媛小姑子、继母 |
| 彩礼、嫁妆 | 婚前协议（prenup）、信托基金、遗产分配 |
| 宗门、门派 | 仅奇幻题材：狼人族群、女巫议会、吸血鬼家族；现实题材：家族企业、私立学院、兄弟会 |
| 修仙境界、灵根、功法、丹药 | 仅奇幻题材：血统觉醒、魔法天赋、契约能力；现实题材：专业能力（外科、设计、投资、法律） |
| 神医 | 天才外科医生、制药公司研究员 |
| 古装宫斗 | 现代豪门或企业继承权之争 |
| 高考、编制、户口 | 大学录取与奖学金、终身职位、工作签证或绿卡（涉及时） |
| 春节、中秋、相亲 | 感恩节、圣诞节、毕业舞会、婚礼、约会软件 |

## 四、北美项目写作要点

- 人名、地名、机构、节日、饮食、社交与法律关系都用北美语境；中文只是表达语言，不是故事世界。
- 用户没有要求奇幻时写现实题材；用户要奇幻时只用西方体系（狼人、吸血鬼、女巫、精灵等），不出现修仙、宗门、灵根、渡劫、法宝、仙尊、龙王、战神等中式元素。
- 开场 15 秒内给出强冲突；言情每集约 60 秒落一个情绪点，惊悚每集 90—120 秒；集尾停在反应镜头或揭示前一刻。
- 少用长篇世界观说明、群像和依赖大场景的戏；多用特写、反应镜头和自然口语化台词。
- AI 漫剧画面以美漫或半写实风格为主，避免中式古装、仙侠造型。
