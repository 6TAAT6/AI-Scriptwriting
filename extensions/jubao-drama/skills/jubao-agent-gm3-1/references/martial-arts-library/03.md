## 区2：现代格斗招式模板区

> 蒸馏 6 种现代格斗术的招式描写模板（含写法机制+招式模板+虚构样本+改写对照+适用范围+禁忌+来源规律）。

### 格斗 1：散打（散手）

**写法机制**：散打的核心是"远踢近打贴身摔"——远距离用腿踢，中距离用拳打，近距离用摔法。散打是综合性最强的现代格斗，描写散打的关键是"距离切换"——角色根据距离切换攻击方式。散打的招牌是"鞭腿+侧踹+直拳+抱摔"的组合。散打的节奏是"快→切换→快"——快速攻击，切换距离，继续攻击。

**招式模板**：
- 鞭腿：小腿如鞭，抽对手大腿/腰部/头部
- 侧踹：脚跟踹对手胸口/腹部，力大势沉
- 直拳+摆拳：直拳开路，摆拳重击
- 抱摔：近身抱腿，摔投

**虚构样本**：
```
王少在三步外——林远起腿。
（远——鞭腿。）
小腿抽在王少大腿上——王少腿一软。
林远收腿，进步——
（切换——远→中。）
直拳开路，王少抬手挡——
林远摆拳绕过防御，砸在王少太阳穴。
（中——直拳+摆拳。）
王少踉跄——林远俯身抱腿。
（切换——中→近。）
起身——王少被掀翻。
（近——抱摔。）
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用散打打败了王少" | "林远鞭腿→直拳+摆拳→抱摔，距离切换三连" | 差版是抽象，好版是组合+切换 |
| "林远一拳打倒王少" | "林远直拳开路，摆拳重击太阳穴——组合拳" | 差版是单拳，好版是组合（散打特性） |

**适用范围**：现代/军警/格斗/战神/逆袭题材
**禁忌**：不写单一攻击方式；必须有距离切换；组合攻击
**来源规律**：电影《激战》（张家辉）；《八角笼中》

### 格斗 2：MMA（综合格斗）

**写法机制**：MMA 的核心是"站立+地面"双模式。描写 MMA 的关键是"打-摔-锁"——站立打击，摔倒对手，地面降服。MMA 的招牌是"地面缠斗+降服技"——裸绞/十字固/三角锁。MMA 的节奏是"站立对轰→摔倒→地面缠斗→降服"。

**招式模板**：
- 站立对轰：拳脚组合，试探为主
- 摔倒：抱单腿/双腿摔，将对手拖入地面
- 地面缠斗：骑乘位/侧控/防守位
- 降服技：裸绞（锁喉）、十字固（锁肘）、三角锁（锁颈+手臂）

**虚构样本**：
```
（站立对轰——互相试探。）
林远一拳，王少一拳，互相试探。
林远突然下潜——抱住王少双腿。
（摔倒——抱双腿摔。）
王少被掀翻——林远直接上骑乘位。
（地面缠斗——骑乘。）
林远膝盖压住王少手臂，双手卡住王少脖子——
（降服技——裸绞。）
王少挣扎——三秒后拍地认输。
（拍地认输=降服。）
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用 MMA 打败王少" | "林远站立试探→抱摔→骑乘→裸绞降服" | 差版是抽象，好版是完整流程 |
| "林远在地面上打王少" | "林远上骑乘位，膝压手臂，裸绞锁喉——地面有位置" | 差版是笼统，好版是具体地面位置 |

**适用范围**：现代/格斗/热血/逆袭题材
**禁忌**：不只有站立打击；必须有地面缠斗；降服技必须有名
**来源规律**：电影《激战》；《勇士》

### 格斗 3：拳击

**写法机制**：拳击的核心是"步法+拳法+防守"。描写拳击的关键是"移动+刺拳+重拳"——步法移动找角度，刺拳试探，重拳收割。拳击不写"腿踢摔投"，只写"拳头"。拳击的招牌是"刺拳+直拳+勾拳+摆拳"的组合。拳击的节奏是"刺→刺→重"——连续刺拳试探，突然一记重拳。

**招式模板**：
- 刺拳：前手轻拳，试探+干扰
- 直拳：后手重拳，力大势沉
- 勾拳：从侧面绕过防御，打太阳穴/下巴
- 摆拳：大幅度横扫，力量最大但破绽也大

**虚构样本**：
```
林远脚步移动——绕着王少转。
（步法——找角度。）
刺拳——轻，快，试探。
王少抬手挡——
林远再刺拳——还是轻。
王少放松了——
林远后手直拳砸出！
（直拳——重拳收割。）
拳头正中王少下巴——王少眼神涣散，膝盖发软。
林远补一记勾拳——王少倒地。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用拳击打败王少" | "林远刺拳试探×2，王少放松，后手直拳收割" | 差版是抽象，好版是组合+节奏 |
| "林远一拳打倒王少" | "林远刺拳轻→直拳重——轻重组合" | 差版是单拳，好版是轻重组合（拳击特性） |

**适用范围**：现代/格斗/热血/逆袭题材
**禁忌**：不写腿踢摔投；必须有步法移动；必须有刺拳+重拳组合
**来源规律**：电影《洛奇》系列；《奎迪》；《拳王阿里》

### 格斗 4：军警格斗

**写法机制**：军警格斗的核心是"一击必杀+利用环境"。描写军警格斗的关键是"快+狠+环境"——快速攻击要害，狠辣不留情，利用身边一切物品作为武器。军警格斗不写"回合制"，写"一击制敌"。军警格斗的招牌是"攻击要害+夺武器+利用环境"——插眼/锁喉/踢裆/夺枪/用笔用毛巾用椅子。

**招式模板**：
- 攻击要害：插眼/锁喉/踢裆/击打太阳穴
- 夺武器：抓手腕+扭转+夺刀/夺枪
- 利用环境：用笔插/用毛巾勒/用椅子砸/用门撞
- 一击制敌：快速精准，不缠斗

**虚构样本**：
```
王少掏出刀——
林远没退。
他抓起桌上的钢笔——
（利用环境——钢笔。）
王少刺来——林远侧身让过，手搭王少手腕。
（抓手腕——夺刀。）
林远钢笔插进王少手背——
（攻击要害——手背神经。）
王少惨叫，刀脱手。
林远顺势锁喉，把王少按在桌上——
（一击制敌——不缠斗。）
林远：别动。
王少没动。
（全程不超 3 秒。）
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用军警格斗打败王少" | "林远用钢笔插手背，锁喉按桌——3 秒制敌" | 差版是抽象，好版是具体招式+环境利用 |
| "林远和王少缠斗很久" | "林远 3 秒制敌——军警格斗不缠斗" | 差版是缠斗（违反军警特性），好版是一击 |

**适用范围**：现代/军警/特工/杀手/战神题材
**禁忌**：不写缠斗；必须一击制敌；必须利用环境或攻击要害
**来源规律**：电影《谍影重重》系列；《突袭》；《约翰·威克》

### 格斗 5：泰拳

**写法机制**：泰拳的核心是"八体攻击+硬桥硬马"。描写泰拳的关键是"双拳+双腿+双肘+双膝"——八个攻击点，全方位打击。泰拳不写"巧劲"，写"硬碰硬"。泰拳的招牌是"肘击+膝撞+扫腿"——肘如刀，膝如锤，腿如鞭。泰拳的节奏是"对轰→缠抱→膝肘"——站立对轰，近身缠抱，膝肘收割。

**招式模板**：
- 扫腿：小腿如鞭，抽对手大腿/腰部
- 肘击：肘尖如刀，切割对手额头/眉骨（开伤口）
- 膝撞：膝盖如锤，顶对手胸口/腹部/下巴
- 缠抱：双手锁对手后颈，控制距离，膝撞

**虚构样本**：
```
林远一记扫腿——抽在王少大腿上。
（腿——如鞭。）
王少腿一软——但没倒。
王少还击——林远不躲，硬扛。
（硬桥硬马——泰拳不躲。）
林远近身——双手锁住王少后颈。
（缠抱——控制距离。）
膝盖顶上王少胸口——
（膝——如锤。）
王少弯腰——林远肘尖砸下，切开王少眉骨。
（肘——如刀。）
血顺着王少眉角流下。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用泰拳打败王少" | "林远扫腿→缠抱→膝撞→肘击，八体连击" | 差版是抽象，好版是八体组合 |
| "林远闪避王少的攻击" | "林远不躲，硬扛——泰拳不闪避" | 差版是闪避（违反泰拳特性），好版是硬扛 |

**适用范围**：现代/格斗/热血/战神/逆袭题材
**禁忌**：不写闪避；必须硬碰硬；必须用肘或膝；缠抱后必须膝肘收割
**来源规律**：电影《拳霸》（托尼·贾）；《冬荫功》

### 格斗 6：柔术（巴西柔术）

**写法机制**：柔术的核心是"地面降服+以小博大"。描写柔术的关键是"拉入地面+控制位置+降服"——把对手拖入地面，用杠杆原理控制，最终降服。柔术不写"站立打击"，写"地面缠斗"。柔术的招牌是"防守位+十字固+裸绞"——弱势方用腿控制强势方（防守位），用杠杆锁关节（十字固），从背后锁喉（裸绞）。柔术的节奏是"拉地→抢位→降服"。

**招式模板**：
- 拉入地面：抱腿摔/勾腿摔，将对手拖入地面
- 防守位：仰躺，用腿缠住对手腰部，控制距离
- 十字固：夹住对手手臂，用腰顶肘关节反折
- 裸绞：从背后锁对手脖子，手臂+腿双夹

**虚构样本**：
```
王少比林远大一圈——站着打，林远吃亏。
林远主动下潜——抱住王少双腿。
（拉入地面——抱腿摔。）
王少被掀翻——但马上要站起来。
林远仰躺，双腿缠住王少腰部——
（防守位——以小博大。）
王少挣不脱——林远抓住王少手臂。
林远双腿夹住王少肩膀，腰一顶——
（十字固——锁肘反关节。）
王少惨叫——拍地认输。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用柔术打败王少" | "林远拉地→防守位→十字固，以小博大" | 差版是抽象，好版是完整流程 |
| "林远站着和王少打" | "林远主动拉入地面——柔术不打站立" | 差版是站立（违反柔术特性），好版是地面 |

**适用范围**：现代/格斗/逆袭/以弱胜强题材
**禁忌**：不写站立打击；必须拉入地面；降服技必须有名
**来源规律**：电影《红带》；MMA 赛事

## 区3：冷兵器招式模板区

> 蒸馏 6 种冷兵器的招式描写模板（含写法机制+招式模板+虚构样本+改写对照+适用范围+禁忌+来源规律）。

### 兵器 1：长剑（双手剑）

**写法机制**：长剑的核心是"劈+刺+撩+格"四种基本技法。描写长剑的关键是"距离控制+力量+精准"——长剑是双手武器，力大势沉，但需要距离控制。长剑不写"花哨剑花"，写"大开大合+精准刺击"。长剑的招牌是"劈头+刺胸+撩裆+格挡反击"。长剑的节奏是"蓄→劈→收→刺"——大开大合后必有收招间隙。

**招式模板**：
- 劈：双手高举，从上往下劈，力达剑尖
- 刺：剑尖直冲，最致命但也最冒险
- 撩：从下往上撩，攻击下盘
- 格：用剑身格挡，顺势反击

**虚构样本**：
```
林远双手握剑——高举。
（蓄——高举。）
一剑劈下——风声呼啸。
（劈——力大势沉。）
王少举刀硬格——火星四溅，虎口发麻。
林远收剑——王少刚松一口气。
林远剑尖一转——直刺。
（刺——精准。）
剑尖停在建少咽喉前一寸。
林远：认输吗。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远挥剑砍向王少" | "林远双手握剑高举，劈下——风声呼啸" | 差版是抽象（挥剑砍），好版是具体（双手+高举+劈） |
| "林远用剑花迷惑王少" | "林远大开大合，劈完收剑——长剑不花哨" | 差版是剑花（不符合长剑特性），好版是大开大合 |

**适用范围**：古装/武侠/玄幻/战场题材
**禁忌**：不写花哨剑花；必须大开大合；劈后必须有收招间隙
**来源规律**：电影《卧虎藏龙》；《英雄》；《大明劫》

### 兵器 2：短刀（匕首/短刀）

**写法机制**：短刀的核心是"近身+快+狠"。描写短刀的关键是"贴身+连刺+划割"——短刀是近身武器，必须贴近对手，快速连刺或划割要害。短刀不写"大开大合"，写"短促+精准+致命"。短刀的招牌是"划手腕+刺腰+割喉"——攻击血管密集区。短刀的节奏是"近→刺→退→近"——贴身刺完速退，再找机会近身。

**招式模板**：
- 划：刀刃划过手腕/手臂/大腿，割血管
- 刺：刀尖直刺腰部/腹部/胸口
- 割：刀刃割喉咙，致命
- 挡：用刀身格挡，顺势反击

**虚构样本**：
```
林远藏在袖中的短刀一翻——刀尖朝下。
他侧身贴近王少——
（近——贴身。）
刀刃划过王少持刀的手腕——
（划——割血管。）
血线飙出——王少刀脱手。
林远没退——他再进半步。
刀尖刺入王少腰侧——
（刺——精准。）
王少弯腰——林远收刀，退两步。
（退——刺完速退。）
林远：你流了很多血。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用短刀和王少搏斗" | "林远贴身，划手腕，刺腰侧，退——短促精准" | 差版是抽象，好版是具体招式+节奏 |
| "林远挥舞短刀砍向王少" | "林远不砍，贴身连刺——短刀不挥舞" | 差版是挥舞（不符合短刀特性），好版是贴身连刺 |

**适用范围**：古装/现代/暗杀/刺客/特工题材
**禁忌**：不写大开大合；必须贴身；攻击必须是要害（血管/器官）
**来源规律**：电影《绣春刀》；《谍影重重》；《突袭》

### 兵器 3：枪棍（长枪/棍棒）

**写法机制**：枪棍的核心是"距离+扫+戳"。描写枪棍的关键是"控制距离+横扫+直戳"——枪棍是长兵器，优势是距离，必须保持距离不让对手近身。枪棍不写"近身缠斗"，写"远距离横扫+直戳"。枪棍的招牌是"横扫千军+毒蛇吐信+当头棒喝"——扫腿/戳胸/砸头。枪棍的节奏是"扫→戳→砸"——远距离横扫控制，中距离直戳攻击，近距离砸头应急。

**招式模板**：
- 横扫：棍身横扫，攻击腿部/腰部/头部
- 戳：棍尖/枪尖直戳，攻击胸口/喉咙
- 砸：棍头从上往下砸，攻击头部
- 挑：棍尖从下往上挑，拨开攻击

**虚构样本**：
```
林远长枪一横——挡在身前。
王少冲来——林远枪尖一抖。
（戳——毒蛇吐信。）
枪尖戳向王少胸口——王少侧身让过。
林远收枪，横扫——
（扫——横扫千军。）
枪杆抽在王少小腿——王少跪倒。
林远枪尖下压——停在建少后脑。
林远：动一下就死。
```

### 兵器 4：暗器（飞镖/飞刀/袖箭）

**写法机制**：暗器的核心是"隐蔽+突然+精准"。描写暗器的关键是"藏+发+中"——暗器藏在身上（袖中/腰间/发间），出手突然，精准命中要害。暗器不写"正面交锋"，写"偷袭+暗算"。暗器的招牌是"袖箭/飞刀/毒针"——发射瞬间极快，命中后致命或致毒。暗器的节奏是"藏→诱→发"——先藏暗器，诱对手露出破绽，突然发射。

**招式模板**：
- 袖箭：袖中暗藏小箭，手腕一抖即发
- 飞刀：手指夹刀，甩手即发
- 毒针：针尖淬毒，命中即中毒
- 飞镖：镖尖沉重，命中要害

**虚构样本**：
```
林远双手抱拳——袖中藏着三支袖箭。
王少：你投降？
林远：嗯。
王少走近——放松了警惕。
（诱——让对手放松。）
林远手腕一抖——
（发——突然。）
一支袖箭射入王少肩膀。
王少还没反应——第二支射入膝盖。
王少跪倒——第三支停在他咽喉。
林远：我说投降了。没说投降谁。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远扔暗器攻击王少" | "林远袖箭三连，肩膀→膝盖→咽喉——精准命中" | 差版是抽象，好版是具体暗器+命中点 |
| "林远正面用暗器和王少打" | "林远假装投降，诱王少放松，突然发射——暗器不正面" | 差版是正面（违反暗器特性），好版是偷袭 |

**适用范围**：古装/武侠/刺客/暗杀/悬疑题材
**禁忌**：不写正面交锋；必须先藏后发；命中必须是要害
**来源规律**：电影《绣春刀》；《龙门飞甲》；《唐伯虎点秋香》（搞笑版）

### 兵器 5：双兵器（双刀/双剑/双匕首）

**写法机制**：双兵器的核心是"攻守同步+连击不断"。描写双兵器的关键是"一手攻一手守+双兵器连击"——一手攻击时另一手防御，攻击完后另一手立刻接上，连击不断。双兵器不写"单手停顿"，写"左右交替+无缝连击"。双兵器的招牌是"双刀流/双剑合璧/双匕首连刺"——左右交替攻击，让对手防不胜防。双兵器的节奏是"左→右→左→右"——快速交替，没有间隙。

**招式模板**：
- 左攻右守：左手攻击，右手格挡
- 右攻左守：右手攻击，左手格挡
- 双刀合璧：双手同时攻击，左右夹击
- 交替连击：左右手交替攻击，无缝衔接

**虚构样本**：
```
林远双刀在手——刀尖朝下，反握。
王少挥刀劈来——林远左手刀格开。
（左守。）
格开的瞬间——林远右手刀已经划向王少腰侧。
（右攻。）
王少回防——林远左手刀又到。
（左攻——交替。）
左→右→左→右——四刀连击。
王少退了四步——身上多了四道血线。
林远收刀——双刀归鞘。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用双刀连击王少" | "林远左守右攻→右守左攻→交替连击四刀" | 差版是抽象，好版是具体交替节奏 |
| "林远双手同时攻击" | "林远一手攻一手守，交替连击——双兵器不同时" | 差版是同时（不符合双兵器特性），好版是交替 |

**适用范围**：古装/武侠/玄幻/刺客题材
**禁忌**：不写单手停顿；必须左右交替；攻守同步
**来源规律**：电影《龙门飞甲》；《绣春刀》；《刀》

### 兵器 6：软兵器（九节鞭/长鞭/锁链）

**写法机制**：软兵器的核心是"变向+缠绕+突然"。描写软兵器的关键是"绕圈+变向+缠绕"——软兵器走弧线，可以在中途变向，让对手无法预判。软兵器不写"直线攻击"，写"弧线+变向+缠绕"。软兵器的招牌是"缠绕脖颈/变向攻击/抽击要害"——鞭身缠绕对手武器或身体，突然抽击要害。软兵器的节奏是"绕→变→缠→抽"——先绕圈蓄力，突然变向，缠绕对手，抽击要害。

**招式模板**：
- 缠绕：鞭身缠住对手武器或手腕
- 变向：鞭在空中突然变向，攻击不同角度
- 抽击：鞭尖抽击要害（太阳穴/喉咙/眼睛）
- 收放：鞭身可收可放，控制距离

**虚构样本**：
```
林远九节鞭在手——鞭身在头顶绕圈。
（绕——蓄力。）
王少冲来——林远手腕一抖。
鞭身突然变向——从右侧扫向王少左侧。
（变——突然。）
王少举刀格挡——鞭身缠住刀柄。
（缠——缠绕。）
林远一拉——王少刀脱手。
鞭尖回弹——抽在建少太阳穴。
（抽——要害。）
王少倒地。
```

**改写对照**：

| 差描写 | 好描写 | 为什么改 |
|--------|--------|---------|
| "林远用鞭子抽王少" | "林远绕圈→变向→缠刀→抽太阳穴——四步连击" | 差版是抽象，好版是具体流程 |
| "林远直线挥鞭" | "林远鞭走弧线，中途变向——软兵器不走直线" | 差版是直线（违反软兵器特性），好版是弧线变向 |

**适用范围**：古装/武侠/玄幻/女性武打题材
**禁忌**：不写直线攻击；必须有变向；必须缠绕或抽击
**来源规律**：电影《方世玉》；《黄飞鸿》系列
