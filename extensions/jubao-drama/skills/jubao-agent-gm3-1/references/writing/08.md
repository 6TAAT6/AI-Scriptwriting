# 第四部分 B  编剧内核六维

> **使用规则**：写作时可按需对照六维方法，默认不输出检查记录；每次输出后必须在【创作笔记】中覆盖六维自评。

## 4B.1  六维总览

```
① 主题深度 —— 不只讲什么，还要讲为什么
② 人物弧光 —— 缺陷 → 考验 → 领悟/毁灭
③ 冲突层次 —— 外在 / 内在 / 关系 / 价值，四层交织
④ 潜台词设计 —— 不等台词专家诊断，写作时主动设计
⑤ 戏剧讽刺 —— 观众知道角色不知道
⑥ 人物关系动态 —— 不是静态档案，是动态变化
```

## 4B.2  维度 ①：主题深度

### 核心原则

**主题不是说出来，是通过选择体现。**

每场戏都要问自己：这场戏在说什么？如果只是"推进剧情"，它就缺了一层。

### 写作时的操作方法

1. **开场 5 分钟内埋下主题追问**：不用台词说，用一个动作 / 一个画面 / 一个情境
   - 例：《肖申克的救赎》开场是安迪被判刑——"制度能否定义一个人？"
   - 反例：角色直接说"我今天在想人生的意义"

2. **主题通过角色的选择体现**：
   - 主角在关键时刻的选择 = 主题声明
   - 例：主角选择救人而不是逃跑 = 主题是"人性本善"
   - 反例：旁白说"他终于明白了爱的意义"

3. **主题的反命题必须有力量**：
   - 反派 / 困境必须能说出主题的反面，且让观众觉得"也有道理"
   - 单面主题 = 说教；有反命题的主题 = 思辨

4. **主题的隐喻系统贯穿全剧**：
   - 选 1-2 个核心隐喻（物件 / 动作 / 空间），反复出现
   - 每次出现时状态变化 = 主题深化
   - 例：《千与千寻》的"名字"——失去 → 寻找 → 夺回 = 身份主题

### 检查清单（写作后自评）

```
【主题深度自评】
□ 主题是否一句话能说清：是 / 否
□ 主题是否有反命题：有 / 无
□ 主题是否通过角色选择体现：是 / 否（还在用台词说教）
□ 是否有隐喻系统：有 / 无
□ 开场是否埋下主题追问：是 / 否
□ 结尾是否回应主题追问：是 / 否
```

## 4B.3  维度 ②：人物弧光

### 核心原则

**弧光不是"主角变好了"，是"主角的底层信念被检验、动摇、重塑或毁灭"。**

### 弧光设计的四要素

```
1. 起点信念：主角开头坚信什么
   例："只要努力就能成功" / "爱可以战胜一切" / "没有人可以信任"

2. 检验事件：什么事件开始动摇这个信念
   例：努力到极致仍然失败 / 用爱救人却反被伤害 / 被最信任的人背叛

3. 抉择时刻：主角必须做出选择
   - 坚守旧信念 → 悲剧（或喜剧收尾）
   - 放弃旧信念 → 成长（或堕落）
   - 选择"灰色地带" → 现实主义

4. 终点状态：主角结尾相信什么
   - 与起点相同但更深刻 → 成长
   - 与起点相反 → 堕落或觉醒
   - 没有改变 → 停滞（通常是悲剧）
   - 主动不变并改变外界 → 平面弧（Flat Arc）
     例：《肖申克的救赎》安迪（信念不变，改变了监狱和瑞德）
     例：《守护解放西》（坚持原则，影响周围）
     注意：平面弧 ≠ 停滞。停滞是没成长，平面弧是主动选择不变并影响外界
     写作要点：平面弧主角的信念必须在开场就建立，且会被反复考验
```

### 弧光方向选择指引

```
成长弧：主角信念被检验 → 动摇 → 重塑（最常见，适合大多数主角）
堕落弧：主角信念被检验 → 固执 → 毁灭（反派起源故事 / 悲剧）
循环弧：主角经历一圈回到原点，但视角已变（现实主义 / 文艺片）
停滞弧：主角拒绝改变，被剧情碾压（悲剧 / 警示）
平面弧：主角信念不动，但通过坚持改变了世界/周围的人（英雄片 / 群像戏）
```

### 弧光写作的常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 无弧光 | 主角开头结尾一样 | 必须有检验事件和抉择 |
| 弧光太急 | 一场戏就顿悟 | 弧光需要 3-5 个节点渐进 |
| 弧光无代价 | 改变没有付出 | 每次转变必须有代价 |
| 弧光无逻辑 | 突然就变了 | 每个节点要有因果链 |
| 配角无弧光 | 只有主角在变 | 重要配角也应有弧光（哪怕是反向的） |

### 对接角色坐标九维

```
项目档案中的"角色坐标九维"提供了：
  ④ 核心欲望 → 弧光的驱动力
  ⑤ 核心恐惧 → 弧光的阻力
  ⑧ 关系定位 → 弧光的镜像 / 冲突对象

写作时必须：
  - 让核心欲望和核心恐惧在关键场次直接对抗
  - 让镜像角色在弧光转折点出现
  - 让弧光代价与核心恐惧相关（最怕什么，就让他失去什么）
```

## 4B.4  维度 ③：冲突层次

### 核心原则

**只有外在冲突的戏 = 动作片；四层冲突交织的戏 = 戏剧。**

### 四层冲突

```
① 外在冲突：角色 vs 外部障碍（反派 / 环境 / 任务）
   例：警察抓小偷

② 内在冲突：角色 vs 自己（欲望 vs 恐惧 / 信念 vs 现实）
   例：警察发现小偷是自己的救命恩人

③ 关系冲突：角色 vs 重要他人（爱 / 恨 / 背叛 / 救赎）
   例：警察和师父（教他抓人） vs 小偷（救过他的命）

④ 价值冲突：一种价值观 vs 另一种价值观（正义 vs 恩情 / 法律 vs 人情）
   例："法不容情" vs "恩将仇报不是人"
```

### 写作时的层次叠加法

每场戏至少要有 **两层冲突**。关键场次（中点 / 黑暗时刻 / 高潮）要有 **三层以上**。

```
写作前问自己：
  □ 这场戏的外在冲突是什么？（角色要做什么，什么挡路）
  □ 这场戏的内在冲突是什么？（角色心里在纠结什么）
  □ 这场戏的关系冲突是什么？（和对手之间有什么张力）
  □ 这场戏的价值冲突是什么？（背后在争论什么价值观）

如果只有外在冲突 → 补内在冲突
如果只有外在 + 内在 → 补关系冲突
如果三层都有 → 在高潮场补价值冲突
```

### 冲突推进的"回合感"

好的对白像两人持球互攻，不是单口相声：

```
✅ 回合感：
  A：我想走。（推进）
  B：你不能走。（反向力）
  A：为什么不能？（质疑）
  B：因为你走了，她会死。（加码 + 信息释放）

❌ 无回合感：
  A：我想走，因为我害怕，而且外面下雨了，还有……
  B：好的我理解你。
  （A 在独白，B 在配合）
```

## 4B.4.1  维度 ③ 补充：金手指三道锁

> 主角的特殊优势（能力/资源/人脉/天赋）必须有三道锁，否则就是无敌。
> 三道锁本身是冲突来源，不是限制剧情，是制造剧情。

### 写作时的检查

每场戏用到主角特殊优势时，自问：
□ 这场戏展示代价了吗？（前三次使用必须展示）
□ 这场戏触及边界了吗？（让优势在关键时刻失效）
□ 这场戏有反制吗？（让对手有能力克制）

### 三道锁的运用节奏

```
第一次使用：展示代价（让观众记住"这能力不是白用的"）
第二次使用：展示代价 + 暗示边界（观众开始担心）
第三次使用：代价明确 + 边界触发（主角第一次因优势吃瘪）
中点：反派展示反制（主角的优势被克制，陷入危机）
高潮：主角在边界内创造性使用优势（不是更强，是更聪明）
```

### 禁忌

| 禁忌 | 表现 | 修正 |
|---|---|---|
| 无代价 | 主角随便用能力 | 加代价，且代价随使用次数升级 |
| 无边界 | 什么情况都能用 | 设一个"情感/道德/物理"边界 |
| 无反制 | 反派完全无法应对 | 给反派至少一种反制手段 |
| 优势膨胀 | 能力越来越强 | 优势不升级，升级的是主角的运用智慧 |

## 4B.5  维度 ④：潜台词设计

### 核心原则

**潜台词不是台词专家诊断出来的，是写作时就要主动设计的。**

角色说的 ≠ 角色想的 ≠ 角色要的。这三者之间的缝隙就是潜台词。

### 潜台词的三层模型

```
第 0 层：字面意（角色说了什么）
第 1 层：真实意图（角色为什么要说这句话）
第 2 层：关系折射（这句话同时对不同人有不同含义）
第 3 层：命运暗示（这句话在预示什么）
```

### 写作时的潜台词设计法

**方法一：反写法**
- 先想角色真正想说什么
- 再想他不会直接说什么
- 最后让他用"另一句话"间接表达

```
角色真正想说："我爱你，别走"
直接说 → 0 层潜台词："我爱你，别走"
反写 → 2 层潜台词："外面下雨了，你带伞了吗？"
```

**方法二：信息差法**
- A 知道某事 B 不知道
- A 的台词对 B 是一层意思，对观众是另一层意思

```
（A 知道自己快死了，B 不知道）
A：明天你帮我买杯咖啡。
B：好。
（对 B：日常请求；对观众：他知道自己没有明天了）
```

**方法三：行为错位法**
- 角色嘴上说 A，身体做 B
- 观众看到的是 B，不是 A

```
A（紧握拳头）：我没生气。
（字面：没生气；身体：气得发抖）
```

### 范例教学：潜台词的三层示范

> 规则容易跑偏，范例最易吸收。以下三个范例逐行分析。

**范例一：信息差法（2 层潜台词）**

```
（父亲知道儿子考上了，儿子还不知道父亲知道）
父亲（看着报纸）：今天回来挺早。
儿子：嗯，放学了。
父亲：报纸上说今年录取率涨了。
儿子（僵住）：……是吗。
```
逐行分析：
1. "今天回来挺早"——字面：闲聊；潜文本：我知道你有事瞒着我
2. "报纸上说录取率涨了"——字面：聊新闻；潜文本：我知道你考上了，你在等什么时候告诉我
3. "儿子僵住"——身体先于台词暴露真相；"……是吗"的省略号 = 他知道父亲知道了
4. 全场没有一句"你考上了吧"，但观众全程都知道两人在博弈

**范例二：行为错位法（3 层潜台词）**

```
（妻子刚查出重病，丈夫不知道）
妻子（把体检报告塞进口袋，笑了笑）：今晚吃什么？
丈夫：随便。你怎么这么早回来？
妻子（去厨房翻柜子）：想给你做顿好的。
丈夫：你平时最讨厌做饭。
妻子（背对他，声音很轻）：是吗……可能今天心情好。
```
逐行分析：
1. "塞进口袋 + 笑了笑"——动作先于表情，"笑"是装的
2. "今晚吃什么"——字面：日常；潜文本：我想在告诉你之前，做一件正常的事
3. "想给你做顿好的"——字面：心情好；潜文本：可能是最后一段正常日子了
4. "你平时最讨厌做饭"——丈夫的疑问是天然的，不需要解释
5. "背对他 + 声音很轻"——身体暴露真相，"是吗"的犹豫 = 她快撑不住了
6. 全场没有一句"我病了"，但观众通过"塞报告+反常做饭+背对+声音轻"四层信号已经猜到

**范例三：反写法（1 层但最有力）**

```
（分手三年后重逢）
他：你还好吗？
她（看着手机）：嗯，挺好的。
他：那就好。
（沉默十秒）
她：你呢？
他：也还行。
```
逐行分析：
1. 全是废话——但废话本身就是潜台词：两人已经无话可说
2. "看着手机"——身体回避，比台词更诚实
3. "沉默十秒"——替代型表演，沉默比任何台词都有力
4. "也还行"——"也"字暴露他在模仿她的回答，说明他还在意她的节奏
5. 这个范例的潜台词只有 1 层（"我们已经回不去了"），但留白的力量胜过 3 层

### 每场戏的潜台词检查

```
□ 这场戏有没有"角色想什么说什么"的台词？→ 改成间接表达
□ 这场戏有没有信息差可以利用？→ 设计一层
□ 这场戏有没有行为错位？→ 加一个动作
□ 整场戏的潜台词层数：____（0/1/2/3）
```

## 4B.6  维度 ⑤：戏剧讽刺

### 核心原则

**观众知道角色不知道 = 戏剧讽刺。这是让观众"参与"的最强工具。**

### 三种戏剧讽刺

```
① 悬念式讽刺：观众知道危险，角色不知道
   例：观众知道杯子里有毒，角色端起来要喝
   效果：紧张感 + 对角色的同情

② 反讽式讽刺：角色说的话，观众知道是反的
   例：角色说"他永远不会背叛我"，观众刚看到那人背叛
   效果：悲剧感 + 命运感

③ 误解式讽刺：角色之间有误解，观众知道真相
   例：A 以为 B 是敌人，观众知道 B 在保护 A
   效果：焦灼感 + "快揭晓"的期待
```

### 写作时的运用

**不是每场戏都要有戏剧讽刺**，但关键场次至少一处：

```
开场 → 用悬念式讽刺建立紧张
中点 → 用反讽式讽刺深化主题
高潮 → 用误解式讽刺引爆情感
```

### 戏剧讽刺的禁忌

- **不能滥用**：每场都有 = 观众疲劳
- **不能太明显**：观众一眼看穿 = 没有参与感
- **不能只讽刺不共情**：观众要为角色担心，不是嘲笑角色

## 4B.7  维度 ⑥：人物关系动态

### 核心原则

**静态关系 = 工具人。动态关系 = 活人。**

项目档案里的"关系定位"是起点，不是终点。剧本要展现关系的**变化**。

### 关系动态的四阶段

```
阶段 1：初始关系（档案中的关系定位）
   例：师徒 / 敌人 / 陌生人 / 恋人

阶段 2：关系考验（什么事件在挤压这段关系）
   例：师父发现徒弟在撒谎 / 敌人发现彼此有共同敌人

阶段 3：关系转折（关系发生质变）
   例：师徒 → 对手 / 敌人 → 盟友 / 陌生人 → 恋人

阶段 4：关系终局（结尾的关系状态）
   例：和解 / 决裂 / 救赎 / 共生 / 永别
```

### 关系动态的写作要求

```
每对重要关系都要有：
  □ 初始状态（来自档案 ⑧ 关系定位）
  □ 至少 1 个考验事件
  □ 至少 1 个转折点
  □ 终局状态

关系变化必须驱动剧情：
  - 关系转折点 = 剧情转折点
  - 不是"关系变了所以剧情变了"，而是"事件同时改变了关系和剧情"
```

### 关系网矩阵（写作前画一张）

```
         主角
        /    \
      敌人    恋人
       |      |
      镜像   救赎者
```

每条线标注：
- 这条关系的核心张力是什么
- 这条关系在第几场发生转折
- 这条关系的终局是什么

| 信息边界（有无越界） | ✓/✗/N/A | |
| 角色状态矩阵（位置/情绪/关系/资源/目标） | ✓/N/A | |
| 表演层（4层设计/矛盾关系/空间调度） | ✓/✗/N/A | |
| 白描方法核对（如启用） | ✓/✗/N/A | |
| 伏笔登记（本场是否新埋/回收伏笔，是否更新登记表） | ✓/✗/N/A | |
| 创作笔记（含六维自评+不满意点） | ✓ | |

规则：
- "✗"展开说明问题并记录一次定向建议；不自动修复
- "N/A"必须写一句理由（如"过场戏，5视角免跑" / "短剧模式，表演层 N/A"）
- "创作笔记"栏的"不满意点"改为"风险点或可优化点"——如果确实没有问题，可以写"暂无风险"，但必须说明为什么没有风险
- "伏笔登记"栏：本场如果新埋了伏笔，必须当场更新【1.剧本框架】的伏笔登记表（编号/埋设位置/内容/计划回收位置）；本场如果回收了伏笔，必须更新状态为"已回收"；无伏笔变化时填 N/A
- 整张表格控制在 200 字内，不要长篇大论

## 4B.8  六维写作工作流

### 写作前（生成前问询阶段追加）

```
【人设产能参照】
> 对接【1.剧本框架】角色档案的"人设产能验证"。
> 写作前参照人设产能，决定角色戏份权重。

主角人设产能复查：
□ 危机锁（≥3 条）：是否在本轮写作中触发至少 1 条
□ 资源锁（≥3 条对冲）：本轮是否动用资源，是否展示代价
□ 人设×世界观冲突矩阵：本轮写作是否激活至少 1 项冲突

配角戏份分配原则：
□ 人设产能强的配角：可给更多戏份
□ 人设产能弱的配角：戏份压缩，或本轮补强人设
□ 独占性强的角色：优先安排关键场次

【编剧内核预检】
① 主题深度：
   一句话主题：____
   反命题：____
   核心隐喻：____

② 人物弧光：
   主角起点信念：____
   主角终点信念：____
   核心考验：____

③ 冲突层次：
   外在冲突：____
   内在冲突：____
   关系冲突：____
   价值冲突：____

④ 潜台词设计重点：
   哪几场戏要做潜台词：____

⑤ 戏剧讽刺：
   在哪里埋讽刺：____

⑥ 关系动态：
   核心关系的转折点：____
```

### 写作中（每场戏的六维方法核对）

每写完一场戏，内部自问：

```
□ 这场戏推进了主题吗？（①）
□ 这场戏推进了主角弧光吗？（②）
□ 这场戏有几层冲突？（③）
□ 这场戏的潜台词层数？（④）
□ 这场戏有没有戏剧讽刺？（⑤）

```

如果一场戏六维全空 → 这场戏可能是"过渡戏"，考虑是否能合并或删除。

```

```

## 4B.9  角色驱动写作法

### 何时用角色驱动

- 角色戏（人物深刻的文艺片 / 连续剧 / 长篇电影）→ 必用
- 强情节戏（短剧 / 短视频 / 动作片）→ 选用于关键场次
- 单元剧 → 每集用一次（集尾情感戏）

### 角色驱动写作三步法

```
第一步：进入角色
   闭上眼睛，用角色坐标九维"成为"这个角色
   问自己：
     - 我现在最想要什么（④核心欲望）
     - 我现在最害怕什么（⑤核心恐惧）
     - 我的身体在做什么（⑦肢体语言）

第二步：让角色"说话"
   不是"我让角色说什么"，而是"角色在这种情况下会说什么"
   - 角色的语言指纹（⑥）决定他怎么说
   - 角色的核心欲望（④）决定他想达到什么
   - 角色的核心恐惧（⑤）决定他在回避什么

第三步：让角色"冲突"
   - 把角色的欲望和恐惧放在同一个场景
   - 让他"既想又怕"
   - 这种内在撕裂就是戏
```

### 角色驱动 vs 大纲驱动

```
大纲驱动：
   场景目的 → 角色动作 → 台词 → 完成
   （角色服务于场景）

角色驱动：
   角色欲望 → 角色遇到障碍 → 角色选择 → 场景生成
   （场景服务于角色）

最佳实践：两者结合
   大纲给出"这场戏要发生什么"
   角色驱动给出"这场戏怎么发生"
```
