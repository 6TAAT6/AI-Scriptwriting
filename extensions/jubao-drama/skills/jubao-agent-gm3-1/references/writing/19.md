# 附录 B：总控整合协议

> 当本 skill 被《剧本总控 · 从灵感到可执行剧本》调用时，除原有写作流程外，必须识别当前写作任务属于“初稿 / 修订 / 整合”哪一种模式，并在输出末尾追加统一交接摘要。

## B1. 本 skill 在总控流水线中的定位

- 对应阶段：S4 剧本初稿 / S6 结构修订 / S8 台词整合
- 上游输入：项目档案、大纲、会诊报告、修改任务清单、台词替换清单
- 下游交付：剧本 v1.0 / 剧本 v2.0 / 剧本 v3.0
- 推荐下一步：初稿后进入【剧本医生】；结构修订后进入【台词专家】；台词整合后进入【最终可执行剧本包】。

## B2. 三种写作任务模式

### 初稿模式

触发条件：已有项目档案 + 已锁定大纲，但尚无完整剧本。

输出目标：
- 剧本 v1.0
- 剧本说明
- 创作笔记
- 交接摘要

### 修订模式

触发条件：已有剧本 + 会诊报告 / 修改任务清单。

处理规则：
- 先列出将采纳的修改任务。
- 保留未受影响的场次。
- 不因局部问题重写全剧，除非用户明确要求。
- 输出修订说明，标注“采纳 / 未采纳 / 暂缓”。

### 整合模式

触发条件：已有剧本 + 台词替换清单。

处理规则：
- 只替换被采纳的台词。
- 保持剧情走向、人物关系、场次结构不变。
- 如果台词替换会改变剧情，必须停下询问。
- 输出台词整合说明和角色语言一致性检查。
- 完成整合稿后，提供【导演画面版】可选输出；如用户需要，将最新整合稿交由总控按 `references/visual-director.md` 转换，不修改整合稿正文。

## B3. 统一交接摘要格式

```
【交接摘要】
当前阶段：S__
项目名称：____
已有材料：项目档案 / 大纲 / 剧本旧版本 / 会诊报告 / 台词替换清单
本轮新增：剧本 v__
已确认内容：____
待用户确认：____
主要风险：____
建议下一步：进入剧本医生 / 进入台词专家 / 输出最终可执行剧本包
推荐调用：剧本医生 / 台词专家 / 剧本总控
版本号：剧本 v__
```
