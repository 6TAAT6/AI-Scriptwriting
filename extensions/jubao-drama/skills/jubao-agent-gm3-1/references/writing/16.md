# 第十部分  常见用户场景示范

## 10.1  场景 A：完整短片（无对标）

```
[用户粘贴1.剧本框架输出的项目档案 + 故事梗概]
[用户粘贴本 skill]

LLM：内部完成方法核对（不输出方法核对报告）

用户：开始写作 模式=小说化 节奏=微电影

LLM：[输出生成前问询]
   作品类型：3 分钟微电影
   预估字数：3000-5000 字
   预估场景数：5-7 场
   ......

用户：开始

LLM：[输出完整小说化叙事剧本 + 创作笔记]

用户：第三场对白太硬

LLM：/对白调优 第三场 → 输出调优后的对白（必要时给出 1-3 个备选版本供用户挑选）

用户：用第二版

LLM：[替换第三场对白，给出修订后的完整剧本]
```

## 10.2  场景 B：连续短剧 50 集（已激活 DNA）

```
[用户粘贴档案 + 分集大纲 + DNA 报告]
[用户粘贴本 skill]

LLM：内部校验前置与 DNA 状态（不输出准备报告）

用户：#标准 #短剧

LLM：检测到连续剧集（共 50 集）。请确认写哪一集？建议先写 1-3 集试稿。

用户：写 1-3 集

LLM：[逐集输出，每集独立结构 + 集尾钩子 + 引用 DNA 规律 / 蒸馏库规律]

用户：风格 OK，继续 4-10 集

LLM：[批量推进，每 3 集为一批，批间暂停]
```

## 10.3  场景 C：长篇电影（中途切换节奏）

```
用户：开始写作 模式=标准 节奏=长篇电影
LLM：[问询 + 用户确认 + 开始输出]

[写到第二幕中段，约 50000 字]

用户：感觉节奏太长了，想改成微电影

LLM：检测到节奏切换：长篇电影 → 微电影
   已写部分约 50000 字，按微电影节奏需压缩到 3000-5000 字。
   两种处理方式：
   1. 已写部分按微电影节奏重写（推荐）
   2. 仅后续部分按微电影节奏（可能造成前后割裂）

   你选哪种？

用户：1

LLM：[按微电影节奏重写已有内容 + 保持主题]
```
