# 附录 C：中文短剧拍摄稿格式（推荐给短剧 / 短视频 / 微电影）

> 当用户要求“格式类似短剧案例 / 拍摄稿 / 中文剧本格式 / 不要 FADE IN 和 CUT TO”时，优先使用本格式。  
> 对竖屏短剧、短视频、微电影、中文拍摄执行稿，本格式比英文工业格式更直观。

## C1. 适用场景

- 竖屏短剧
- 抖音 / 视频号 / 小红书短片
- 微电影拍摄稿
- 需要给导演、演员、分镜、制片直接看的中文执行稿

## C2. 格式规则

### 集数标题

```
第一集
```

单集短片可写：

```
短片：《项目名》
```

### 场次标题

格式：

```
1-1 场景名 日/夜 内/外
```

示例：

```
1-1 青槐路 夜 外
1-2 粥铺门口 夜 外
1-3 旧楼楼道 夜 内
```

### 人物行

格式：

```
人物：阿远 老周 粥铺老板
```

只列本场实际出现或发声的人物。画外音 / 电话声也可列入。

### 动作行

动作、画面、调度可用 `△` 开头，但 `△` 标记的是一个连续动作 / 画面段落，不是每一句话都要加。

```
△暴雨砸在外卖箱上。阿远停在旧墙前，低头看手机导航。
△他抬头，从左手边的 16 号看到右手边的 18 号。两块门牌之间没有 17 号，只有一堵贴满小广告的旧墙。
```

动作行要求：
- 一个 `△` 只写一个连续动作段，通常 1-3 句即可。
- 动作发生转折、视角切换、时间跳跃、人物关系变化时，再另起一个 `△`。
- 不要每个短句都加 `△`，避免剧本像提示词预处理文本。
- 不写抽象心理，如“他很痛苦”；改写为“他攥紧饭盒贴纸，眼眶发红。”
- 可写导演提示，但必须简短：

```
（注：此处镜头先给 16、18，再露出中间旧墙。）
```

### 对白行

格式：

```
角色：台词
角色（动作/状态）：台词
角色（OS）：台词
角色（VO）：台词
```

示例：

```
阿远：哥，您这地址是住墙体里吗？
老周（看向旧墙）：十年前有。
门内女人（OS）：放门口吧，阿远。
路白（VO）：苏小姐，霍总约你下午去民政局办手续。
```

### 声音 / 手机 / 字幕

手机提示、系统音、字幕可这样写：

```
手机提示：预约单已预付。超时将影响评分。
系统音（VO）：您已到达目的地。
字幕：三天后。
```

## C3. 输出样式模板

```
短片：《项目名》

1-1 场景名 日/夜 内/外
人物：角色 A 角色 B
△连续动作 / 画面段落。
角色 A（状态）：台词。
角色 B：台词。
△连续动作 / 转场画面。

1-2 场景名 日/夜 内/外
人物：角色 A
△连续动作 / 画面段落。
手机提示：____
角色 A：____
```

## C4. 与原 M1 标准影视格式的关系

- M1 标准影视格式适合英文工业剧本、电影剧本、需要 FADE IN / CUT TO 的团队。
- 中文短剧拍摄稿格式适合国内短剧、短视频、AI 分镜、拍摄执行。
- 用户给出中文剧本案例或明确说“类似这种格式”时，自动切换到中文短剧拍摄稿格式。

## C5. 交接摘要标注

使用本格式时，在交接摘要中写：

```
剧本格式：中文短剧拍摄稿格式
```
