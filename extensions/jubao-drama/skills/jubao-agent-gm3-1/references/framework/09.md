# 附录 C：题材专项模块

> 根据项目档案的"题材方向"字段，自动加载对应模块。
> 每个模块包含：必须机制 + 必检维度 + 禁忌。

## C1 悬疑/推理模块

### 必须机制
1. 线索铺设矩阵：每条线索记录"铺设位置/显隐程度/误导方向/回收方式"
2. 公平推理原则：所有破案关键线索必须在揭晓前已铺设（不能临时编线索）
3. 误导设计：至少 2 条误导线索，每条有"被识破"的节点
4. 嫌疑人矩阵：每个嫌疑人的"动机/机会/手段"三项必须明确

### 必检维度
- 线索是否在揭晓前已铺设？
- 误导是否公平（可以被识破，不是欺骗）？
- 嫌疑人是否都有合理排除理由？
- 真相揭晓是否依赖已铺设线索而非临时信息？

### 禁忌
- 禁止"凶手视角"提前暴露（除非故意制造悬念）
- 禁止关键证据凭空出现
- 禁止侦探靠"灵感"破案而非推理

## C2 科幻模块

### 必须机制
1. 科技设定表：每项技术的"原理/限制/副作用/社会影响"
2. 未来感语言：术语体系 + 日常语言变化 + 称谓系统
3. 科技因果链：技术如何影响社会结构/阶层/日常生活的因果说明

### 必检维度
- 科技设定是否前后一致？
- 技术的限制是否被遵守？
- 社会影响是否合理（有这项技术，社会会怎么变）？
- 语言是否有未来感但不影响理解？

### 禁忌
- 禁止"科技万能"（任何技术必须有代价/限制）
- 禁止用现代思维套未来社会
- 禁止技术设定与剧情需要矛盾

## C3 历史模块

### 必须机制
1. 史实考据清单：涉及的真实事件/人物/制度/器物的考据记录
2. 时代语言系统：称谓/敬语/俗语/禁忌语的时代规范
3. 礼仪与规矩：交往礼仪/等级规矩/性别规范的时代特征

### 必检维度
- 史实是否有考据支撑（不能凭印象写）？
- 语言是否符合时代（不能出现现代词汇）？
- 礼仪规矩是否正确？
- 虚构人物与真实事件的互动是否合理？

### 禁忌
- 禁止现代人思维代入历史人物
- 禁止改变重大史实（除非标明"架空"）
- 禁止时代错位的器物/制度/语言

## C4 喜剧模块

### 必须机制
1. 笑点节奏表：每 N 分钟一个笑点的排布（开场/中段/高潮前的调节）
2. 反差设计：角色反差/情境反差/语言反差的组合
3. 错位层次：信息错位/身份错位/目标错位

### 必检维度
- 笑点密度是否足够（喜剧场场要有笑点）？
- 笑点是否服务于人物和剧情（不是为笑而笑）？
- 反差是否持续有效（不能一次用完）？
- 是否有"冷场段"（超过 5 分钟无笑点）？

### 禁忌
- 禁止低俗/歧视性笑点
- 禁止角色"降智"制造笑点（除非是设定）
- 禁止笑点破坏情感戏

## C5 恐怖/惊悚模块

### 必须机制
1. 恐惧递增曲线：恐惧感从弱到强的阶梯设计
2. 跳吓节奏：跳吓点间隔（不能连续跳吓，需要"安全段"调节）
3. 未知感管理：哪些信息给观众/哪些保留/何时释放

### 必检维度
- 恐惧是否递增（不能一直保持在同一水平）？
- 跳吓是否有铺垫（无铺垫的跳吓是廉价惊吓）？
- 未知感是否有效（给的太多=不恐怖，给的太少=混乱）？
- 安全段是否足够（观众需要呼吸空间）？

### 禁忌
- 禁止过度依赖跳吓（恐怖≠惊吓）
- 禁止恐怖元素逻辑矛盾（鬼的规则不能变）
- 禁止"为恐怖而恐怖"破坏剧情

## C6 武侠/仙侠模块

### 必须机制
1. 武学/境界体系：境界划分/突破条件/每个境界的能力范围
2. 江湖规矩：门派/师徒/恩怨/信义的行为规范
3. 武功招式设计：招式名称/特点/克制关系/修炼代价

### 必检维度
- 境界体系是否一致（不能越级碾压无代价）？
- 江湖规矩是否被遵守（除非违规是剧情点）？
- 武功设计是否有逻辑（克制关系/修炼代价）？
- 称谓是否符合武侠/仙侠语境？

### 禁忌
- 禁止"主角光环"无视境界差距（要有合理突破逻辑）
- 禁止武功体系前后矛盾
- 禁止现代思维破坏江湖氛围
