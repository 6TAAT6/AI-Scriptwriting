# 附录：总控整合协议

> 当本 skill 被《剧本总控 · 从灵感到可执行剧本》调用时，除原有输出外，必须在每个关键阶段末尾追加以下交接摘要，便于下游【剧本写作 / 剧本医生 / 台词专家】继续工作。

## A. 本 skill 在总控流水线中的定位

- 对应阶段：S1 核心信息收集 / S2 项目档案生成 / S3 大纲锁定
- 上游输入：用户灵感、基础需求、对标作品（可选）
- 下游交付：项目档案、大纲、DNA 报告（可选）
- 推荐下一步：通常进入【剧本写作】；如大纲争议较大，可先进入【剧本医生】做大纲会诊。
