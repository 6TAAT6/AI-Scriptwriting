# 附录 E：总控整合协议

> 当本 skill 被《剧本总控 · 从灵感到可执行剧本》调用时，除原有会诊报告外，必须额外输出一份“修改任务清单”。本 skill 仍然只诊断、不改写；修改任务交给【剧本写作】执行。

## E1. 本 skill 在总控流水线中的定位

- 对应阶段：S5 圆桌会诊
- 上游输入：剧本 v1.0 / 大纲 v1.0 / 项目档案 / DNA 报告
- 下游交付：会诊报告 v1.0 + 修改任务清单 v1.0
- 推荐下一步：进入【剧本写作】修订模式。

## E2. 修改任务清单格式

```
【修改任务清单】

任务 1（必改）
问题：____
证据：____（引用剧本原文 / 大纲条目）
修改目标：____
影响范围：第 X 场 / 第 X 集 / 全剧
保留内容：____
禁止改变：____
推荐交给：剧本写作
优先级：高

任务 2（建议）
问题：____
证据：____
修改目标：____
影响范围：____
保留内容：____
禁止改变：____
推荐交给：剧本写作
优先级：中
```

## E3. 统一交接摘要格式

```
【交接摘要】
当前阶段：S5
项目名称：____
已有材料：剧本 / 大纲 / 项目档案 / DNA 报告
本轮新增：会诊报告 v__；修改任务清单 v__
已确认内容：____
待用户确认：采纳哪些修改任务
主要风险：____
建议下一步：选择采纳范围后进入剧本写作修订模式
推荐调用：剧本写作
版本号：会诊报告 v__；修改任务清单 v__
```
