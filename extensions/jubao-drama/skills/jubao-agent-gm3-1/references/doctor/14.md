# 附录 A：按用户授权召集规则（按作品类型）

## 商业类型片（恐怖 / 动作 / 悬疑 / 爱情 / 喜剧 + 长片）
5 人天团：商业制片 + 类型片编剧 + 核心受众观众 + 营销总监 + 平台采购

## 文艺片
5 人天团：文艺制片 + 影评人 + 责任编辑 + 路人观众 + 演员经纪

## 短剧（竖屏多集）
5 人天团：商业制片 + 平台采购（抖音 / 红果视角）+ 核心受众观众 + 短视频解说 UP 主 + 营销总监

## 短视频（单条）
4 人小组：平台采购 + 短视频解说 UP 主 + 路人观众 + 营销总监

## 微电影
5 人天团：文艺制片 + 影评人 + 路人观众 + 演员经纪 + 营销总监

## 单元剧
5 人天团：平台采购 + 类型片编剧 + 核心受众观众 + 追剧型观众 + 责任编辑

## 连续剧
6 人天团：商业制片 + 平台采购 + 核心受众观众 + 追剧型观众 + 营销总监 + 责任编辑

## 长篇电影（院线 / 流媒体单部）
5 人天团：商业制片（如商业向）/ 文艺制片（如文艺向）+ 资深类型片编剧 + 影评人 + 演员经纪 + 平台采购 / 院线发行

## AI 视频生成项目
5 人天团：文艺制片 + 影评人 + AI 视频导演 + 路人观众 + 演员经纪

## 投流驱动的短剧 / 短视频
6 人天团：商业制片 + 平台采购 + 核心受众观众 + 投流操盘手 + 平台算法工程师 + 营销总监

## 出海项目
6 人天团：商业制片 + 出海发行官 + 平台算法工程师 + 核心受众观众 + 营销总监 + 投流操盘手

## 单场 / 单点会诊的特殊召集

|---|---|
| **单场会诊** | 自动选 3 人小组：1 位关注结构（资深编剧 / 责任编辑），1 位关注角色（核心受众 / 演员经纪），1 位关注呈现（类型片编剧 / 影评人） |
| **单点会诊** | 见 5.4 节的"单点 → 评委"映射表 |
