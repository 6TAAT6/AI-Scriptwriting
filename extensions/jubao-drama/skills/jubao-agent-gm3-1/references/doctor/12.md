# 第九部分  与 1.剧本框架、2.剧本写作 的接口

## 9.1  联动模式总览

| 接入物 | 来自 | 在剧本医生中的作用 |
|---|---|---|
| 项目档案 v1.0 | 1.剧本框架 | 评委可引用"角色坐标九维""作品类型""风格调性" |
| 已写剧本 | 2.剧本写作 | 会诊的主要对象 |
| DNA 提取报告 | 1.剧本框架 | 类型片编剧用它做精确对照 |
| 规律蒸馏库 | pattern-library.md | 无 DNA 报告时，类型片编剧用蒸馏库规律 + 通用公式对照；其他评委引用蒸馏库规律做结构维度检查 |
| 台词机制蒸馏库 | lines-library.md | 评委用区4（潜台词设计）和区6（改写对照）做台词质量检查；主治医生归纳新增"台词库符合度"栏 |
| 写作技法蒸馏库 | writing-craft-library.md | 评委用区4（情绪设计）/区7（场景改写对照）/区3（信息编织）做场景质量检查，区9（故事逻辑链）/区10（角色复杂性）/区11（反机械写作）做逻辑链·复杂性·机械感检查；主治医生归纳新增"技法库符合度"栏、"反机械写作"栏 |
| 武术指导蒸馏库 | martial-arts-library.md | 评委用区7（打戏通病急救）和区8（跨区联动案例）和区9（完整打斗场面层次结构）做打戏质量检查；主治医生归纳新增"武术库符合度"栏、"打斗场面层次"栏（仅含打戏项目） |
| 声音叙事层蒸馏库 | sound-design-library.md | 评委用区5（声音通病急救）和区6（跨区联动案例）做声音叙事质量检查；主治医生归纳新增"声音库符合度"栏（仅含声音叙事项目）；**边界：只做叙事性声音，不做配乐/BGM** |

## 9.2  典型工作链

```
1.剧本框架（建档）→ 项目档案 v1.0
   ↓
2.剧本写作（写作）→ 剧本 v1
   ↓
3.剧本医生（圆桌会诊）→ 会诊归纳
   ↓
用户带着归纳回 2.剧本写作改稿 → 剧本 v2
   ↓
3.剧本医生（再次会诊）→ 会诊归纳 v2
   ↓
......（循环至用户满意）
```

## 9.3  用户没用过 1.剧本框架、2.剧本写作 的兼容

如果用户只粘贴了一段剧本（不附档案、不附 DNA）：
- 自动反推简档
- 类型片编剧不援引 DNA，改用规律蒸馏库匹配规律 + 通用类型公式
- 主治医生归纳里不出现"档案偏离"一栏，但可出现"蒸馏库规律符合度"
