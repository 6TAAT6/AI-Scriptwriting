## 1.3h  打斗场面层次质量会诊（martial-arts-library 区9）

> 武术指导蒸馏库（`references/martial-arts-library/index.md`）区9「完整打斗场面层次结构区」提供 5 类打斗场面（单挑持久战/群战混战/追逐转打斗/武器对决/异能对决）的完整 5 层结构样本，每层含环境互动+情绪推进+信息揭示。
> doctor 在 S5 会诊打戏时使用区9 作为打戏层次完整性的会诊标尺，与 writing 在 S4 的写后方法核对（见 writing 第17条）形成“写作方法参照与用户主动会诊分工”。
> 仅在剧本含打戏/动作戏时触发本库检索——纯甜宠/纯商战/纯家庭剧等无打戏项目不检索。

### 会诊前必做

读取 `references/martial-arts-library/index.md` 区9「完整打斗场面层次结构区」，按项目档案中的武打配置+本场戏类型匹配参照：

1. **5 层结构参照**：读取区9 中匹配类型的 5 层结构样本（开场对峙→试探交手→升级对抗→转折爆发→收尾），作为打戏层次完整性的会诊标尺
2. **环境互动参照**：读取样本中每层的环境互动设计（打斗不能在真空里）
3. **情绪推进参照**：读取样本中每层的情绪推进设计（打斗承载角色关系变化）
4. **信息揭示参照**：读取样本中每层的信息揭示设计（打斗承载叙事功能）

### 会诊时的打斗场面层次质量检查

会诊过程中，评委（特别是动作片导演/武指视角评委和类型片编剧）按以下维度检查打戏层次：

| 检查维度 | 对照项 | 检查问题 | 严重度 |
|---------|-------|---------|--------|
| 5 层结构完整性 | 区9 | 关键打戏是否有完整层次推进（开场对峙→试探交手→升级对抗→转折爆发→收尾）？是否有"各放一招没了"的简略描写？短促交手可只抓关键层 | P1（关键打戏缺层）/ P2 |
| 环境互动 | 区9 每层 | 打斗是否有环境互动？打斗不能在真空里——是否利用地形/道具/天气/障碍物？ | P1（关键打戏无环境互动）/ P2 |
| 情绪推进 | 区9 每层 | 打斗是否承载角色关系变化？每层是否有情绪递进（如从试探到愤怒到决绝）？ | P1（关键打戏无情绪推进）/ P2 |
| 信息揭示 | 区9 每层 | 打斗是否承载叙事功能？是否通过打斗揭示身份/弱点/关系/真相？ | P1（关键打戏无信息揭示）/ P2 |
| 动作篇幅 | 区9 样本 | 关键打戏是否有足够篇幅展开？是否触发"简略描写"的机械模式？（字数是参考不是合格线） | P1（关键打戏过度简略）/ P2 |

### 与 writing 的边界

- **writing 写作方法核对**：S4 写打戏时按区9 的 5 层结构编排（见 writing 第17条），是"预防性"检查
- **doctor 会诊**：从全剧视角看打戏层次的整体问题（哪段打戏最扁平/哪场打戏最缺层），输出"打戏层次病灶图"，不逐场改写
- doctor 发现的打戏层次问题在会诊报告中标记为"建议进入 S6 结构修订（打戏层次重写）"，不直接改写
- 区9 的 5 层结构是"诊断标尺"，不是"改写模板"——doctor 指出哪层缺失，改写由 S6 writing 执行

### 主治医生归纳新增栏

主治医生归纳在原有"DNA 偏离度""蒸馏库规律符合度""台词库符合度""技法库符合度""武术库符合度""声音库符合度""反机械写作"基础上，新增"打斗场面层次"栏（仅含打戏项目）：

```
【打斗场面层次】（仅含打戏项目）
- 5 层结构完整性：____（达标/不达标，缺层打戏数：__）
- 环境互动：____（达标/不达标，真空打戏数：__）
- 情绪推进：____（达标/不达标，无情绪变化打戏数：__）
- 信息揭示：____（达标/不达标，纯动作罗列打戏数：__）
- 动作篇幅：____（达标/不达标，过度简略打戏数：__）
- 总体打戏层次健康度：____（健康/亚健康/不健康）
- 建议进入 S6 结构修订（打戏层次重写）：是 / 否
- 建议优先修订的打戏：____
```

### 防机械套用检查

会诊时检查剧本是否存在对区9 的机械套用（如生硬凑齐 5 层但层与层之间缺乏递进逻辑，或环境互动/情绪推进/信息揭示只是标签式点缀而非有机融入）。发现时标记为 P1 级问题，建议"5 层结构必须有递进逻辑，不是填表"。

## 1.3i  AI味识别与消除会诊（writing-craft-library 区12）

> **触发条件**：所有会诊必做（AI味是通病，不分题材）。与 §1.3g 反机械写作会诊互补：§1.3g 查结构（动机/转折/情绪/冲突/场景目的），本节查文本气质（用词/句式/节奏/留白）。
> **定位**：本节是风险识别工具，不是统一成品格式。不同题材可以有不同答案——生活流可以有破碎台词，喜剧可以有逻辑跳跃，不要求每场戏都具备所有"人味"特征。
> **调用库**：writing-craft-library 区12「AI味识别与消除区」。

### 12维AI味检查清单

逐场检查以下12项，不通过的在会诊报告中标注：

| 维度 | 检查问题 | 判定标准 |
|------|---------|---------|
| ①台词书面化 | 角色说话是否像写文章？ | 句句完整+语法规范+无破碎无重复→不通过 |
| ②情绪直白化 | 是否直接用情绪词？ | 出现"愤怒/悲伤/开心/恐惧/焦虑"→不通过 |
| ③逻辑过度线性 | 对话/情节是否像数学公式？ | 无思维跳跃+无联想+无离题→不通过 |
| ④描写均匀化 | 所有元素描写篇幅是否相当？ | 无重点详写+无长短句交替→不通过 |
| ⑤角色声音趋同 | 去名后能否区分说话人？ | 不能区分→不通过 |
| ⑥形容词堆砌 | 形容词密度是否过高？ | 每个名词前都有形容词→不通过 |
| ⑦比喻泛滥 | 比喻频率是否过高？ | 一场戏>1个比喻→不通过 |
| ⑧对话过于有效 | 每句对话是否都承载信息？ | 无寒暄+无废话+无跑题→不通过 |
| ⑨结尾升华 | 是否有"明白了/懂得了/领悟了"？ | 出现升华句→不通过 |
| ⑩情绪反应合理化 | 情绪反应是否总"合理"？ | 该哭就哭+该怒就怒+无非匹配反应→不通过 |
| ⑪描写过度完整 | 每个动作是否都分解到？ | 无省略+无跳跃+全程流水账→不通过 |
| ⑫转折过于规整 | 转折位置是否可预测？ | 转折都在"该转折处"→不通过 |

### AI味综合评分

- **≤2项不通过**：人味达标
- **3-5项不通过**：需修订（P2级问题，作为修订优先级参考）
- **≥6项不通过**：AI味较重（建议复查受影响场次是否过度规整，但不自动判为P1——需结合题材和场景功能综合判断）

### 会诊报告输出格式

在会诊报告的「专项质量会诊」部分新增「AI味识别」汇总栏：

```
### AI味识别汇总

| 维度 | 状态 | 典型问题场次 |
|------|------|------------|
| ①台词书面化 | ✓/✗ | 第X场 |
| ②情绪直白化 | ✓/✗ | 第X场 |
| ... | ... | ... |
| ⑫转折过于规整 | ✓/✗ | 第X场 |

```

### 预防与会诊边界

- **预防**（S4 写作时）：writing.md 第18条要求写完按需用12项清单方法核对，不自动触发额外修订
- **会诊**（S5 本节）：逐场检查，输出综合评分和优先修订建议
- **边界**：AI味消除不是走向极端（过度破碎/过度省略/过度非理性），目的是让文本更真实，不是更怪异

## 1.4  作品类型识别（决定召集哪些评委）

| 档案/剧本特征 | 判定类型 |
|---|---|
| 类型片标签明确（恐怖/动作/悬疑/爱情/喜剧 + 商业向） | **商业类型片** |
| 文学性强、慢节奏、作者气质重 | **文艺片** |
| 单集 90 秒-3 分钟，竖屏 | **短剧** |
| 单条 15 秒-3 分钟 | **短视频** |
| 5-30 分钟，主题先行 | **微电影** |
| 单集独立 + 整体世界观 | **单元剧** |
| 30-50 分钟单集，多集主副线 | **连续剧** |
| 45-180 分钟，单部 | **长篇电影** |

**类型不明确时**，LLM 必须追问：
> 检测到作品类型不明确。请确认是否属于：商业类型片 / 文艺片 / 短剧 / 短视频 / 微电影 / 单元剧 / 连续剧 / 长篇电影 之一？
