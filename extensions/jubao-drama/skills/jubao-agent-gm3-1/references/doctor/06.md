# 第二部分  五步工作流

## 2.1  工作流总览

```
1. LLM 校验前置
       ├─ 缺剧本/大纲 → 立即停止，要求补
       ├─ 缺档案 → 自动反推简档，请用户确认
       └─ 齐全 → 进入步骤 2
2. 用户输入会诊指令（粒度 + 身份 + 是否加极端）
3. LLM 按用户授权召集评委 + 展示评委名单
       - 显示 4-6 位评委的【角色名 + 立场宣言】
       - 等用户回复"开始会诊"或调整评委
4. 评委轮替陈述（按附录 B 角色卡，每人独立段落）
       - 每位评委 200-400 字
       - 必须援引立场 + 引用至少 1 段剧本原文
       - 必须给出至少 1 个风险点或可优化点
5. 主治医生归纳清单
       - 按"必改 / 建议 / 可议 / 别动"分级
       - 每条标注评委来源 + 分歧度
       - 不下最终裁决
       - 末尾附【创作笔记】
```

## 2.2  评委召集确认（步骤 3 详解）

```
【按用户授权召集评委】（基于作品类型：____）

  1. ____ — 立场宣言：____
  2. ____ — 立场宣言：____
  3. ____ — 立场宣言：____
  4. ____ — 立场宣言：____
  5. ____ — 立场宣言：____

如需调整：
  - 替换：/换评委 [旧名] → [新名]
  - 增加：/加评委 [新名]    （从角色池中选，参见附录 B）
  - 移除：/移评委 [名]
  - 加极端反对者：+极端
  - 直接开始：回复"开始会诊"
```

## 2.3  评委陈述（步骤 4 详解）

每位评委的发言必须包含**4 个固定段落**：

```
【评委 X：____】（一句立场宣言）

▸ 我看到了什么
   引用至少 1 段剧本原文（标注场号/集号），用 > 引用块格式。

▸ 我的判断
   2-4 句，必须援引立场。禁止"和稀泥词"。

▸ 我的核心质疑（或核心认可）
   1-2 条，每条具体到位。

▸ 给用户的一句话
   1 句话。如果我是你，下一步该动哪里。
```

## 2.4  主治医生归纳（步骤 5 详解）

主治医生**不是评委之一**，他是会诊的总结者，立场中立。

```
═══════════════════════════════════════════════════
【主治医生归纳】
═══════════════════════════════════════════════════

🔴 必改（≥3 位评委独立提到，强烈共识）
  □ 问题 1：____
    出处：____ 场 / 第 ____ 集
    评委来源：[评委 A] + [评委 B] + [评委 C]
    分歧度：低（都说要改）

🟡 建议（2 位评委独立提到）
  □ 问题 2：____
    评委来源：[评委 A] + [评委 D]
    分歧度：中

⚪ 可议（仅 1 位评委提到，但有真知灼见）
  □ 问题 3：____
    评委来源：[评委 E]
    分歧度：高
    备注：建议参考但不必照办

🟢 别动（≥3 位评委一致认可，是本剧本的优点）
  □ 优点 1：____

🚨 用户必须做的下一个决定
   ____（一句话告诉用户，会诊完了你最该做什么）

【风格符合度提示】🔒
   - 按项目档案风格锁🔒检查对应风格的符合度（不可跳过）：
     - 白描：检查白描六条铁律（禁抒情/以物写人/动词优先/短句为主/留白/一个细节胜过十句概括），不符合的标 🟡/P1
       对接【2.剧本写作】4B.15 白描写作技法 +【1.剧本框架】语言风格🔒字段
     - 浓烈：检查情感浓度/辞藻丰富度/戏剧化，不符合的标 🟡/P1
     - 喜剧：检查笑点密度/反差设计/禁低俗，不符合的标 🟡/P1
     - 标准：检查叙事平衡度（无明显风格偏移即可），不符合的标 🟡/P1
   - 如项目档案无风格锁🔒（未确认语言风格）：标为 P0 级硬伤，提示"回 1.剧本框架 确认风格"

【创作笔记】
   本次会诊召集了 X 位评委
   会诊粒度：____
   核心矛盾：____
   未尽事项：____（哪些维度本次没覆盖）
   自评不满意点：____（评委陈述哪段写得不够锋利）
═══════════════════════════════════════════════════
```

### 严重度映射

用户主动会诊时保留以下问题优先级；只用于本次诊断，不自动安排复检或返修：

| 医生原分级 | 问题优先级 | 说明 |
|---|---|---|
| 🔴 必改 | P0 | 硬伤，报告证据和影响，由本次授权范围决定处理 |
| 🟡 建议 | P1 | 明显问题，给出定向修改建议 |
| ⚪ 可议 | P2 | 提升空间，建议修改 |
| 🟢 别动 | — | 保持现状，不触发修改 |

主治医生归纳时，每条修改建议必须同时标注原分级和问题优先级：
例：🔴/P0 第3场角色A使用了禁忌信息"____"
例：🟡/P1 第7场潜台词密度偏低

> 对接【0.剧本总控】5 视角与 24 评委池分工规则。

执行方式：

2. 输出"5 视角已修复问题清单"

## 2.5 编剧内核诊断

会诊时，除了原有的结构、角色、节奏、市场评估外，主治医生归纳必须额外输出【编剧内核诊断】：

```
【编剧内核诊断】

① 主题深度
   主题是否清晰：____（一句话能说清 / 模糊 / 缺失）
   主题是否有层次：____（只有表面 / 有反命题 / 有隐喻系统）
   主题是否通过行动体现：____（是 / 角色在用台词说教）

② 人物弧光
   主角弧光是否完整：____（有起点 / 有考验 / 有变化 / 闭环 / 缺失项____）
   弧光方向是否清晰：____（成长 / 堕落 / 循环 / 停滞 / 不清晰）
   弧光代价是否合理：____（有代价 / 太轻易 / 无代价）

③ 冲突层次
   外在冲突：____（清晰 / 模糊）
   内在冲突：____（主角内心的矛盾是否建立）
   关系冲突：____（人物之间的冲突是否多维）

```

## 2.10  伏笔超期检测

> 对接【1.剧本框架】的伏笔登记表。

### 检查内容

1. 超期检测：检查所有"未回收"伏笔，是否已超过计划回收位置 3 集
   - 超期 = P0 级硬伤
   - 接近超期（差 1-2 集）= P1 级预警

2. 孤儿伏笔检测：检查是否有伏笔在剧本中完全未被提及（埋了就消失了）
   - 孤儿伏笔 = P1 级

3. 强行回收检测：检查已回收伏笔的回收方式是否合理
   - 生硬回收（突兀、无铺垫）= P2 级
   - 矛盾回收（回收内容与埋设矛盾）= P0 级

4. 伏笔密度检测：
   - 每 5 集至少 1 个伏笔回收（密度太低=观众遗忘）
   - 单集不超过 3 个新伏笔（密度太高=观众记不住）

### 输出格式

【伏笔检测报告】
| 编号 | 状态 | 问题 | 严重度 | 建议 |
|------|------|------|--------|------|
| F1 | 已回收 | 回收生硬 | P2 | 增加铺垫 |
| F2 | 超期 | 计划第5集回收，现第8集 | P0 | 立即回收或废弃 |
| F3 | 未回收 | 正常 | - | 继续保持 |

## 2.11  规则一致性诊断

> 对接【1.剧本框架】的世界观规则表。
> 仅当项目档案有"世界观规则表"时启用。

### 检查内容

1. 规则违反检测：角色使用能力/技术时，是否违反了已设定的规则边界
   - 违反 = P0 级硬伤

2. 规则矛盾检测：新出现的规则是否与已有规则矛盾
   - 矛盾 = P0 级硬伤

3. 规则遗漏检测：角色使用了未在规则表中登记的能力
   - 遗漏 = P1 级（需要补登规则或修改剧情）

4. 规则滥用检测：某条规则被频繁使用但从未展示其限制/代价
   - 滥用 = P2 级

### 输出格式

【规则一致性报告】
| 规则编号 | 使用位置 | 是否违反 | 问题 | 严重度 |
|----------|---------|----------|------|--------|
| W1 | 第3场 | 否 | - | - |
| W1 | 第7场 | 是 | 角色在金丹期飞行，但规则要求元婴期 | P0 |
| 未登记 | 第5场 | - | 角色使用了"瞬移"但规则表无此能力 | P1 |

## 2.12  风格符合度诊断

> 对接【1.剧本框架】项目档案的"语言风格🔒"字段（风格锁）。
> 风格锁是强制项，所有项目都应已确认风格。本诊断始终启用，按锁定的风格类型检查符合度。
> 如发现项目档案无风格锁🔒（未确认语言风格），标记为 P0 级硬伤并提示"回 1.剧本框架 确认风格后再来会诊"。

### 检查内容

1. 白描风格符合度（仅当选择白描时）：
   - 禁抒情检查：是否有情绪形容词（悲伤/愤怒/喜悦…）？→ P1
   - 以物写人检查：人物性格是否通过对待物品的方式呈现？→ P2
   - 动词优先检查：形容词配额是否超标（每200字>3个）？→ P2
   - 短句检查：是否有超过25字未拆分的句子？→ P2
   - 留白检查：段落结尾是否停在画面上（而非总结升华）？→ P1
   - 感官细节检查：每场是否至少一个感官细节？→ P2

2. 浓烈风格符合度（仅当选择浓烈时）：
   - 情感浓度检查：关键场次的情感表达是否足够浓烈？→ P2
   - 辞藻丰富度检查：是否有足够的修辞（比喻/排比/通感）？→ P2
   - 戏剧化检查：冲突是否足够外放？→ P2

3. 喜剧风格符合度（仅当选择喜剧时）：
   - 笑点密度检查：是否场场有笑点？→ P1
   - 反差设计检查：是否有角色/情境/语言反差？→ P2
   - 禁低俗检查：是否有低俗/歧视性笑点？→ P0

4. 标准风格符合度（当锁定为标准时）：
   - 叙事平衡度检查：是否有明显的风格偏移（突然变白描或突然变浓烈）？→ P2
   - 语言一致性检查：全剧语言风格是否保持平衡？→ P2

|--------|------|------|--------|

| 以物写人 | ✓ | - | - |
