# 05. OnlyShot短剧流水线

- **仓库**：https://github.com/A-cat-with-carrots/OnlyShot（242★，2026-08-23 查证）
- **技能数**：ai-short-drama（1 个大技能，v0.6.0，15 个 references + 14 个模板）

## 是什么

工业级 AI 短剧 IP 创作流水线。三阶段：Phase1 创作（剧本+ref图迭代）→ Phase1.5 分镜图（8 段 prompt 模板 CHARACTER/BACKGROUND/ACTION/SCENE/CAMERA/LIGHT/TEXT/STYLE）→ Phase2 出片（即梦 4 模）。沉淀了实战 SOP：ref 库工艺偏置铁律、即梦 5.0 失败模式+敏感词替换表、红果必爆 7 招、36 grid×4-10s 变奏。附带 14 个项目模板（角色圣经/场景圣经/分镜.json 等）。

## 怎么触发

「帮我做一部短剧」及任何短剧/IP 改编/即梦出片请求

## 安装方法

本包内每个子目录（含 SKILL.md）就是一个独立 skill。装到全局：

```bash
# Windows (Git Bash) — 把要用的技能目录拷到全局 skills 目录
cp -r <技能目录> ~/.claude/skills/

# 或装到某个项目内（仅该项目可用）
cp -r <技能目录> <项目>/.claude/skills/
```

装完后在任意目录启动 `claude`，对话中提到相关需求即可自动触发；也可显式点名「用 xxx skill」。

> 注意：Claude Code 只扫描 `.claude/skills/` 下**一层**目录，`<技能名>/SKILL.md` 才能识别，多包一层不加载。
