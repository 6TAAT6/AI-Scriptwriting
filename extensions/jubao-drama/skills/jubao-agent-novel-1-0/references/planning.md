# 规划：设定稿、短篇大纲、长篇三层规划

本模块在“新建”和“规划”时完整读取。设定稿、大纲和章纲都是作者可见的稿件，用清楚的中文标题和编号组织，不写空字段。

## 一、设定稿（kind="document"，名称“《书名》设定”）

按下面顺序写，只写已确认或已代定的内容，代定项在汇总时已告知作者：

一、作品信息
作品名；篇幅（短篇或长篇）；题材类型；主情绪；目标读者或平台；目标字数（长篇再写计划卷数、每章建议字数）；叙事视角；文风基调。

二、一句话故事
谁处在什么困境，为了什么采取行动，最后付出或得到什么。

三、一句话卖点
用一句一秒能看懂的话写出“身份 + 反差 + 钩子”，像书城里的推荐语，例如“老公出轨后，我嫁给了他的残疾小叔”。另写读者在这本书里被放在什么心理位置（被辜负的人、终于清醒的人、忍无可忍的人、被世界亏欠的人、比别人更早看透的人等），以及本书的终极钩子：读者追到最后要看到的那个答案，必须是具体的画面或一句台词。

四、主要人物
每个主要人物写：
1. 一句话标签：身份 + 反差点 + 核心欲望。
2. 年龄、身份，外貌只写两个最显著的特征。
3. 核心价值观、最大恐惧、致命缺陷、真正渴望。
4. 背景里塑造他现在的关键记忆、创伤或秘密（只写会影响剧情的）。
5. 说话方式，附一句能代表性格的台词。
6. 成长弧光：从什么样变成什么样。

反派另写：他为什么认为自己是对的；与主角的深层联系；他的致命缺陷。反派要强大可信，有自己的逻辑。
配角写功能定位（导师、盟友、搞笑、爱情线、叛徒等）、一句话记忆点、与主角的关系、说话特点。没有功能的人物删掉。

五、人物关系
关键关系对的初期状态、中期转折、结局方向和戏剧张力来源。

六、世界规则与关键物件
已确定的规则、能力体系的边界和代价、组织权限、关键物件。现实题材没有特殊规则就写现实背景要点。不写没有用到的设定。

七、内容边界与结局方向
作者的雷点和尺度；短篇的情绪落点或长篇的终局方向。

## 二、短篇

### 核心目标

短篇用有限的篇幅讲完一个集中、闭合、有余味的故事。不要把长篇设定压缩成梗概，也不要靠连续反转代替人物选择。全文按章节写，章节是作者和平台看到的唯一外部结构，章内按情节自然推进。

### 构思顺序

1. 先定读者读完的主要感受：爽、痛、暖、惊、怕或释然，只选一个主情绪。
2. 用一句话写出：谁处于什么困境，为了什么采取行动，最后付出或获得什么。
3. 设计一个能改变读者理解的核心揭示，前文至少有三个具体线索支撑它。
4. 让主角在高潮做出不可撤回的选择，结局来自选择的后果，而不是旁白总结。
5. 删掉不能推动冲突、改变关系、提供线索或积累情绪的片段。

### 短篇大纲（kind="outline"，名称“《书名》大纲”）

一、作品目标：作品名、题材、目标字数、目标读者、主情绪。
二、一句话故事：主角、困境、行动、核心变化。
三、开场钩子：前 300 字发生的异常、危机、损失或必须回答的问题。
四、人物关系：每个关键人物想从主角身上得到什么，双方冲突在哪里。
五、章节链：每章写核心事件、章内情节、冲突、信息变化、情绪变化、离开时的状态和章末推进力。切章落在事件完成、地点或时间转换、情绪转折处，不按字数平分。
六、线索与反转：列出每条线索的出现位置、表面解释、真实含义和揭示位置。
七、高潮与结局：主角的最终选择、代价、情绪落点和最后一个画面。

### 节奏（诊断用，不是字数配额）

- 开头约 10%：建立异常、危机或损失，不先讲完整背景。
- 中段约 60%：阻力递增，每章都有新变化；线索一边解释旧问题，一边制造更深的问题。
- 高潮前约 20%：表面答案崩塌，主角必须在有限时间或代价下做选择。
- 结尾约 10%：展示选择后果，回收核心线索，留下符合主情绪的余韵，最后一段不讲主题。

### 短篇章节

每次写完整的一章。大众移动阅读默认每章 800—1500 字，一章容纳一至三个紧密关联的情节段落；开头尽快建立当下目标或异常，章内至少一次阻力升级，结束时信息、关系、处境或决定发生变化。章末保留明确的阅读推进力，可以是新问题、危机降临、错误理解、被迫选择、情绪反转、关系破裂、线索出现或希望出现；同时完成本章核心事件，不只截断一句话。

### 短篇完成标准

1. 主角的核心困境已经产生不可逆的结果。
2. 核心揭示有前置线索，没有逻辑断口。
3. 关键人物的最后状态清楚。
4. 不打算保留的伏笔全部回收。
5. 最后一段是故事画面或人物行动，不是作者总结。

### 短篇结构模板（按题材挑选，不为套结构牺牲因果）

- 三章微型：激励事件并决定行动 → 尝试、失败、升级 → 最终尝试与结局。
- 五章标准：现状与激励事件 → 犹豫与跨过门槛 → 挑战与盟友或敌人 → 低谷与觉醒 → 高潮与结局。
- 悬疑：发现事件 → 接手调查与初步线索 → 嫌疑人各有嫌疑 → 新线索指向意外方向 → 侦探陷入危险 → 重大反转 → 对决与真相（结尾可留一点余疑）。
- 言情：分别建立双方处境 → 相遇（第一印象不佳）→ 被迫相处、发现吸引 → 亲密 → 误解或障碍 → 关系破裂 → 意识到真心并克服障碍 → 在一起。
- 惊悚：危机出现 → 应对计划失败 → 被逼入绝境 → 发现新希望但时间紧迫 → 生死对抗 → 后果。
- 反转：建立“真实”情况 → 出现不明显的疑点 → 第一次小反转 → 第二次反转 → 最终反转。每次反转回看都有迹可循，不机械降神。

## 三、长篇

长篇只维护三个规划层级：总纲、卷纲、滚动章纲。越近越具体，越远只保留方向。总字数、单章字数和滚动章纲数量都不设硬上限，默认值只在作者、平台和既定大纲都没有要求时使用。

### 总纲（回答全书承诺）

1. 作品定位：题材、目标读者、核心阅读快感或情绪价值。
2. 主角驱动力：外部目标、内部需求、限制和不能接受的代价。
3. 核心矛盾：长期对手或系统性阻力，不依赖反派反复犯蠢。
4. 成长路径：能力、认知、身份、资源和关系分别怎样升级。
5. 主要故事线：主线优先，每条支线说明怎样服务主线或人物弧。
6. 分卷路线：每卷带来不同的问题、不同的对手和读者能感到的阶段结果。
7. 终局方向：最终选择以及核心矛盾的解决方式，不要求提前锁死所有细节。

### 卷纲

卷首状态（人物、资源、关系和未解决的问题）；本卷目标（主角主动追求、可判断成败的结果）；阻力阶梯（至少三个强度递增、性质不同的阻力）；中点变化（新事实或代价改变行动方式，而不只是又来一个敌人）；阶段兑现（兑现此前承诺的能力、关系、真相、身份或胜利）；卷末高潮（主角通过选择和行动获得结果并承担代价）；下卷牵引（由本卷后果自然产生，不靠无关人物突然报信）。

总纲和第一卷卷纲可以合成一份大纲稿件“《书名》总纲与第一卷卷纲”，后续卷纲单独保存。

### 滚动章纲（kind="outline"，名称“《书名》第1—10章章纲”）

作者没指定时每次规划接下来 10 章。每章只写六项：

1. 本章目标：主角或视角人物要完成什么。
2. 主要冲突：谁或什么在阻止。
3. 实质推进：信息、关系、资源或处境发生什么变化。
4. 情绪兑现：读者在本章得到哪一种具体满足或冲击（可以用“憋屈 → 暗爽 → 震惊”这样的情绪曲线标出至少三个情绪点）。
5. 伏笔动作：新埋、推进或回收哪条线，不需要每章都埋新伏笔。
6. 章末未解问题：读者为什么要读下一章（写出具体内容，如信息差、危机逼近、关系转折）。

十章是一个小阶段：前两章建立任务，三到五章升级阻力，第六章出现方向变化，七到九章逼近兑现，第十章完成一次阶段结果并引出新局面。

同时套上读者情绪节奏：每 3 章一个情绪单元。

| 章节 | 情绪任务 | 必须完成 | 章末落点 |
|---|---|---|---|
| 1—3 | 压 → 小扬 → 压（建立代入，抛出异常） | 读者共情主角困境；第一个打破日常的事件；展示主角独特的优点 | 第 3 章结尾有窒息感或强烈好奇，暗示即将反击 |
| 4—6 | 小扬 → 压 → 爆（第一次小爽或小反击） | 主角被迫行动；展示独特能力；拿到具体收益；第 6 章引爆第一个雷 | 出现更大的麻烦或神秘助力 |
| 7—9 | 压 → 小扬 → 压（关系推进，阵营划分） | 明确对立方；出现有魅力的配角；主角做出主动选择 | 抛出中期谜题，暂不解答 |
| 10—12 | 小扬 → 压 → 爆（第一次大高潮） | 引爆前期埋的雷；主角当众胜利；代价随之而来 | 旧平衡彻底打破，进入新局面 |

之后按此循环，爆点规模逐轮扩大。两种节奏冲突时以因果为准，不为套结构硬造事件。

### 不同情绪类型的前三章写法

- 打脸爽文：主角因隐藏身份被嘲讽 → 不经意露出实力却被当成运气 → 遇到更强对手，章末暗示即将当众揭穿身份。
- 虐恋觉醒：女主被忽视或伤害 → 女主觉醒，决定离开 → 对方开始后悔，章末出现后悔的画面。
- 反套路喜剧：主角陷入经典套路 → 用清奇思路破解 → 原剧情或系统试图纠正，章末留“这也能行？”。
- 悬疑惊悚：遭遇无法解释的诡异事件 → 找到一点线索或规律 → 发现规律本身是陷阱，章末留细思极恐的钩子。
- 治愈甜宠：主角孤独或缺爱 → 与对方有一次温暖互动 → 出现小误会，章末对方做出心动举动。
- 脑洞系统：拿到金手指却面临生存危机 → 用金手指解决小危机 → 发现金手指有代价，章末出现更大的机遇。

### 长篇单章

作者没指定时每章 2000—2500 字（明确面向番茄等免费平台时 2200—2800 字）。这个范围既不是最低要求也不是上限。2200—2500 字左右通常容纳一个主要事件加一个次要事件、两到三个场景；2500 字以上可以有一到两个主要事件、三到四个场景。每章至少有一个不可删除的核心事件。

### 连载连续性

日常写作只加载与本章有关的窄上下文，不把整本书塞进一次对话：最近三章摘要维持方向，前两章正文维持语言和动作的承接，更早的内容按人物、伏笔、地点或事件关键词按需查找。已写正文中的事实高于旧大纲；作者的新指令高于现有规划，但不能悄悄改写已发生的事实，需要改历史时先说明影响范围。

### 伏笔管理

伏笔状态只用四种：未回收、推进中、已回收、放弃。新伏笔写清读者看到的表层信息和预计回收窗口；推进时增加新证据，不重复第一次的暗示；回收时答案要同时解释至少一个前文的异常，并改变人物的行动或读者的理解。超过窗口的伏笔标为逾期，不自动删除或强行回收。
