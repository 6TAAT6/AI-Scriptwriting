# 读者思维：情绪定位、书名、简介与评论区

本模块用在拟书名、写简介、定全书情绪定位和设计爽点与讨论点的时候。核心是用户思维：不用“我觉得”判断，先想读者在这一秒得到了什么。这里只借用爆款内容的读者洞察和标题方法，不借用它的说教腔、粗口文风、软广和煽动对立。

## 一、一秒原则

读者在书城只给一本书一两秒。书名、简介第一句和第一章开头，必须一秒能看懂：谁、什么反差、什么钩子。看不懂的书名不是读者理解不了，而是读者不会给第二秒。

爆款故事通常同时满足三件事里的一到两件：

1. 大热点，但比别人写得更新、更深。
2. 永恒的共鸣：被辜负、被看轻、想被理解、想翻身、想被偏爱。
3. 新鲜洞察：老问题的新回答。同一个套路（退婚、重生、替身、追妻），要找到别人没写过的切口。

## 二、读者心理位置

普通的故事回答“发生了什么”，抓人的故事先决定读者点开的那一秒被放在什么位置。动笔前为全书选一到两个主位置，每个爽点或虐点再确认一次：

- 被辜负的人：付出没有回报，终于要讨回来。
- 终于清醒的人：看穿了一段关系或一个局，决定离开或反击。
- 忍无可忍的人：被一再压迫，一次爆发。
- 被世界亏欠的人：明明有本事却被埋没，等待正名。
- 比别人更早看透的人：掌握信息差，看别人入局。
- 正在错过机会的人：时间紧迫，必须选择。
- 有资格审判别人的人：拿到证据，可以当众揭穿。
- 被独家理解的人：终于有人看见他的好。

主角替读者站在这个位置上行动，读者就会代入。位置要和主情绪一致：打脸爽文多用忍无可忍、被世界亏欠、有资格审判；虐文觉醒多用被辜负、终于清醒；治愈甜宠多用被独家理解。

## 三、四类读者情绪

一个爽点单元写得好，往往同时照顾四类读者：

| 读者 | 在故事里给他们什么 | 他们的反应 |
|---|---|---|
| 委屈的人 | 一个看得见的压迫者，以及压迫从何而来 | 想转发给有同样经历的人 |
| 着急的人 | 期限、倒计时、“再不行动就来不及” | 追更 |
| 想评判的人 | 关系、家庭或职场冲突里谁对谁错的现场 | 去评论区表态 |
| 想被原谅的人 | 主角过去的失败被重新理解：不是他不行，是规则对他不公平 | 认同主角，持续追读 |

写完一个情绪单元自检：这四类读者在里面都能找到自己的位置吗？少一类不是错误，但要知道自己少了哪一类。

压迫者用故事里虚构的具体人物和组织，不点名、不影射现实中可识别的人或公司；结构性的压迫（规则、偏见、旧观念）落在具体人物的行为上，不写成对某个现实群体的攻击。

## 四、书名

合格的书名同时做到：

1. 一秒看懂：身份 + 反差 + 钩子，最好是一个画面或一个事件。
2. 有情绪：读者看一眼就知道是爽、是虐、是甜还是怕。
3. 能被转述：读者愿意把它当一句话推荐给别人，不需要再解释。

常用结构：

- 事件 + 反转：“离婚后，我成了前夫的顶头上司”“老公出轨后，我嫁给了他残疾的小叔”。
- 身份反差：“全公司都在等我被开除，直到总裁叫我姐”。
- 第一人称叛逆：“退婚？我偏要嫁给你最怕的人”。
- 设定 + 金手指：“末日降临，我在末世开超市”“穿成炮灰后，我靠吐槽活到了最后”。
- 悬疑悬念：“请勿在零点后乘坐电梯”“我的邻居好像不是人”。

给作者备选时出 2—3 个不同情绪版本，例如更爽的、更虐的、更悬的，推荐一个并说明理由。书名不剧透核心反转，不使用低俗、侮辱性的极端词。

## 五、章名

章名是“判决”，不是“摘要”：写出本章最抓人的那一下，而不是概括本章内容。例如写“他跪下来叫我董事长”，而不是“身份揭晓”；写“十一点五十九分的电梯”，而不是“夜晚的异常”。章名不剧透本章结尾的反转。

## 六、简介（上架资料）

400 字以内，按顺序写：背景危机 → 主角处境 → 核心机制或金手指 → 核心爽点或情绪价值 → 结尾钩子。第一句就要能单独截取当推荐语。标签选 5—8 个与正文实际内容一致的词，不虚构正文没有的卖点。

## 七、评论区入口

让读者想在评论区说话的口子（每 3—5 章至少一两个）：

1. 两难选择：主角在两个都有道理的选项间犹豫，章末先不写决定。
2. 信息差：读者比主角多知道一点，但不是全部。
3. 误解暂不解释：主角被冤枉时先不立刻澄清。
4. 配角高光：给反派或配角一个让人又恨又同情的瞬间。
5. 灰色选择：主角做了道德上有争议的选择，叙述者不评判对错。
6. 一句可以反驳的话：让某个人物说出立场鲜明、读者会站队的话。

理想的评论区会同时出现“说得太对了”“这也太过分了”“换我早走了”“我也经历过”几种声音。

## 八、诚实边界

借用这些方法写的是虚构作品，不是用来操纵读者情绪的工具：

- 不把煽动情绪等同于打动读者；不把贩卖焦虑等同于洞察痛点。
- 不把语言暴力包装成“敢说真话”，人物可以狠，但叙述者不羞辱读者和现实群体。
- 不编造“真实故事”“亲身经历”的噱头来包装虚构情节。
- 真实的悲剧、死亡和弱势群体的真实遭遇不做猎奇加工；重大历史和革命题材不套爽文公式；不把以暴制暴、渲染极端复仇写成被赞美的出路。
- 性别、代际、婚恋这类容易对立的话题，矛盾落在具体人物上，给每一方合理的动机，不写成对某个群体的审判。
