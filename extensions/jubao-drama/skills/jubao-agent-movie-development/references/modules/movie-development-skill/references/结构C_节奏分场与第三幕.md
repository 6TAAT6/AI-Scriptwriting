## 1. 三世界变形机器

可以把剧本看成主角被扔进一台“变形机器”。

| 世界 | 位置 | 功能 |
|---|---|---|
| 正题世界 | 第一幕 | 主角旧生活、旧缺陷、旧规则 |
| 反题世界 | 第二幕 | 主角进入相反世界，被迫测试新方式 |
| 合题世界 | 第三幕 | 主角整合经验，创造新秩序 |

### 1.1 正题世界

要展示：

1. 主角现在怎么活。
2. 他为什么不能继续这样活。
3. 他害怕什么。
4. 他误以为什么能拯救自己。

### 1.2 反题世界

要展示：

1. 主角被迫进入相反生活。
2. 旧方法短期有效，长期失效。
3. 娱乐游戏兑现前提。
4. 中点让新身份公开。
5. 后半段让旧缺陷反噬。

（正题/反题的规则对照表见《结构B_15节拍写作手册.md》2.6.4。）

### 1.3 合题世界

要展示：

1. 主角没有完全回到旧我。
2. 主角也没有被新世界吞没。
3. 主角整合旧能力和新领悟。
4. 最终行动创造新的关系、新秩序或新身份。

## 2. 五要点结局

第三幕常写坏，因为作者只知道“最后赢”，不知道赢之前要经历哪些步骤。五要点结局用于构建最终行动：

```text
召集团队 -> 执行计划 -> 高塔意外 -> 深入挖掘 -> 新计划成功
```

| 步骤 | 功能 |
|---|---|
| 召集团队 | 修复关系、整合资源、准备最终行动 |
| 执行计划 | 让观众看到新策略似乎有效 |
| 高塔意外 | 证明计划仍不够，旧逻辑还不够 |
| 深入挖掘 | 主角做开场时绝不可能做的选择 |
| 新计划成功 | 主角用主题真相解决 A 故事 |

### 2.1 召集团队

主角决定进入最终行动，重新团结盟友、修复关系、准备工具。

不一定真有团队，独角戏也可以是：

1. 重新整合技能。
2. 找回信念。
3. 带上前面铺垫的道具。
4. 与关键人物和解。

### 2.2 执行计划

计划开始顺利，观众感觉“也许真的能成”。

注意：

1. 让配角发挥前面铺垫的能力。
2. 让主角表现出新策略。
3. 让观众看到目标越来越近。

### 2.3 高塔意外

计划失败，主角发现：

1. 目标不在预想位置。
2. 反派早有准备。
3. 盟友中有人背叛。
4. 之前的理解是错的。
5. 真正考验不是原来的任务。

功能：证明主角不能靠旧计划胜利。

### 2.4 深入挖掘

所有常规办法失效，主角必须做开场时绝不可能做的事。

这是结局中最重要的变化证明。

例子方向：

| 开场缺陷 | 深入挖掘时必须做 |
|---|---|
| 控制欲 | 放手让别人选择 |
| 逃避 | 当众承认真相 |
| 自私 | 牺牲个人利益 |
| 冷漠 | 主动表达爱 |
| 依赖规则 | 打破规则救人 |
| 怕失败 | 公开承担失败 |

### 2.5 新计划执行

主角使用新自我完成最终行动。

注意：

1. 不要让运气解决问题。
2. 不要让配角替主角完成变化。
3. 不要让反派突然变蠢。
4. 胜利必须来自主角学到的主题。

## 3. 多模型节奏对照

面对不同长度、不同类型、不同叙事传统的故事时，不要只套一个 15 节拍表，而要把多个结构模型互相翻译。判断结构时，先问三个问题：

```text
1. 这个故事的观众期待是什么？类型快感决定节奏密度。
2. 主角的错误信念何时被打破？人物弧光决定关键转折。
3. 每 10-15 分钟有没有一个不可逆变化？观影注意力决定钩子频率。
```

### 3.1 五种节奏模型的对应关系

| 功能 | 10 分钟钩子 | 15 分钟段落 | 三幕式 | 英雄旅程 | Save the Cat |
|---|---|---|---|---|---|
| 建立世界和缺口 | 0-10 分钟 | 第 1 段 | 第一幕开端 | 平凡世界 | 开场画面、主题呈现、铺垫 |
| 事件打破旧生活 | 10-20 分钟 | 第 2 段 | 第一幕推动 | 冒险召唤、拒绝召唤 | 催化剂、争论 |
| 主角正式上路 | 20-30 分钟 | 第 3 段 | 第一幕转第二幕 | 跨越第一道门槛 | 第二幕衔接点、B 故事 |
| 兑现类型承诺 | 30-45 分钟 | 第 4-5 段 | 第二幕前半 | 考验、盟友、敌人 | 娱乐游戏 |
| 游戏规则反转 | 45-60 分钟 | 第 6 段 | 第二幕中点 | 接近洞穴深处 | 中点 |
| 压力系统收紧 | 60-75 分钟 | 第 7-8 段 | 第二幕后半 | 严峻考验前的逼近 | 坏蛋逼近 |
| 旧方法彻底失败 | 75-85 分钟 | 第 9 段 | 第二幕低谷 | 严峻考验、死亡与重生 | 一无所有、灵魂黑夜 |
| 新自我产生新方案 | 85-95 分钟 | 第 10 段 | 第二幕转第三幕 | 奖赏、归途 | 第三幕衔接点 |
| 最终选择和行动 | 95-115 分钟 | 第 11-12 段 | 第三幕高潮 | 复活、带着灵药归来 | 结局 |
| 情绪回声 | 最后 3-5 分钟 | 尾声段 | 结局后状态 | 归来后的新世界 | 终场画面 |

使用方法：

```text
如果用户给的是 120 分钟长片，用 10 分钟钩子检查注意力。
如果用户给的是 90-100 分钟电影，用 15 节拍检查功能完整性（见《结构B_15节拍写作手册.md》）。
如果用户给的是人物成长故事，用英雄旅程检查内在变化。
如果用户给的是商业类型片，用 Save the Cat 检查类型承诺和中点强度。
如果用户给的是文艺/作者电影，用三幕式检查不可逆转折（见《结构D_结构诊断.md》），不要机械要求每个节拍都外显。
```

### 3.2 英雄旅程的剧本化使用

英雄旅程适合人物成长、冒险、奇幻、科幻、成长片、公路片，也适合普通现实题材。使用时不要机械写“导师、宝剑、洞穴”，而要把它翻译成人物心理。

| 英雄旅程功能 | 剧本写法 | 人物变化 |
|---|---|---|
| 平凡世界 | 展示主角惯性和缺口 | 他相信错误信念还能保护自己。 |
| 冒险召唤 | 外部事件要求他改变 | 世界第一次证明旧方法不够用。 |
| 拒绝召唤 | 主角逃避、讨价还价 | 他还想保住旧身份。 |
| 遇见导师 | 遇见价值观相反的人/事件 | 新真相第一次被说出或示范。 |
| 跨越门槛 | 主角进入新规则 | 他开始行动，但仍用旧方法。 |
| 考验盟友敌人 | 连续场景暴露能力和关系 | 他知道谁能帮他，谁会压迫他。 |
| 接近洞穴 | 逼近核心恐惧 | 外部目标开始触碰内心旧伤。 |
| 严峻考验 | 象征性死亡 | 错误信念带来最大代价。 |
| 奖赏 | 得到线索、能力或真相 | 他看见另一种活法。 |
| 归途 | 新真相接受现实检验 | 改变不是顿悟，而是行动风险。 |
| 复活 | 最终选择 | 他用新自我面对旧恐惧。 |
| 带药归来 | 尾声 | 新行为改变世界或关系。 |

## 4. 10 分钟钩子表（120 分钟电影，含 15 分钟段落问题）

10 分钟钩子不是每 10 分钟放一个爆点，而是每 10 分钟让观众获得一个新的观看理由。这个理由可以是目标推进、关系变化、信息反转、压力升级、道德选择或情绪兑现。适合商业电影、类型片、长片梗概和分场。90-100 分钟电影按比例压缩时间即可；如果某一段只是在路上、聊天、解释背景，就说明节奏松。

| 时间（分） | 功能 | 必须发生的变化 | 观众心理 / 本段问题 | 写作检查 |
|---|---|---|---|---|
| 0-10 | 开场钩子 | 主角旧世界、缺陷、压力和主题暗示；暴露错误信念和生活失衡 | 我愿意跟这个人走吗？主角为什么不能继续这样活？ | 开场是否有动作、矛盾或强画面，而不是背景介绍？ |
| 10-20 | 催化压力 | 旧世界被打破，主角开始失控，但还想逃 | 这事会把他推到哪里？为什么现在必须行动？ | 主角能否回到原生活？如果能，催化剂不够强。 |
| 20-30 | 进入新世界 | 主角做决定，第二幕启动，B 故事露头 | 故事终于开始了 | 主角是主动进入，还是被剧情搬运？ |
| 30-40 | 前提兑现 1 | 新世界规则展示，类型承诺开始兑现 | 这片子的卖点出现了 | 公路片要上路，悬疑片要出谜，喜剧要开始失控。 |
| 40-50 | 前提兑现 2 | 主角短期适应，关系发生小变化，小胜利里埋下大问题 | 原来事情没那么简单 | 主角的旧方法是否开始造成新问题？ |
| 50-60 | 中点 | 伪胜利/伪失败，赌注提高，目标、身份发生不可逆变化 | 我以为懂了，其实不懂 | 是否出现伪胜利/伪失败？赌注是否提高？ |
| 60-70 | 坏蛋逼近 1 | 外部压力增强，团队或关系出现裂缝 | 主角撑不住了 | 反派、制度、关系、时间是否同时压迫？ |
| 70-80 | 坏蛋逼近 2 | 旧伤、秘密、敌人策略集中爆发，B 故事或核心关系被撕开 | 这次可能真的完了；他最需要的人为什么离开/反对？ | 失去的是物品、关系、身份还是信念？ |
| 80-90 | 一无所有 | 关系破裂、目标失败、死亡气息，旧方法被证明无效 | 主角失去什么才算真的完？ | 失败是否来自主角旧方法，而不是外部运气？ |
| 90-100 | 灵魂黑夜 | 主角承认失败，真正主题浮现，从错误信念转向真相 | 他终于明白问题不是外面的 | 主角是否承认自己的错误信念？ |
| 100-110 | 最终行动 | 召集团队、执行计划、高塔意外（见第 2 章五要点结局） | 我想看他怎么赢/怎么输；他会付出什么？ | 新方案是否来自人物改变，而不是天降线索？ |
| 110-120 | 深入挖掘与终场 | 主角用新自我胜利，终场画面对照开场 | 这个故事改变了什么？ | 主角是否必须放弃旧欲望来完成新自我？终场是否和开场形成对照？ |

### 4.1 每 10 分钟钩子的检查问题

```text
这一段开始时主角相信什么？
这一段结束时主角失去或获得了什么？
是否有新信息、新地点、新关系变化或新危险？
是否让下一个 10 分钟不可避免？
```

## 5. 40 场分场板

将 120 分钟电影拆成 40 场，每场约 2-4 分钟。

| 区段 | 场次 | 功能 |
|---|---|---|
| 第一幕 | 1-10 | 旧世界、主题、催化、争论、选择 |
| 第二幕前半 | 11-20 | 新世界、B 故事、娱乐游戏、中点 |
| 第二幕后半 | 21-30 | 坏蛋逼近、一无所有、灵魂黑夜 |
| 第三幕 | 31-40 | 第三幕方案、五要点结局、终场 |

### 5.1 每场戏必须填写

```text
场号：
节拍归属：
场景地点：
出场人物：
主角目标：
阻力：
冲突：
本场转折：
本场结束状态：
是否推动主题：
是否推动 A 故事：
是否推动 B 故事：
```

### 5.2 场景级结构

每场戏内部按：

```text
目标 -> 冲突 -> 灾难/反转 -> 反应 -> 两难 -> 决定
```

如果一场戏没有目标、冲突、转折，它可能只是信息说明。
