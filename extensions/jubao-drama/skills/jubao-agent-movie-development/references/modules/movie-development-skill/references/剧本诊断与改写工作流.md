# 剧本诊断与改写工作流

这个文件用于让 Agent 像剧本医生一样工作：先判断问题属于结构、人物、类型、场景、对白还是压力系统，再给出可执行改法。不要直接给笼统评价。

## 0. 总工作原则

```text
先诊断，再改写。
先结构，再人物，再场景，再对白。
先找旧方法造成的代价，再写新选择。
每条建议都必须能落到具体场景。
```

## 1. 烂剧本诊断与改写规则

当用户说“哪里烂”“哪里不对”“帮我诊断常见问题”时，按“表面症状 -> 根本原因 -> 对应改法 -> 改写示例”的顺序输出。

| 问题 | 表面症状 | 根本原因 | 对应改法 |
| --- | --- | --- | --- |
| 对白太直白 | 人物直接说情绪、主题和关系结论 | 缺少具体事实、动作和潜台词 | 把“我很难过”改成账单、旧物、错过的日期、没打出的电话；让人物说眼前事，潜台词说真正伤口 |
| 场景没有目标 | 人物聊天很多，但没有人想在场景内得到某个结果 | 没有场景任务 | 给每场戏设置可见目标：拿到签字、阻止离开、隐瞒真相、争取资源、逼对方承认 |
| 人物没有弧光 | 人物从头到尾只是被事件推着走 | 没有错误信念和新行为 | 补“旧伤-错误信念-旧方法-代价-新选择”，让第三幕行动和开场相反 |
| 冲突重复 | 每场都在吵同一件事 | 没有升级阶梯 | 第一场吵事件，第二场吵旧账，第三场吵价值观，第四场做不可逆选择 |
| 中段塌陷 | 第二幕只有连续任务或散点段落 | 中点不改变规则 | 设计伪胜利/伪失败，让目标、赌注、身份或关系发生反转 |
| 结尾太快和解 | 一句道歉解决多年伤害 | 没有具体承担 | 让和解前先发生承认、补偿、放权、公开承担或真正失去 |
| 反派只会作恶 | 反派没有逻辑，只制造麻烦 | 缺价值观压迫 | 给反派一套能自洽的世界观，让他逼主角回答主题问题 |
| 爱情线像奖励品 | 主角完成任务后获得爱情 | 爱情没有改变人物 | 让爱情线暴露主角防御，迫使其付出选择代价 |
| 喜剧只是插科打诨 | 笑点可删，不影响剧情 | 喜剧没有来自人物和压力 | 让笑点来自角色认真坚持错误方法，并让笑点造成新麻烦 |
| 类型爽点不足 | 观众看不到该类型该有的关键场景 | 没有类型承诺清单 | 列出该类型 8 个必备场景，中段至少兑现 4 个并逐步升级 |
| 外部压力不够 | 主角只是在内心纠结 | 缺少反派/制度/时间/关系压迫 | 加入可见压力系统，让主角不行动会失去具体东西 |

诊断任意一类问题时，统一使用以下输出格式：

```text
Agent 输出格式：
问题判断：<上表中的问题名>
证据：指出大纲/场景中 2-3 个具体表现。
优先级：高/中/低。
修复方案：给出 3 个场景级改法。
改写示例：写一个 8-15 行的新版场景骨架或对白骨架。
```

## 2. 桥段升级库

### 2.1 小误会升级成大麻烦

1. 误会必须先有合理来源
2. 第二步让人物为了体面撒小谎
3. 第三步让小谎影响外部利益
4. 第四步让无辜者承担代价
5. 第五步逼主角公开承认或继续更大谎言

### 2.2 普通争吵升级成关系破裂

1. 第一轮争当前事件
2. 第二轮翻旧账
3. 第三轮攻击身份
4. 第四轮说出不能收回的话
5. 第五轮用行动切断关系：离开、退群、撤资、取消婚礼

### 2.3 普通旅途升级成生死选择

1. 先让目的地有情感意义
2. 再制造资源损失
3. 然后出现必须救人的旁支
4. 最后让继续前进和回头救人互斥

### 2.4 喜剧尴尬升级成失控

1. 先设计一个小体面需求
2. 让角色用错误方法遮掩
3. 让旁观者误读
4. 让制度流程介入
5. 让公开场合把私事放大

### 2.5 真相一层层揭开

1. 第一层给错误答案
2. 第二层推翻动机
3. 第三层暴露关系隐瞒
4. 第四层让主角也有责任
5. 第五层真相改变下一步选择

### 2.6 失败升级成代价

1. 不要只让任务失败
2. 让失败损害关系、身份、资源或信念
3. 让主角亲手造成一部分后果
4. 让补救方案更昂贵

### 2.7 和解升级成真正选择

1. 先承认具体伤害
2. 再让受伤者有拒绝权
3. 让道歉者付出可见代价
4. 用新规则替代旧相处方式

升级任意桥段时，统一使用以下提示词：

```text
提示词：请把这个桥段按“<上述某条升级阶梯>”升级。输出升级前问题、五级升级链、每一级的可拍动作、最后造成的新局面。
```

## 3. 反派与压力系统库

| 压力类型 | 定义 |
| --- | --- |
| 反派压力 | 反派不是坏人标签，而是主角错误信念的外部化。他要逼主角用旧方法赢，或证明主角的新信念很天真。 |
| 制度压力 | 制度压力来自规则、流程、审批、舆论、KPI、法律和组织惯性。它最好没有单一坏人，但人人都在维护它。 |
| 家庭压力 | 家庭压力常用爱、牺牲、面子和亏欠包装控制。它的强度来自“你不听就是不孝/不懂事”。 |
| 职场压力 | 职场压力来自评价权、资源分配、背锅机制和晋升诱惑。人物在这里容易出卖原则。 |
| 疾病压力 | 疾病让时间、金钱、照顾责任和未说出口的话同时变紧。不要只当催泪工具。 |
| 贫穷压力 | 贫穷不是背景，而是每个选择的成本差异。同样的错误，对穷人更致命。 |
| 时间压力 | 倒计时必须改变决策质量，让人物无法等到完美方案。 |
| 舆论压力 | 舆论压力让人物必须在真相、体面、商业和亲密关系之间选择。 |
| 道德压力 | 道德压力来自两个正确选择互相冲突，而不是好人坏人二选一。 |

九种压力共用同一套设计方法：

- 给压力一个具体执行者或具体规则。
- 让压力每 10-15 分钟收紧一次。
- 让压力攻击主角最想保护的东西。
- 让压力逼主角暴露错误信念。
- 让第三幕解决压力的方式必须来自人物改变。

设计任意压力时，统一使用以下提示词：

```text
提示词：请为这个故事设计【某某压力】。输出压力来源、执行者、规则、三次升级、主角旧方法如何失败、第三幕如何用新选择破解。
```

## 4. Agent 工作流提示词库

| 任务 | 要求 |
| --- | --- |
| 生成故事大纲 | 输入创意后，先产出一句话故事线、主角弧光、类型判断、三幕梗概、15 节拍和关键场景 |
| 诊断大纲问题 | 先复述故事，再按结构、人物、类型、压力、关系、对白六项评分 |
| 扩写分场 | 把每个节拍拆为场景，要求每场有目标、冲突、转折、状态改变 |
| 改写对白 | 调用对白指南，先判断场景类型和人物声音，再写较长、可演、带潜台词的对白 |
| 强化人物弧光 | 调用人物弧光库，补旧伤、错误信念、代价、中点诱惑、最低谷和新行为 |
| 增加喜剧桥段 | 调用类型片库和桥段升级库，让喜剧来自人物错误方法和局面失控 |
| 增加压迫感 | 调用压力系统库，让外部压力、关系压力和时间压力同时收紧 |
| 检查三幕结构 | 调用结构指南，检查不可逆转折、中点、最低谷、第三幕选择 |
| 检查商业类型片爽点 | 调用类型片模板库，核对必备场景和类型承诺是否兑现 |
| 输出制片可读版梗概 | 把创意整理成片名、类型、卖点、人物、三幕、核心场景、预算敏感点和受众 |

执行任意任务时，统一使用以下提示词格式：

```text
你现在执行任务：【某某任务】。
请先判断应该调用哪些参考文件，再输出结果。
必须包含：问题判断、使用的规则、具体输出、下一步建议。
不要只给抽象建议，每条建议都要能落到场景、人物选择或台词。
```

## 5. 一次完整剧本医生输出模板

```text
【任务判断】用户要解决的是结构 / 人物 / 类型 / 场景 / 对白 / 改稿中的哪一类问题。
【调用资料】列出本次使用的文件和章节。
【核心诊断】最多 5 条，每条必须指出具体表现。
【优先级排序】先改什么，后改什么，为什么。
【结构修复】给出新版节拍或三幕调整。
【人物修复】给出错误信念、代价和新行为。
【场景修复】列出需要新增、删除、合并、强化的场景。
【对白修复】说明哪些对白要更克制、更压迫、更喜剧或更具体。
【可执行改写】输出一段新版大纲/分场/对白示例。
```
