# 人物原型设计库

这个文件用于在写人物弧光之前，先判断角色的原型能量、欲望、恐惧、优势、黑暗面和叙事功能。它不是性格标签库，而是帮助 Agent 把人物从“设定描述”推进到“可拍行动”的工具。

使用原则：

1. 原型不是模板。同一个原型可以出现在不同性别、阶层、职业、时代和类型片中。
2. 原型不能替代人物弧光。原型回答“这个人天然如何反应”，弧光回答“这个人在故事中如何改变”。
3. 原型不能替代关系冲突。关系回答“谁最能逼他暴露本性和改变”。
4. 正向原型和反面原型不是好人坏人的区别，而是同一套欲望在压力下是否失控。
5. 所有原型判断必须落到场景动作：他会保护谁、控制谁、逃避谁、诱惑谁、背叛谁、牺牲什么。

## 0. 人物原型设计总流程

```text
角色位置 -> 原型能量 -> 外在目标 -> 内在欲望 -> 最大恐惧 -> 失控黑暗面 -> 关系压力 -> 弧光类型 -> 可拍场景
```

### 0.1 角色设计六问

| 问题 | 用途 | 输出要求 |
| --- | --- | --- |
| 他最在乎什么 | 判断欲望来源 | 具体到人、地位、自由、秩序、爱、名声或安全 |
| 他最害怕什么 | 判断戏剧压力 | 必须能被某个事件触发 |
| 他靠什么解决问题 | 判断行动习惯 | 力量、智慧、魅力、照顾、控制、逃避、信仰或创造 |
| 别人怎么看他 | 判断外部形象 | 崇拜、依赖、害怕、误解、嫉妒、嘲笑或利用 |
| 他失控时会伤害谁 | 判断反面形态 | 伤害对象要具体，不写“伤害所有人” |
| 谁最能改变他 | 判断关系冲突 | 对手、爱侣、导师、孩子、家人、同伴或镜像敌人 |

### 0.2 原型调用顺序

```text
1. 先判断角色在故事中的功能：主角、反派、爱侣、导师、盟友、对手、镜像、过去、未来。
2. 再选择最接近的原型，不要按性别机械选择。
3. 写出正向欲望和反面失控版本。
4. 从《人物弧光与关系冲突库》中选择弧光类型。
5. 从关系库中选择最能逼出原型黑暗面的关系压力。
6. 设计三场戏：日常本性场、压力失控场、第三幕新行为场。
```

## 2. 女性主角与反面人物原型

### 2.1 阿芙洛狄忒：诱人缪斯 / 蛇蝎美人

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 带来感官活力、吸引力、创造力和情感唤醒，让沉闷世界重新有欲望 |
| 外在目标 | 获得爱情、舞台、创作机会、审美表达或被看见的位置 |
| 内在欲望 | 想证明自己的魅力不是罪，而是一种生命力 |
| 最大恐惧 | 被当成消遣、被抛弃、失去吸引力、被社会羞辱 |
| 行动习惯 | 用魅力、身体语言、审美直觉和情绪感知解决问题 |
| 正向关系 | 能让压抑型角色承认欲望，也能让控制型角色放下僵硬规则 |
| 失控形态 | 蛇蝎美人把魅力变成操控，把爱变成控制和报复 |
| 可拍场景 | 她用一次表演、设计、亲密接触或公开亮相改变全场权力关系 |

常见写烂方式：

- 只写性感，不写她的创造力、感知力和对爱的需求。
- 把她写成“诱惑男人的工具”，没有自己的目标。
- 反面化时只写恶毒，不写她为什么把被爱变成占有。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 逃避型 | 用感官和关系逃避真正承诺 |
| 控制型 | 用魅力控制他人的注意力 |
| 赎罪型 | 因过去的诱惑、背叛或伤害寻求修复 |

### 2.2 阿尔忒弥斯：亚马逊女子 / 蛇发女妖

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 独立、行动、竞技、女性联盟、边界感 |
| 外在目标 | 赢得比赛、完成任务、逃离控制、证明自己不需要庇护 |
| 内在欲望 | 想拥有不被驯服的人生 |
| 最大恐惧 | 被支配、被羞辱、被迫依赖、身体或自由被占有 |
| 行动习惯 | 直接行动、竞争、训练、离开、战斗 |
| 正向关系 | 能教弱势角色建立边界，也能逼团队学会尊重 |
| 失控形态 | 蛇发女妖把独立变成仇恨，把保护自己变成攻击一切靠近的人 |
| 可拍场景 | 她拒绝被安排的人生，当众打破规则，但也因此失去一个盟友 |

常见写烂方式：

- 只写“女强”，不写她害怕被伤害和被控制。
- 让她全程无敌，缺少必须信任他人的时刻。
- 把愤怒写成性格，而不是由旧伤触发的防御。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 控制型 | 过度依赖独立和控制边界 |
| 复仇型 | 被伤害后把自由变成反击 |
| 天才受困型 | 在高压竞技或制度中证明自我 |

### 2.3 雅典娜：父亲的女儿 / 背后中伤者

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 理性、战略、事业心、规则理解、权力系统内的生存能力 |
| 外在目标 | 获得职位、完成方案、进入核心圈、被权威承认 |
| 内在欲望 | 想证明自己足够优秀，配得上权力和尊重 |
| 最大恐惧 | 被情绪拖累、被视为软弱、被排除在男性权力结构之外 |
| 行动习惯 | 分析、规划、结盟、压抑情绪、向强者学习 |
| 正向关系 | 能帮混乱型角色建立策略，也能帮团队冷静拆局 |
| 失控形态 | 背后中伤者用理性包装野心，暗中踩掉威胁者 |
| 可拍场景 | 她在会议上用一个精准判断赢得权力，却牺牲了一个信任她的人 |

常见写烂方式：

- 只写聪明，不写她对权威认可的饥饿。
- 让她完全没有情感需求，变成冷冰冰的工具人。
- 反派化时只写职场宫斗，不写她害怕被踢出系统。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 野心型 | 成功欲和被认可需求强 |
| 控制型 | 依靠计划和权力降低恐惧 |
| 失败者翻身型 | 从被低估到进入核心权力 |

### 2.4 得墨忒耳：养育者 / 过度控制的母亲

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 照顾、修复、稳定、食物、家庭、身体和情感安全 |
| 外在目标 | 保护孩子、维持家庭、救助弱者、建立安全空间 |
| 内在欲望 | 想确认自己被需要，自己的爱有价值 |
| 最大恐惧 | 被孩子离开、被遗忘、自己不再有用 |
| 行动习惯 | 照顾、牺牲、安排、替别人承担后果 |
| 正向关系 | 能让孤独角色重新相信归属，也能让团队有情感根基 |
| 失控形态 | 过度控制的母亲把照顾变成占有，把牺牲变成道德勒索 |
| 可拍场景 | 她以“为你好”为名替别人做决定，结果让对方失去重要机会 |

常见写烂方式：

- 只写善良母性，不写她也需要权力和被需要感。
- 让牺牲变成免死金牌，不让她承担控制的后果。
- 把母亲角色写成背景，而不是剧情压力源。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 控制型 | 爱和安排难以分开 |
| 亲情修复型 | 需要承认亲密中的旧账 |
| 赎罪型 | 用照顾偿还过去亏欠 |

### 2.5 赫拉：女族长 / 被嘲笑的女人

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 婚姻秩序、家族体面、资源管理、公开身份和承诺 |
| 外在目标 | 维护婚姻、家族、名誉、组织稳定或继承秩序 |
| 内在欲望 | 想拥有不可替代的位置和被承认的身份 |
| 最大恐惧 | 被背叛、被公开羞辱、被年轻者取代、失去体面 |
| 行动习惯 | 管理关系、维护仪式、控制社交秩序、清除威胁 |
| 正向关系 | 能让漂泊型角色学会承诺，也能给混乱家庭建立边界 |
| 失控形态 | 被嘲笑的女人把维护体面变成报复和羞辱他人 |
| 可拍场景 | 她在公开场合维持完美秩序，私下用极端手段挽回尊严 |

常见写烂方式：

- 只写“正宫斗小三”，不写身份、承诺和社会评价的压力。
- 把她的体面写成虚荣，忽略她对秩序的真实贡献。
- 反面化时只写歇斯底里，不写羞辱如何击穿她的自我。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 控制型 | 秩序和体面容易变成统治 |
| 复仇型 | 被背叛后寻求尊严修复 |
| 亲情修复型 | 家族秩序与个人选择冲突 |

### 2.6 赫斯提亚：神秘主义者 / 背叛者

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 内在宁静、精神洞察、独处、信仰、神秘感 |
| 外在目标 | 守护秘密、完成精神任务、离开纷扰、寻找真相 |
| 内在欲望 | 想保留完整的内心世界，不被外界粗暴占有 |
| 最大恐惧 | 被迫暴露、被卷入人群、精神信念被摧毁 |
| 行动习惯 | 沉默、观察、抽离、用直觉判断 |
| 正向关系 | 能让行动型角色停下来面对内心，也能提供精神方向 |
| 失控形态 | 背叛者用抽离和神秘感逃避责任，关键时刻抛弃关系 |
| 可拍场景 | 她掌握真相却迟迟不说，因为说出口会破坏自己的安全世界 |

常见写烂方式：

- 只写神秘，不写她为什么需要孤独。
- 让她永远像旁白，缺少必须行动的时刻。
- 把背叛写成剧情反转，而不是长期逃避关系的结果。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 逃避型 | 以精神世界回避现实责任 |
| 赎罪型 | 因沉默或背离造成伤害后承担 |
| 控制型 | 用秘密和距离控制他人接近 |

### 2.7 伊西斯：女救世主 / 毁灭者

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 拯救、疗愈、复原、公共责任、凝聚群体 |
| 外在目标 | 救人、修复系统、阻止灾难、让破碎者重生 |
| 内在欲望 | 想证明痛苦可以被修复，牺牲有意义 |
| 最大恐惧 | 无法救回重要之人、善意无效、世界不可修复 |
| 行动习惯 | 承担、疗愈、组织、牺牲、把别人的痛苦当成自己的任务 |
| 正向关系 | 能让自私角色学会承担，也能让绝望群体重新行动 |
| 失控形态 | 毁灭者为了所谓更大善，允许伤害个体或摧毁局部 |
| 可拍场景 | 她决定牺牲少数人拯救多数人，故事逼她面对这个决定的代价 |

常见写烂方式：

- 只写圣母，不写她也会被使命吞噬。
- 让拯救变成万能能力，缺少必须选择谁不能被救的痛苦。
- 反面化时只写残忍，不写她仍相信自己是在救世界。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 赎罪型 | 用拯救偿还过去失败 |
| 控制型 | 以拯救名义替别人决定 |
| 野心型 | 公共使命与个人名望纠缠 |

### 2.8 珀耳塞福涅：少女 / 问题少女

| 内在欲望 | 想在安全和自由之间找到自己的声音 |
| 最大恐惧 | 被抛弃、做错选择、失去保护、真正长大 |
| 行动习惯 | 讨好、跟随、试探、撒娇、逃进幻想 |

| 亲情修复型 | 与控制型家庭产生强冲突 |

## 3. 男性主角与反面人物原型

### 3.1 阿波罗：商人 / 背叛者

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 秩序、效率、文明、商业判断、规则和计划 |
| 外在目标 | 成功、晋升、交易、建立稳定系统 |
| 内在欲望 | 想证明自己能在规则中赢，并获得体面尊重 |
| 最大恐惧 | 混乱、失败、情绪失控、被拒绝、规则崩塌 |
| 行动习惯 | 算账、谈判、规训、制定流程、压抑冲动 |
| 正向关系 | 能让混乱团队提高效率，也能让理想落地 |
| 失控形态 | 背叛者为了事业或组织利益牺牲朋友、爱人和原则 |
| 可拍场景 | 他在合同、会议或危机选择中出卖一个信任他的人 |

常见写烂方式：

- 只写精英冷血，不写他为什么需要秩序。
- 让背叛只为钱，缺少“我是在保护系统”的自我辩解。
- 缺少混乱事件逼他暴露真正价值排序。

适配弧光：

| 弧光 | 适配原因 |
| --- | --- |
| 野心型 | 成功和身份焦虑强 |
| 控制型 | 用规则抵抗混乱 |
| 赎罪型 | 背叛后承担后果 |

### 3.2 阿瑞斯：保护者 / 角斗士

| 维度 | 写作要求 |
| --- | --- |
| 正向功能 | 行动、勇气、身体保护、即时反应、直面危险 |
| 外在目标 | 救人、复仇、打败威胁、护送或守住阵地 |
| 内在欲望 | 想证明自己有力量保护所爱 |
| 最大恐惧 | 无力、懦弱、无法阻止伤害发生 |
| 行动习惯 | 先冲上去，再思考后果 |

## 5. 配角原型库

配角不是填空角色。每个配角都应该至少承担一种压力功能：帮助、误导、阻碍、照出缺点、提醒过去、指向未来。

### 5.1 朋友类配角

| 配角原型 | 正向功能 | 制造麻烦的方式 | 使用场景 |
| --- | --- | --- | --- |
| 智者 | 提供经验、规则和训练 | 保留信息、拒绝帮助、用艰难课程逼主角成长 | 主角进入新世界、学习新能力、遭遇规则门槛 |
| 指导者 | 更贴近主角的实操老师 | 过度参与、嫉妒主角成长、把主角当成自己未完成梦想 | 职场、竞技、警匪、训练、行业片 |
| 挚友 | 情感支持和日常镜子 | 好心办坏事、害怕主角改变、嫉妒新关系 | 爱情、成长、喜剧、公路、都市故事 |
| 爱侣 | 安全感、亲密、情感目标 | 误会、最后通牒、被抓走、要求承诺 | 爱情线、B 故事、主角软肋、结尾情感兑现 |

朋友类配角调用模板：

```text
请为这个主角补一个【朋友类配角】。
输出：配角类型、他能给主角什么、他会如何好心制造麻烦、他在哪一场戏逼主角改变、他在结尾是否留下。
```

### 5.2 对手类配角

| 配角原型 | 正向功能 | 制造麻烦的方式 | 使用场景 |
| --- | --- | --- | --- |
| 逗乐者 | 缓解压力、制造喜剧节奏 | 用玩笑打断关键时刻、泄露秘密、让严肃问题变形 | 喜剧、群戏、办公室、家庭聚会 |
| 小丑 | 纯真、笨拙、意外变量 | 帮倒忙、损坏道具、在错误时间出现 | 冒险、动作喜剧、儿童/家庭片 |

| 调查者 | 提问、怀疑、程序压力 | 让主角反复解释、拖慢行动、扩大疑虑 | 悬疑、制度、家庭伦理、社会压力 |
| 悲观者 | 提醒风险和失败可能 | 否定方案、削弱信心、劝主角不行动 | 灾难、历史、创业、冒险 |

## 6. 女性旅程与男性旅程

这里的“女性旅程/男性旅程”不是按角色性别强制划分，而是两种不同的变化路径。女性旅程更偏内在觉醒和重生，男性旅程更偏外部挑战、盟友、工具、死亡关口和最终选择。

### 6.1 女性旅程九阶段

| 阶段 | 剧本功能 | 场景写法 | 诊断问题 |
| --- | --- | --- | --- |
| 1. 对完美世界的幻想 | 主角相信现状安全 | 展示她如何忍受限制并合理化 | 她为什么宁愿不站起来 |
| 2. 背叛或领悟 | 安全幻觉破裂 | 一个事件让她看见规则并不保护她 | 谁背叛了她的信任 |
| 3. 觉醒 | 准备离开旧身份 | 她第一次说出或做出不同选择 | 她是否已经无法回到原状 |
| 4. 下降 | 穿过审判之门 | 她进入更危险、更真实的世界 | 她失去了哪层保护 |
| 5. 风暴之眼 | 暂时平静和自我确认 | 她短暂体验新自我 | 这个平静为什么危险 |
| 6. 死亡 | 失去一切 | 旧身份、旧关系或旧幻想崩塌 | 哪个错误信念被击穿 |
| 7. 支持 | 接受帮助和新连接 | 她不再独自硬撑 | 谁证明她可以被支持 |
| 8. 重生 | 真相时刻 | 她用新自我做不可逆选择 | 她做了开场绝不会做的事吗 |
| 9. 周而复始 | 回到世界但已不同 | 她重返旧世界或建立新秩序 | 世界如何承认她的变化 |

适合任务：

- 女性成长片、亲情片、爱情片、心理片、被压抑者觉醒、身份寻找。
- 也适合男性角色的内在觉醒故事，例如长期压抑、情感失语、身份被规训的角色。

### 6.2 男性旅程九阶段

| 阶段 | 剧本功能 | 场景写法 | 诊断问题 |
| --- | --- | --- | --- |
| 1. 完美世界 | 主角相信自己能赢 | 展示目标、能力、外部期待 | 他为什么相信自己准备好了 |
| 2. 朋友与敌人 | 建立队伍和阻碍 | 让盟友、对手、规则一起出现 | 谁会帮他，谁会拖住他 |
| 3. 召唤 | 目标正式压到眼前 | 任务、挑战、危机或机会出现 | 他能拒绝吗，拒绝代价是什么 |
| 4. 小成功 | 初步胜利 | 他用旧方法赢一次 | 这个胜利隐藏了什么问题 |
| 5. 邀请 | 更大的目标或诱惑 | 成功后被邀请进入更危险层级 | 他被什么名誉/权力/爱诱惑 |
| 6. 考验 | 能力和团队受压 | 连续障碍消耗资源和信心 | 哪个缺陷开始反噬 |
| 7. 死亡：十字路口 | 失败或象征性死亡 | 他必须决定放弃旧身份还是固执到底 | 他失去了什么才会醒 |
| 8. 觉醒或叛逆 | 抓住或拒绝改变机会 | 他承认真相，或更极端地坚持旧方法 | 他选择新自我还是旧权力 |
| 9. 成功或失败 | 最终结果 | 成功必须有内在代价，失败必须有主题原因 | 结局证明了什么价值观 |

适合任务：

- 冒险、动作、传记、创业、竞技、战争、任务片。
- 也适合女性角色的外部挑战故事，例如行业闯关、复仇、夺权、竞技。

### 6.3 两种旅程的选择

| 判断问题 | 更适合女性旅程 | 更适合男性旅程 |
| --- | --- | --- |
| 故事核心 | 从内在束缚走向完整 | 从外部挑战走向胜败和身份选择 |
| 主角问题 | 不敢成为自己 | 以为旧身份足够赢 |
| 中点重点 | 看见真实自我 | 获得更大目标或诱惑 |
| 低谷重点 | 旧幻想死亡 | 旧方法失败 |
| 结尾重点 | 重生和回到世界 | 成功/失败体现是否觉醒 |

## 8. 人物原型诊断模板

### 8.1 设计主角

```text
请按《人物原型设计库》为这个故事设计主角。
输出：
1. 最适合的 1-2 个原型候选。
2. 最终选择的主原型和原因。
3. 外在目标、内在欲望、最大恐惧。
4. 正向能力和失控黑暗面。
5. 三个可拍场景：日常本性、压力失控、第三幕新行为。
6. 推荐衔接《人物弧光与关系冲突库》的弧光类型和关系压力。
```

### 8.2 设计反派

```text
请按《人物原型设计库》为这个故事设计反派。
输出：
1. 反派对应的反面原型。
2. 他相信自己为什么是对的。
3. 他和主角共享的欲望或恐惧。
4. 他如何把正向能力用成伤害。
5. 三次压力升级：诱惑主角、伤害关系、逼出主题选择。
6. 结尾主角必须证明自己和他哪里不同。
```

### 8.3 补配角

```text
请按《人物原型设计库》补全配角系统。
输出：
1. 朋友类配角：智者/指导者/挚友/爱侣中选 1-2 个。
2. 对手类配角：逗乐者/小丑/劲敌/调查者/悲观者/超能力者中选 1-2 个。
3. 象征类配角：影子/迷失的灵魂/翻版中选 1 个。
4. 每个配角的目标、与主角旧账、制造麻烦的场景、结尾功能。
```

### 8.4 诊断人物扁平

```text
请按《人物原型设计库》诊断这个人物为什么扁平。
输出：
1. 当前人物像哪个原型，但缺了哪一维。
2. 缺少的是：欲望 / 恐惧 / 行动习惯 / 黑暗面 / 他人眼光 / 关系压力。
3. 给出三个补强场景。
4. 说明应接入《人物弧光与关系冲突库》的哪种弧光。
```

### 8.5 重建人物关系网

```text
请按《人物原型设计库》重建这个故事的人物关系网。
输出：
1. 主角原型。
2. 反派或镜像人物原型。
3. 爱侣/导师/盟友/对手/象征角色的功能分配。
4. 每个人如何逼主角暴露恐惧。
5. 每个人在第三幕留下、牺牲、背叛或改变的功能。
```

## 9. 使用禁区

1. 不要把原型当成性别模板。女性角色可以走男性旅程，男性角色也可以走女性旅程。
2. 不要让角色只代表一种抽象品质。每个角色都要有自己的具体目标。
3. 不要把反面原型写成纯恶。反面原型必须相信自己的行为有理由。
4. 不要让配角只提供信息。配角必须制造麻烦、诱惑、误导或照出主角缺陷。
5. 不要用原型替代场景。所有判断最后都要变成可拍事件。

```text
【失控黑暗面】
【关系压力】

【接入人物弧光】
```
