## 1. 尴尬喜剧

**核心机制：角色试图维持体面，但现场不断暴露他不体面。**

适合：职场会议、相亲饭局家庭聚会、面试试镜路演、被当众误会、小谎必须继续圆。

对白目标：让角色越解释越糟；让旁观者逐渐意识到真相；让角色的自尊变成笑点来源。

常用句型：

```text
我不是那个意思，我的意思比那个更复杂。
这件事如果单独看，确实很奇怪。
我可以解释，但解释之前我需要你先降低期待。
你们现在看到的是一个过程，不是结果。
```

升级路径：

```text
小失误
被人注意
角色否认
否认制造更大漏洞
旁观者补刀
角色加倍伪装
体面彻底崩塌
```

写作注意：

1. 尴尬喜剧不要让角色主动搞笑，要让他认真自救。
2. 旁观者越平静，主角越狼狈。
3. 角色说得越正式，内容越荒唐，喜剧效果越强。

原创示例：

```text
A：你刚才叫错了董事长的名字。
B：不算叫错。我只是用了他未来可能会喜欢的名字。
A：他姓陈。
B：人是会成长的。
A：姓氏一般不靠成长解决。
B：所以我才说“未来可能”。
```

## 2. 身份错位喜剧

**核心机制：角色被误认为另一种身份，他为了利益、恐惧或虚荣暂时不纠正。**

适合：小人物误入高端场合、骗子装专家、外行被迫讲专业话、仇人被迫扮朋友、普通人被当成权威。

对白目标：让角色用模糊话术拖延；让懂行的人提出越来越具体的问题；让错误知识制造笑点和危机。

常用策略：

| 策略 | 台词表现 |
|---|---|
| 抽象化 | “这取决于底层逻辑。” |
| 反问 | “你希望它停留在哪个层面？” |
| 借势 | “这个问题刚好也是国际上争议最大的部分。” |
| 转移责任 | “我需要先听听你们内部怎么定义它。” |

原创示例：

```text
专家：你怎么看这套算法的训练集偏差？
骗子：我首先反对用“偏差”这个词。
专家：那你用什么词？
骗子：人类痕迹。
专家：所以你没看过训练集。
骗子：我尊重它的隐私。
```

## 3. 职场互损喜剧

**核心机制：团队成员在共同危机中互相推锅、拆台、争夺聪明人位置。**

适合：创业团队、编剧室项目组办公室、路演前夜、技术事故、甲方临时改需求。

对白目标：每个人都想显得有用；每个人都在证明别人更没用；笑点来自专业话术和低级人性冲突。

角色分工：

| 角色 | 说话方式 |
|---|---|
| 自恋领导 | 把失败包装成愿景 |
| 技术专家 | 纠正细节，但忽略人情 |
| 焦虑执行者 | 试图回到问题本身 |
| 摸鱼者 | 用玩笑逃避责任 |
| 旁观补刀者 | 用短句总结尴尬 |

原创示例：

```text
领导：我们不是延期，我们是在延长用户期待周期。
执行：用户已经退款了。
技术：严格说，他们退款的是上一个版本的期待。
摸鱼者：那我们至少在期待管理上实现了闭环。
执行：闭环的意思不是把门从外面锁上。
```

## 4. 黑色幽默

**核心机制：严重事件被角色用过度日常、过度冷静或过度礼貌的方式处理。**

适合：犯罪黑帮荒诞社会事件、医院葬礼审判事故现场、角色已习惯危险或腐败、严肃制度与荒唐人性碰撞。

对白目标：让危险和日常并置；让角色的冷静暴露世界荒诞；让笑点背后有不安。

常用技巧：

1. 把暴力当流程。
2. 把灾难当行政问题。
3. 把道德崩坏说成效率优化。
4. 让角色只关心微不足道的小事。

原创示例：

```text
A：他还在后备箱里。
B：我知道。我问的是发票在哪。
A：现在是关心发票的时候吗？
B：如果我们连报销都做不好，那这件事就真的没有任何专业性了。
```

## 5. 嘴炮对决

**核心机制：两个人通过语言争夺地位、智力优势和情绪控制权。**

适合：敌人初次见面、谈判前互相试探、恋人或前任互相防御、职场高手交锋、喜剧双人对打。

对白目标：让每句话都试图改变地位；让攻击越来越精准；让角色在语言上赢一小步、输一小步。

常用结构：

```text
挑衅
反讽
纠正
上纲
拆穿
反拆穿
短暂停顿
更私人化的一击
```

原创示例：

```text
A：你还是这么喜欢迟到。
B：你还是这么喜欢把等待包装成受害。
A：我至少真的等了。
B：是，你在这方面一直很有天赋。什么都不做，然后要求别人感动。
```

## 6. 审讯压迫

**核心机制：问题逐步收窄，让对方从解释变成自我暴露。**

适合：警察审讯、老板盘问下属、家长质问孩子、情侣追问背叛、反派套取信息。

对白目标：让被审者先承认小事实；用小事实制造矛盾；逼对方在“说谎”和“承认更大问题”之间选择。

提问方式：

| 问法 | 作用 |
|---|---|
| 封闭问题 | 控制对方回答范围 |
| 时间问题 | 找出漏洞 |
| 细节问题 | 增加编造成本 |
| 重复问题 | 检查答案稳定性 |
| 假设问题 | 诱导对方暴露真实立场 |

原创示例：

```text
A：你几点离开办公室？
B：九点半。
A：电梯记录是九点四十七。
B：我可能记错了。
A：你记错了十七分钟，还是记错了你跟谁一起下楼？
```

## 7. 师徒羞辱压迫

**核心机制：强者把“培养”包装成羞辱，把认可变成控制。**

适合：艺术训练、体育军队职场导师、天才与权威的对抗、主角渴望被认可。

对白目标：让弱者为了认可不断退让；让强者精准命中弱者羞耻点；让观众分不清这是训练还是虐待。

常用话术：

```text
我骂你，是因为你还有被骂的价值。
你不是不够努力，你是努力得太像普通人。
别急着委屈，委屈说明你还有闲心保护自己。
你想要掌声，还是想要资格？
```

场景流程：

```text
先给小认可
立刻否定
指出具体缺陷
把技术问题上升为人格问题
让对方做更痛苦的选择
用沉默等待对方服从
```

## 8. 家庭控制压迫

**核心机制：亲情语言被用来控制、绑架、定义对方。**

适合：父母反对子女选择、家族利益冲突、婚姻谈判、饭桌争吵、亲人揭旧伤。

对白目标：表面谈现实问题，底层谈归属和亏欠；让角色用“为你好”表达控制；让被控制者既愤怒又无法彻底切断。

常用句型：

```text
我不是反对你，我是比你更知道后果。
你可以不听，但你别说这个家没提醒过你。
我们不是要你还债，我们只是想知道这些年算什么。
你现在翅膀硬了，所以连关心都听不懂了。
```

原创示例：

```text
母亲：我没有拦你。
女儿：你把身份证放哪了？
母亲：我只是怕你走得太急，忘了自己是谁。
女儿：我就是在这个家里才总忘。
```

## 9. 职场权力压迫

**核心机制：上级把命令说成建议，把服从说成成长，把剥削说成机会。**

适合：加班谈话、绩效面谈、甲方压价、投资人控制创业者、大公司收购小团队。

对白目标：让下位者争取解释权；让上位者不断重定义问题；让台词暴露组织权力，而不只是个人坏。

常用话术：

```text
这不是要求，这是一次信任。
我没有否定你的能力，我是在保护你的上限。
你可以拒绝，只是团队会重新评估你的位置。
成熟的人不会把压力理解成伤害。
```

原创示例：

```text
上级：周末这个会你最好参加。
下属：最好，还是必须？
上级：我不喜欢把成长说得那么硬。
下属：那我可以不成长吗？
上级：你当然可以。只是公司也会尊重你的选择。
```

## 10. 亲密关系冷暴力

**核心机制：一方不直接攻击，而是用沉默、敷衍、理性和延迟反应惩罚对方。**

适合：情侣争执、婚姻疲惫期、前任重逢、一方背叛后假装平静。

对白目标：让表面平静比吵架更伤人；让对方不断请求回应；让沉默变成明确动作。

常用方式：

| 方式 | 表现 |
|---|---|
| 延迟回答 | 对方问情绪，他回生活安排 |
| 降级问题 | 把背叛说成沟通误差 |
| 理性切割 | 用逻辑回避感情 |
| 礼貌撤退 | “你说得对”但不再靠近 |

原创示例：

```text
A：你能不能看着我说话？
B：我在听。
A：你看着杯子听？
B：杯子至少没要求我马上给出正确情绪。
```

## 11. 克制告白

**核心机制：角色不直接说爱，而是通过小承诺、小记忆、小退让接近真心。**

适合：朋友变恋人、离别前夜、久别重逢、战争危机病房中的亲密、两个嘴硬的人互相试探。

对白目标：不说满；用具体物件承载情绪；让观众听见没说出口的话。

可用物件：

1. 伞、钥匙、车票、旧照片。
2. 没喝完的咖啡。
3. 忘在对方家的衣服。
4. 一个只有两人懂的玩笑。
5. 一句重复多次但意义变化的话。

原创示例：

```text
A：你这次走，猫怎么办？
B：你不是不喜欢它吗？
A：它抓坏了我的沙发。
B：所以？
A：所以它知道怎么回家。
```

## 12. 破裂告别

**核心机制：角色已经决定离开，但仍在等待对方给出最后一个理由。**

适合：情侣分手、搭档散伙、主角离开家庭、朋友决裂、师徒分道扬镳。

对白目标：不让角色直接总结关系；用收拾东西、退还物品、删除称呼完成告别；让最后一句话具有不可逆性。

原创示例：

```text
A：钥匙放桌上了。
B：你可以留着。
A：不用。我以后敲门。
B：你以前也敲。
A：以前我等你开。
```

## 13. 旧友重逢

**核心机制：两个人共享过去，但现在站在不同位置，熟悉感和陌生感同时存在。**

适合：多年未见的朋友、旧同事旧战友、前任、童年伙伴阶层分化。

对白目标：先用旧梗建立亲密；让旧梗失效，暴露变化；让过去成为武器或诱惑。

常用句型：

```text
你以前不是这么说话的。
你以前也不是这么听话的。
我差点没认出来你。
你认出来了，只是不想承认。
```

## 14. 阶层碰撞

**核心机制：双方对钱、时间、风险和尊严的理解不同。**

适合：富人和服务者、投资人和创业者、城市与乡村、房东与租客、家庭婚恋中的门第冲突。

对白目标：不直接喊阶层口号；通过具体金额、空间、排队、等待、称呼体现差异；让一方的随口话成为另一方的伤口。

原创示例：

```text
A：才三千块，你至于吗？
B：你说“才”的时候，我已经知道这事没法谈了。
A：我不是那个意思。
B：我知道。你只是从来不用知道。
```

## 15. 道德困境

**核心机制：每个选择都有代价，角色通过对白暴露自己的价值排序。**

适合：是否举报亲人、是否牺牲少数救多数、是否公开真相伤害无辜者、是否为了成功背叛原则。

对白目标：双方都不能完全正确；台词要围绕代价，而不是抽象道德；让角色承认自己选择保护什么。

常用问题：

```text
你救的是谁，放弃的又是谁？
如果真相只能伤害活着的人，你还要说吗？
你说这是原则，还是你不敢承担例外？
```

## 16. 反派诱惑

**核心机制：反派不是威胁主角，而是说出主角不愿承认的欲望。**

适合：英雄与反派第一次深谈、黑帮招募、权力交易、堕落前夜。

对白目标：让反派理解主角；让诱惑看起来有道理；让主角拒绝时付出代价。

原创示例：

```text
反派：你不是讨厌权力。
主角：我讨厌滥用权力的人。
反派：不。你讨厌他们用得不够漂亮。
主角：你不了解我。
反派：我了解你每次看见无能者坐在高位时的表情。
```

## 17. 反派审判

**核心机制：反派把自己放在审判者位置，逼主角承认世界本身不干净。**

适合：连环案件、复仇者与执法者、极端理想主义者、主题高潮。

对白目标：反派有一套完整逻辑；主角不能简单用“你是坏人”反驳；对白要逼出主题问题。

常用句型：

```text
你维护的不是正义，是秩序。
你恨我，不是因为我错，是因为我把你们藏起来的规则说出来了。
你们每天都在选择谁可以被牺牲，只是讨厌我把名单念出来。
```

## 18. 悬疑误导

**核心机制：角色说的每句话都可以有第二解释。**

适合：侦探询问证人、记忆不可靠、亲密关系中的谎言、犯罪团伙互相试探。

对白目标：给出线索，但不解释线索；让观众误以为重点在 A，实际在 B；让真相揭示后，旧对白能被重新理解。

原创示例：

```text
侦探：你说你没进过书房。
证人：我说我没碰过那封信。
侦探：我还没提信。
证人：你迟早会提。
```

## 19. 真相揭示

**核心机制：不是公布新信息，而是让旧信息改意义。**

适合：反转结尾、亲人秘密揭开、案件真相、主角发现自己误会了某人。

对白目标：少解释，多让角色反应；用一个旧细节完成反转；真相揭示后必须改变关系或选择。

写法：

```text
不要说：“其实当年救你的人是我。”
可以说：“你手上那道疤不是火烧的。是我把你从窗户推下去时，玻璃划的。”
```

## 20. 信息训练

**核心机制：设定通过训练、失败、演示进入对白。**

适合：科幻规则、魔法系统、间谍装备、新人入行、医疗法律技术流程。

对白目标：让新手犯错；让错误造成后果；让导师用后果解释规则。

原创示例：

```text
新人：我只是多按了一次。
导师：所以门锁死了。
新人：这个按钮不是确认？
导师：第一次是确认，第二次是告诉系统你被胁迫。
新人：那现在系统以为我被胁迫？
导师：不。它以为我们两个都没用了。
```

## 21. 技术争论

**核心机制：表面争技术方案，实际争控制权、路线和自尊。**

适合：创业团队、科研组、黑客场景、工程事故复盘。

对白目标：术语要有现实后果；技术分歧要映射人物关系；不懂的人要承担观众入口。

原创示例：

```text
A：你把缓存关了？
B：我把错误藏起来的地方关了。
C：说人话。
A：他为了让系统诚实，先让它瘫痪。
B：瘫痪至少不会骗人。
```

## 22. 危机短句

**核心机制：危险迫使台词缩短，所有废话都被压力删掉。**

适合：枪战追车逃亡、手术爆炸灾难、角色必须立刻选择。

对白目标：短句承载动作；用一两个私人词显示关系；不解释观众能看到的事。

原创示例：

```text
A：左边。
B：堵了。
A：撞。
B：这是你的车。
A：现在是我们的遗物。撞。
```

## 23. 牺牲前对白

**核心机制：角色知道自己可能回不来，但不直接说遗言。**

适合：战争灾难超级英雄、父母保护孩子、搭档分离、最后一搏。

对白目标：让角色假装这是普通任务；用托付小事表达生死；让另一方意识到但不愿承认。

原创示例：

```text
A：车钥匙在第二个抽屉。
B：你回来自己拿。
A：我怕你又找不到。
B：那你写张纸。
A：我写了。还有三张。
```

## 24. 群体投票

**核心机制：每个人的发言既是观点，也是站队。**

适合：陪审团董事会家庭会议、团队是否放弃某人、是否公开秘密。

对白目标：快速呈现多个立场；让沉默者成为关键；让投票前后的关系改变。

写法：

```text
不要让每个人长篇陈述。
让他们用一句话暴露利益：
“我投反对，不是因为他无辜，是因为我们还用得上他。”
“我弃权，因为我不想替你们的勇敢买单。”
```

## 25. 饭桌群戏

**核心机制：饭桌表面维持秩序，台词底层不断破坏秩序。**

适合：家庭冲突、阶层碰撞、婚恋关系公开、秘密即将爆出。

对白目标：用夹菜、倒酒、座位、称呼制造权力；让别人用礼貌话逼迫主角；让真正的问题被小事引爆。

原创示例：

```text
父亲：多吃点鱼。
女儿：我不吃鱼。
父亲：你小时候爱吃。
女儿：我小时候还爱听你说话。
母亲：吃饭呢。
女儿：我就是等大家嘴里有东西的时候说。
```

## 26. 公众场合暗战

**核心机制：角色不能当众撕破脸，只能用礼貌、暗示和双关攻击。**

适合：颁奖礼酒会发布会、婚礼葬礼、记者会直播、商务饭局。

对白目标：每句话表面无害，实际有刺；旁观者未必听懂，当事人一定听懂；场面越体面，攻击越准确。

原创示例：

```text
A：听说你最近很忙。
B：是，比你消息里听到的还忙。
A：那真好，忙的人通常没时间犯错。
B：也没时间替别人收拾。
```

## 27. 撒谎圆谎

**核心机制：角色为了保护秘密，不断用更复杂的谎解释前一个谎。**

适合：喜剧误会、悬疑审问、情感背叛、骗局进行中。

对白目标：谎言越来越具体；具体细节增加破绽；让角色在自保和伤人之间选择。

原创示例：

```text
A：你说你在医院。
B：对。
A：哪家医院？
B：那种不希望病人被打扰的医院。
A：名字。
B：它们通常不靠名字治病。
```

## 28. 请求原谅

**核心机制：道歉者想减轻代价，被伤害者想确认对方是否真正理解伤害。**

适合：背叛后、父母与子女、搭档失误、主角犯错后的修复。

对白目标：不要只说“对不起”；让道歉者说出具体伤害；让被伤害者拒绝快速和解。

弱道歉：

```text
对不起，我不是故意的。
```

强道歉：

```text
我知道我让你一个人承担了后果，然后回来要求你理解我的难处。
```

## 29. 失败后自嘲

**核心机制：角色用幽默保护自尊，但幽默里有真实疼痛。**

适合：比赛失败、路演失败、表白失败、主角被打回原点。

对白目标：让角色不直接哭诉；让笑话暴露伤口；让旁人决定要不要戳破。

原创示例：

```text
A：至少他们没把我们赶出去。
B：他们是等电梯的时候顺手把我们带出去的。
A：这也算一种陪伴。
B：是，失败有时很注重礼仪。
```

## 30. 主题辩论

**核心机制：角色不是讲主题，而是用自己的命运和利益争主题。**

适合：高潮前夜、主角与反派对谈、家庭重大选择、社会议题剧。

对白目标：不让角色说论文；每个观点都绑定具体代价；让争论改变角色行动。

写法：

```text
不要写：“自由比安全重要。”
可以写：“你说安全的时候，锁总是在别人门上。”
```
