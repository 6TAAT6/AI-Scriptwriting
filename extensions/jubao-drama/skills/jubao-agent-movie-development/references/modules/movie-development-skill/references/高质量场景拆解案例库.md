## 0. 场景拆解总公式

```text
场景目标 + 权力位置 + 信息差 + 冲突升级 + 台词转折 + 关系变化 + 故事状态改变 = 可复用场景
```

各类场景的核心任务相同：让观众在一个明确情境里看到局面变化，而不是听人物解释变化。

## 1. 通用场景机制检查表

下表是所有经典场景共用的机制框架，适用于第 3 节列出的全部 48 个案例。各案例之间唯一的差异在于"这场戏的目标"——即用什么具体事件让故事进入新阶段；其余机制项的检验标准完全一致。拆解或写作任何一场戏时，逐项对照：

| 机制项 | 检验标准 |
| --- | --- |
| 这场戏的目标 | 通过一个具体事件让事件或关系进入新阶段（每个案例的具体事件见第 3 节索引）。 |
| 谁掌握权力 | 表面掌权者通常拥有资源、规则、信息或暴力；真正的戏剧张力来自权力在场景中发生转移。 |
| 信息差在哪里 | 至少有一方知道另一方不知道的事实，或观众比人物多/少知道一层信息。 |
| 冲突如何升级 | 从具体目标受阻开始，升级到身份、尊严、价值观或生死代价。 |
| 台词如何转折 | 第一轮说事，第二轮说人，第三轮说出真正不能承认的恐惧；关键台词应改变对方策略。 |
| 角色关系发生了什么变化 | 场景结束后，信任、控制、亏欠、依赖或敌意至少改变一项。 |
| 场景结束后故事状态改变了什么 | 主角获得新目标、新阻力、新代价或新真相，下一场不能回到原状。 |
| 可复用到国产/短剧/电影桥段 | 可转译为饭桌、病房、办公室、车内、派出所、婚礼、直播现场、评审会、债务谈判等高压空间。 |

## 5. 场景案例使用警报

- 如果只复述经典电影剧情，说明没有完成拆解。
- 如果场景结束后人物关系和故事状态都没变，说明这不是有效场景。
- 如果案例迁移后只剩相同设定，说明没有抓住机制。
- 如果所有冲突都靠大喊，说明权力、信息差和具体目标没有设计好。

## 6. 场景拆解规则、常见问题与修复方法

### 6.1 场景拆解规则

```text
1. 先判断场景功能，不先判断台词好不好。
2. 每场戏必须有一个人想得到某个具体结果。
3. 场景里的权力必须能被看见：谁有钱、证据、身份、地位、时间、武器、规则、情感筹码。
4. 信息差必须影响人物行动，否则只是观众知道得多。
5. 冲突必须升级，不能只是同一句话反复说。
6. 场景结尾必须改变故事状态：目标、关系、信息、资源、时间或信念至少改变一项。
7. 迁移经典场景时，只迁移机制，不迁移设定、台词和角色身份。
```

### 6.2 常见问题

| 问题 | 表现 | 为什么失败 |
|---|---|---|
| 场景只有情绪 | 人物哭、吵、沉默，但没有具体目标 | 情绪没有被事件承载，演员没东西可演 |
| 场景只有信息 | 人物轮流解释背景 | 信息没有变成冲突，观众只是在听说明书 |
| 场景没有权力差 | 两个人平等聊天，谁也压不住谁 | 没有攻防，台词没有方向 |
| 场景没有转折 | 开头是什么关系，结尾还是什么关系 | 这场戏可以删掉 |
| 冲突只靠大喊 | 音量升级，但事实、筹码、选择没有升级 | 观众感到重复和廉价 |
| 信息差不产生行动 | 观众知道秘密，但人物行为不受影响 | 悬念没有戏剧功能 |
| 结尾无后果 | 场景结束后下一场仍可照常发生 | 故事没有推进 |

### 6.3 修复方法

```text
如果场景只有情绪：给人物一个必须完成的动作，例如拿签字、拦住人、隐瞒证据、借到钱。
如果场景只有信息：把信息交给一个不愿说的人，另一个人必须逼他说出来。
如果场景没有权力差：加入资源差、身份差、时间差、道德亏欠或公开场合压力。
如果场景没有转折：设定一个开场状态和结尾状态，例如“信任 -> 怀疑”“合作 -> 决裂”“隐瞒 -> 暴露”。
如果冲突只靠大喊：把争吵分三轮，当前事件、旧账、真正恐惧。
如果信息差无效：让秘密改变人物策略，或让观众重新解释上一场戏。
如果结尾无后果：让场景产生新任务、新阻力、新失去或新承诺。
```

### 6.4 Agent 场景拆解总模板

```text
请拆解下面这场戏，不要评价“好不好”就结束。请按以下格式输出：

1. 场景类型：它属于开场钩子、审讯/谈判、饭桌群戏、父子冲突、师徒压迫、情侣破裂、反派诱惑、真相揭示、中点反转、最低谷、高潮选择、尾声回响、职场喜剧失控、黑色幽默惩罚、动作危机选择中的哪一种？
2. 场景目标：每个主要人物想在这场戏里得到什么？
3. 权力位置：谁掌握资源、规则、证据、时间、情感筹码？权力是否转移？
4. 信息差：谁知道什么？谁误解什么？观众知道多少？
5. 三轮冲突升级：当前事件 -> 旧账/利益 -> 价值观/恐惧。
6. 台词转折：哪一句话改变对方策略？如果没有，请补写。
7. 场景后果：这场戏结束后，事件、关系、信息、资源、信念发生了什么改变？
8. 可迁移桥段：把这个机制转译成国产电影/短剧/网剧的一场戏。
9. 改写建议：如果这场戏弱，给出 3 个具体修复动作。
```

### 6.5 Agent 场景模仿生成总模板

```text
请从本库中选择最接近我需求的经典场景机制，然后原创一场新戏。不要复制原片剧情和台词。

我的故事背景：{填写故事背景}
人物关系：{填写人物关系}
本场目标：{填写谁想得到什么}
希望类型：{喜剧/压迫/悬疑/亲情/爱情/动作/黑色幽默}

请输出：
1. 参考机制：说明借鉴的是哪类场景机制。
2. 原创场景设计：地点、人物、开场状态。
3. 权力和信息差：谁压谁，谁瞒谁。
4. 三轮升级：每一轮冲突如何变严重。
5. 关键对白功能：不要求完整对白，但要写出每轮台词的作用。
6. 场景结尾：状态如何改变，下一场戏被推向哪里。
```
