## 1. 分阶段快速诊断清单

### 1.1 创意阶段

```text
一句话能讲清吗？
片名是否体现故事？
海报感在哪里？
观众为什么现在要看？
类似作品有哪些？
新鲜变化在哪里？
```

### 1.2 主角阶段

```text
主角为什么必须改变？
不改变会怎样死掉？
他想要的和需要的是不是不同？
谁最能迫使他面对主题？
```

### 1.3 类型阶段

```text
这是哪一种深层故事类型？
这个类型的必备元素有没有？（查《结构A_故事线与类型.md》3.11 总表）
副类型是否抢走主类型？
娱乐游戏是否兑现类型承诺？
```

### 1.4 节拍阶段

```text
催化剂是否不可逆？
第二幕是否由主角主动进入？
B 故事是否承载主题？
中点是否改变游戏规则？
一无所有是否真正清空旧方法？
第三幕方案是否来自主题领悟？
```

### 1.5 分场阶段

```text
每场是否有目标？
每场是否有冲突？
每场是否有转折？
每场是否改变主角处境？
是否有只解释信息、不改变局面的场景？
```

## 2. 结构病症与修复

### 2.1 枝蔓过多

症状：

1. 支线人物太多。
2. 每个配角都有完整故事。
3. 主角变化被稀释。
4. 很多场戏有趣但不推进。

诊断问题：

```text
这条支线是否改变主角？
这场戏是否推动 A 故事或 B 故事？
删掉它，主角弧光是否受影响？
```

修复：

1. 合并功能相近的角色。
2. 把支线事件并入主角选择。
3. 删除只提供世界观、不提供变化的场景。
4. 让每条支线服务同一个主题问题。

### 2.2 半步缓行

症状：

1. 事件很多，但每件都不够大。
2. 主角像在过日程。
3. 观众感觉故事一直没真正开始。

修复：

```text
把三个小事件合并成一个大转折。
让每场戏结束状态和开始状态不同。
把“准备做”改成“已经做了并付出代价”。
```

### 2.3 节拍模糊

症状：

1. 中点不明显。
2. 一无所有不像最低点。
3. 第三幕方案突然出现。
4. 终场画面没有变化感。

修复：

| 模糊节拍 | 修复方式 |
|---|---|
| 催化剂弱 | 让它不可逆 |
| 第二幕不清 | 让主角做明确选择 |
| 中点弱 | 加公开展示、赌注提高、敌人识别 |
| 坏蛋逼近弱 | 外部敌人和内部裂缝同时加压 |
| 一无所有弱 | 增加死亡气息和旧方法失败 |
| 第三幕弱 | 让解决方案来自 B 故事主题 |

### 2.4 娱乐游戏不足

症状：

1. 观众期待的卖点没有兑现。
2. 公路片不上路，互换片不利用身体错位，恐怖片不展示怪物规则。
3. 第二幕前半像铺垫延长。

修复：

```text
写出 8-12 个“只有这个前提才会出现”的场景。
把最有海报感的桥段集中放在 30-55 分钟。
```

### 2.5 中点塌陷

症状：

1. 中点只是普通事件或大场面，不改变游戏规则。
2. 前后半段没有明显差异。
3. 主角没有公开新身份或新选择。

修复：

```text
让中点成为伪胜利或伪失败。
让赌注明显提高。
让敌人第一次真正看见主角。
让 A 故事和 B 故事产生交汇。
```

### 2.6 第三幕无力

症状：

1. 主角靠运气或巧合赢。
2. 反派突然变笨。
3. 主题没有参与解决，主角没有付出代价。
4. 和解来得太快，旧账没有被看见。
5. 结尾只是动作场面或只交代结果，没有情绪回响。

修复：

使用五要点结局（详见《结构C_节奏分场与第三幕.md》第 2 章）：

```text
召集团队 -> 执行计划 -> 高塔意外 -> 深入挖掘 -> 新计划成功
```

### 2.7 三幕式诊断：三次不可逆

三幕式的重点不是页码，而是三次不可逆：

```text
第一幕不可逆：主角无法回到原来的生活。
第二幕不可逆：主角发现原目标背后的真正问题。
第三幕不可逆：主角用新的自我做出最终选择。
```

第一幕常见问题：

- 铺垫太久，催化剂太晚。
- 只介绍人物，不制造失衡。
- 主角没有明确外部目标。
- 主题台词太直白，但没有通过事件证明。

第二幕常见问题：

- 只有连续任务，没有关系变化。
- 反派只是不断追杀，没有价值观压迫。
- B 故事和主线平行存在，没有互相解释。
- 中点塌陷（见 2.5）。

第三幕常见问题：见 2.6 第三幕无力。

## 3. 剧本结构评分表

总分 100。

| 维度 | 分值 | 判断标准 |
|---|---:|---|
| 故事线清晰度 | 10 | 一句话能否讲清主角、目标、冲突和卖点 |
| 主角适配度 | 10 | 主角是否变化最大、承受最大冲突 |
| 类型判断 | 10 | 主类型和副类型是否清楚 |
| 主题一致性 | 10 | 主题是否贯穿开场、B 故事、中点、结局 |
| 15 节拍完整度 | 15 | 关键节拍是否都有明确事件和变化 |
| 中点强度 | 10 | 是否伪胜利/伪失败并提高赌注 |
| 坏蛋逼近 | 10 | 外部压力和内部裂缝是否同步增强 |
| 一无所有 | 10 | 旧方法是否彻底失败，是否有死亡气息 |
| 第三幕解决 | 10 | 主角是否用新自我解决旧问题 |
| 终场回响 | 5 | 是否与开场形成有力对照 |

评分解释：

```text
90-100：结构成熟，可进入分场或剧本初稿。
75-89：主干成立，需强化中点、一无所有或第三幕。
60-74：有故事方向，但类型、主角或节拍不稳。
60 以下：需要回到故事线、主角和类型重新设计。
```

## 4. 统一 Agent 工作流与输出模板

### 4.1 角色设定与工作顺序

```text
你是一个专业剧本结构顾问，熟悉故事线、十种故事类型、15 节拍表、三世界变形机器、五要点结局和多种节奏模型。

你的任务是帮助用户开发、诊断、改写剧本结构。你必须先判断故事线、主角、类型和主题，再拆节拍。不要直接套公式，也不要只给笼统建议。

工作顺序：
1. 先问：这部电影一句话讲什么？复述并指出是否清晰。
2. 判断主角：谁承受最大冲突，谁变化最大？列出外部目标、内部需求、错误信念和停滞=死亡。
3. 判断类型：主类型和副类型各是什么？（查《结构A_故事线与类型.md》）
4. 判断主题：主角需要学会什么？
5. 判断主要结构模型：三幕式 / Save the Cat / 英雄旅程 / 10 分钟钩子，说明为什么。
6. 拆 15 节拍：每个节拍是否有事件、选择和情绪变化？（查《结构B_15节拍写作手册.md》）
7. 拆 10 分钟钩子：每 10 分钟是否有新问题、新危机或新承诺？（查《结构C_节奏分场与第三幕.md》）
8. 检查中点、一无所有、第三幕：是否从“探索前提”转入“承担后果”？旧方法是否真正失败？主角是否用新自我解决旧问题？第三幕用五要点结局检查。
9. 输出诊断和可直接改写的方案。

你必须避免：
1. 照搬原书或电影台词。
2. 把类型当成表面题材。
3. 让所有故事都机械套同一模板。
4. 忽略主角变化。
5. 给出无法执行的空泛评价。
```
