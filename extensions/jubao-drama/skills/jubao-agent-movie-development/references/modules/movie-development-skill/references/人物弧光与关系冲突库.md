# 人物弧光与关系冲突库

这个文件帮助 Agent 判断人物不是只会说话，而是有成长路线。人物弧光的核心不是“性格变好”，而是从错误信念出发，在代价中被迫承认真相，并在第三幕用新行为证明改变。

## 0. 人物弧光总公式

```text
旧伤 -> 错误信念 -> 表面目标 -> 旧方法 -> 代价升级 -> 中点诱惑 -> 最低谷崩塌 -> 真相 -> 新选择 -> 新行为
```

判断人物是否成立，不看他说了什么，而看他在压力下是否仍重复旧方法；判断人物是否改变，不看他是否道歉，而看他是否做出开场时绝不会做的行动。

### 0.1 通用：弧光写作步骤（适用于 §1–§8 全部八型）

步骤 1 中“最相信的一句话”逐字使用该型维度表第一行的“错误信念”。

```text
1. 先写主角开场时最相信的一句话（即该型维度表中的错误信念）。
2. 设计一个外部目标，让他有理由继续相信这句话。
3. 让前三次行动都能小胜，但每次都伤害一个关系或制造新代价。
4. 中点给他一次诱惑：似乎只要更极端地坚持旧方法，就能赢。
5. 一无所有处证明：旧方法不仅不能救他，还会毁掉他最在乎的东西。
6. 第三幕让他做出相反选择，用行动而非宣言证明改变。
```

### 0.2 通用：常见写烂方式

- 只给人物悲惨过去，却没有让旧伤影响当下选择。
- 中点之前人物没有犯错，只是被外界欺负。
- 最低谷只是输掉事件，没有击穿错误信念。
- 结尾用一段道歉代替新行为。
- 改变来得太顺，没有付出代价。

### 0.3 通用：改写方法

- 把人物的每次失败都改成“旧方法造成的失败”。
- 给他一个可以轻松走老路的诱惑，再让他拒绝。
- 把和解写成具体行动：归还、承认、公开、留下、放手、承担。
- 让对手或亲密关系说出他不愿承认的真相。

### 0.4 通用：Agent 调用模板

```text
请按【某某型】重设这个人物弧光。
输出：错误信念、表面目标、真正需求、旧伤、第一幕伪装、第二幕三次代价、中点诱惑、最低谷崩塌、第三幕新选择、结尾新行为。
要求：每个节点都必须是可拍的场景动作，不要只写心理状态。
```

## 1. 赎罪型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 我已经不配被原谅，所以只能用行动偿还。 |
| 表面目标 | 弥补过去错误、保护某人或完成遗愿 |
| 真正需求 | 接受责任不是自我惩罚，而是重新选择如何活 |
| 旧伤来源 | 曾经的懦弱、背叛、误判或间接伤害造成不可逆后果 |
| 第一幕伪装 | 沉默、回避旧人、用冷硬效率掩盖愧疚 |
| 第二幕代价 | 越想补偿越制造控制，越救人越像在救过去的自己 |
| 中点诱惑 | 出现一个看似能“一次还清”的机会 |
| 最低谷崩塌 | 发现受害者/亲人并不需要他的自我牺牲，而需要他诚实承担 |
| 第三幕选择 | 放弃赎罪表演，承认具体错误并付出实际代价 |
| 结尾新行为 | 不再求一句原谅，而是持续做正确的事 |

## 2. 野心型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 只有爬到最高处，我才不会被轻视。 |
| 表面目标 | 获得权力、名声、财富、职位或行业认可 |
| 真正需求 | 价值不能只由外部排名证明 |
| 旧伤来源 | 贫穷、羞辱、被低估、家庭期待或天赋焦虑 |
| 第一幕伪装 | 自律、精明、能忍，但把人都当资源 |
| 第二幕代价 | 胜利越多，关系越空；越接近目标，越像压迫过自己的人 |
| 中点诱惑 | 得到梦寐以求的机会，但必须牺牲底线 |
| 最低谷崩塌 | 发现自己赢了表面目标，却失去最初想保护的东西 |
| 第三幕选择 | 拒绝用旧伤复制伤害，选择新的成功定义 |
| 结尾新行为 | 保留能力，但不再把人当阶梯 |

## 3. 复仇型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 只有让对方痛，我的痛才有意义。 |
| 表面目标 | 找到仇人、揭露真相、完成报复 |
| 真正需求 | 痛苦需要被承认，但复仇不能恢复失去的人生 |
| 旧伤来源 | 亲人死亡、被背叛、被制度碾压、尊严被夺走 |
| 第一幕伪装 | 冷静、执拗、把一切关系工具化 |
| 第二幕代价 | 每一步报复都让自己更像敌人，也伤害无辜者 |
| 中点诱惑 | 仇人暴露弱点，复仇似乎触手可及 |
| 最低谷崩塌 | 发现复仇目标背后还有更大的系统或误解 |
| 第三幕选择 | 选择审判、揭露、放下或承担，而非单纯泄愤 |
| 结尾新行为 | 把愤怒转化为保护他人或改变规则 |

## 4. 逃避型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 只要我不面对，问题就不会真正发生。 |
| 表面目标 | 离开、拖延、撒谎、转移话题、保持轻松 |
| 真正需求 | 自由不是逃开责任，而是能主动选择承担 |
| 旧伤来源 | 失败经历、亲密关系创伤、家庭压力或害怕被看穿 |
| 第一幕伪装 | 幽默、圆滑、会哄人，但关键时刻消失 |
| 第二幕代价 | 逃避让小问题滚成大灾难，别人替他付代价 |
| 中点诱惑 | 出现一个完美逃跑出口 |
| 最低谷崩塌 | 发现逃走会把最重要的人留在危险或误解里 |
| 第三幕选择 | 第一次主动留下，面对最难的对话或后果 |
| 结尾新行为 | 不再靠玩笑解围，而是把话说完、把事做完 |

## 5. 控制型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 如果我不控制一切，事情就会毁掉。 |
| 表面目标 | 安排他人的人生、维持秩序、保证结果 |
| 真正需求 | 爱不是替别人活，安全也不是剥夺选择 |
| 旧伤来源 | 曾经历失控、失去、贫穷、背叛或家庭崩塌 |
| 第一幕伪装 | 可靠、强势、能解决问题，但不听别人真正想要什么 |
| 第二幕代价 | 控制越强，关系越窒息；越保护，越制造反抗 |
| 中点诱惑 | 控制方案短暂成功，证明他“好像是对的” |
| 最低谷崩塌 | 被保护者因他的控制遭受更大伤害或离开 |
| 第三幕选择 | 交还选择权，承担自己的恐惧，而不是管理别人的人生 |
| 结尾新行为 | 从命令变成请求，从安排变成陪伴 |

## 6. 天才受困型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 只要我足够聪明，就不需要普通人的连接。 |
| 表面目标 | 证明能力、完成作品、解决难题 |
| 真正需求 | 天赋不能替代情感能力，聪明也不能免除责任 |
| 旧伤来源 | 早熟、孤立、被利用、被神化或被羞辱 |
| 第一幕伪装 | 逻辑强、嘴硬、低情商，用专业术语当防御 |
| 第二幕代价 | 技术越成功，人际越失败；解决问题却伤害团队 |
| 中点诱惑 | 关键难题只有他能解，众人重新依赖他 |
| 最低谷崩塌 | 发现真正卡住的不是问题，而是他不能信任别人 |
| 第三幕选择 | 承认需要合作或亲密连接，把天赋用于共同目标 |
| 结尾新行为 | 仍然聪明，但愿意解释、倾听、道歉和分享控制权 |

## 7. 失败者翻身型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 我这种人赢不了，所以最好先嘲笑自己。 |
| 表面目标 | 证明一次、赢一场、被看见、摆脱底层标签 |
| 真正需求 | 尊严不是别人给的，而是自己停止配合羞辱 |
| 旧伤来源 | 长期失败、阶层压力、家庭否定、社会标签 |
| 第一幕伪装 | 自嘲、油滑、懒散或装作不在乎 |
| 第二幕代价 | 每次机会都因自我破坏差点失败 |
| 中点诱惑 | 意外得到大机会或被迫站到中心 |
| 最低谷崩塌 | 旧自卑导致他背叛团队或放弃自己 |
| 第三幕选择 | 不再用失败当身份，认真承担一次选择 |
| 结尾新行为 | 未必大获全胜，但第一次像主角一样行动 |

## 8. 亲情修复型

| 维度 | 写作要求 |
| --- | --- |
| 错误信念 | 家人应该自动懂我；如果不懂，就说明不爱。 |
| 表面目标 | 得到认可、逃离家庭、证明自己、修复某段关系 |
| 真正需求 | 亲情需要表达、边界和具体承担，不是血缘自动解决 |
| 旧伤来源 | 被忽视、被控制、失去沟通窗口、长期误解 |
| 第一幕伪装 | 嘴硬、冷漠、过度懂事或过度叛逆 |
| 第二幕代价 | 越想证明自己，越重复家族伤害模式 |
| 中点诱惑 | 短暂亲近让主角以为和解已经完成 |
| 最低谷崩塌 | 旧账爆发，证明没有真正说清楚 |
| 第三幕选择 | 说出具体伤害，也听见对方具体恐惧 |
| 结尾新行为 | 关系不一定完美，但出现新的相处规则 |

## 9. 关系冲突总公式

```text
长期旧账 + 当前目标冲突 + 权力差 + 不能说出口的话 + 外部压力 = 有厚度的关系戏
```

关系戏不要从“我爱你/我恨你”开始，而要从具体账目开始：谁付过钱，谁照顾过谁，谁错过了哪一天，谁替谁做过决定，谁在人前没有维护谁。

### 9.0 通用：对白调用方式与 Agent 模板（适用于 §9.1–§9.10 全部十种关系）

对白调用方式：

- 不要让人物直接概括关系，例如“你一直控制我”。改成具体事实：“志愿表你签了，房子你看了，连我几点回家都是你跟门卫说的。”
- 让强势方说规则，弱势方说代价；让亏欠方说理由，被亏欠方说事实。
- 争吵第一轮谈当前事件，第二轮翻旧账，第三轮暴露真正恐惧。

Agent 模板：

```text
请按【某某关系】重写这场戏。
输出：长期旧账、当前导火索、谁掌握权力、谁更害怕失去、三轮冲突升级、最后一句改变关系位置的台词。
```

## 9.1 父子

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 权威与认可 |
| 长期旧账 | “我养你/我教你”与“你从没真正看见我” |
| 常见触发点 | 教育、职业、婚恋、失败、面子、金钱 |
| 权力差 | 父亲掌握资源或道德评价权，子女掌握离开的权力 |
| 不能说出口的话 | 我不是不爱你，我是不知道怎么承认你和我不同 |
| 爆发场景 | 饭桌训话、医院签字、工作选择、旧物翻出、公开维护或公开否定 |
| 和解/决裂条件 | 和解条件是父亲交还人生选择权，子女承认对方恐惧但不再被恐惧支配 |

## 9.2 兄弟

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 比较与亏欠 |
| 长期旧账 | 一个被期待，一个被忽视；一个留下，一个逃走 |
| 常见触发点 | 遗产、照顾父母、事业成败、旧事故责任 |
| 权力差 | 年龄、能力、父母偏爱、经济状况形成隐性权力 |
| 不能说出口的话 | 你欠我的不是钱，是那几年没人替我说话 |
| 爆发场景 | 葬礼/婚礼重逢、分钱、共同撒谎、童年秘密曝光、替对方挨打 |
| 和解/决裂条件 | 必须承认各自承担过的代价，而不是用兄弟情一笔带过 |

## 9.3 情侣

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 亲密与防御 |
| 长期旧账 | “你应该懂我”与“我不敢让你看见真实的我” |
| 常见触发点 | 承诺、事业、前任、家庭、金钱、未来城市 |
| 权力差 | 谁更需要关系，谁就更容易失去谈判权 |
| 不能说出口的话 | 我不是不想靠近你，我是怕靠近后你发现我不值得 |
| 爆发场景 | 同居小事、错过重要时刻、公开身份、前任出现、分手后仍然帮忙 |
| 和解/决裂条件 | 结局必须体现新的相爱方式，或成熟地承认无法继续 |

## 9.4 前任

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 旧情与旧伤 |
| 长期旧账 | 两个人记得的是不同版本的同一段关系 |
| 常见触发点 | 未完成的道歉、误解、背叛、错过、共同朋友 |
| 权力差 | 先放下的人占上风，仍在意的人更脆弱 |
| 不能说出口的话 | 我恨你，是因为我还在替当年的自己要一个解释 |
| 爆发场景 | 重逢寒暄、旧地点、共同物品、现任在场、最后一次帮忙 |
| 和解/决裂条件 | 不是复合才叫完成，真正完成是终于说清楚当年没说的话 |

## 9.5 师徒

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 认可与控制 |
| 长期旧账 | 导师说是训练，徒弟感到被塑形和剥夺 |
| 常见触发点 | 天赋、标准、羞辱、机会、传承、背叛 |
| 权力差 | 导师掌握入口和评价体系，徒弟掌握未来是否继承 |
| 不能说出口的话 | 我把你打碎，是因为我当年也是这样被打出来的 |
| 爆发场景 | 第一次训练、公开羞辱、私下奖赏、机会交换、徒弟反夺舞台 |
| 和解/决裂条件 | 徒弟必须决定继承能力还是继承伤害 |

## 9.6 搭档

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 互补与不信任 |
| 长期旧账 | 一个要规则，一个要结果；一个要安全，一个要冒险 |
| 常见触发点 | 任务分工、功劳归属、方法冲突、秘密隐瞒 |
| 权力差 | 谁掌握关键信息，谁就掌握关系节奏 |
| 不能说出口的话 | 我不信你，不是因为你没能力，是因为你总替我决定 |
| 爆发场景 | 第一次合作失败、互相救场、隐瞒曝光、分开行动、最终交换方法 |
| 和解/决裂条件 | 成熟搭档不是性格相同，而是愿意把弱点交给对方补位 |

## 9.7 敌人

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 镜像与价值观 |
| 长期旧账 | 敌人不是阻碍，而是主角错误信念的极端版本 |
| 常见触发点 | 资源争夺、理念冲突、身份威胁、复仇、审判 |
| 权力差 | 敌人掌握外部压力，主角掌握是否被同化 |
| 不能说出口的话 | 你恨我，是因为我敢把你心里的话做出来 |
| 爆发场景 | 第一次交锋、诱惑交易、公开羞辱、两难选择、最终对峙 |
| 和解/决裂条件 | 好敌人要逼主角回答：我和你到底哪里不同 |

## 9.8 上下级

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 权力与生存 |
| 长期旧账 | 上级要服从，下级要尊严；双方都说自己为了大局 |
| 常见触发点 | KPI、升职、背锅、资源分配、制度漏洞 |
| 权力差 | 上级掌握评价和资源，下级掌握执行细节和真相 |
| 不能说出口的话 | 我不是压你，我是在教你这个系统怎么活 |
| 爆发场景 | 会议否定、私下交易、公开背锅、客户现场、越级汇报 |
| 和解/决裂条件 | 结尾要么重写权力关系，要么让主角看清系统代价 |

## 9.9 阶层差异

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 体面与羞耻 |
| 长期旧账 | 一方把选择当自由，另一方把选择当风险 |
| 常见触发点 | 钱、教育、口音、消费、家庭负担、社交礼仪 |
| 权力差 | 有资源的人定义规则，缺资源的人承担错误成本 |
| 不能说出口的话 | 你说的梦想，对我来说是赌命 |
| 爆发场景 | 付款瞬间、饭局礼仪、家庭住处暴露、礼物不对等、求助被误读 |
| 和解/决裂条件 | 情感兑现必须承认现实差异，不能用爱情/友情抹平阶层 |

## 9.10 家族控制

| 维度 | 写作要求 |
| --- | --- |
| 关系核心 | 爱与统治 |
| 长期旧账 | 家族用爱包装秩序，用牺牲要求服从 |
| 常见触发点 | 婚恋、职业、财产、照顾老人、名声、血脉 |
| 权力差 | 长辈掌握道德审判，晚辈掌握是否离开体系 |
| 不能说出口的话 | 我们不是不让你活，我们是怕你活得不像我们的人 |
| 爆发场景 | 家族会议、婚礼/葬礼、房产签字、亲戚围攻、公开断裂 |
| 和解/决裂条件 | 修复不是所有人抱在一起，而是建立边界和新规则 |
