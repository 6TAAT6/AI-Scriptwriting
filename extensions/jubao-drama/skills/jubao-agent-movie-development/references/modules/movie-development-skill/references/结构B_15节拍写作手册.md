## 2. 每个节拍怎么写

每个节拍都不要只理解成“时间点”，而要理解成一次明确的叙事功能：它必须改变观众对主角、世界、关系、目标或主题的理解。

每个节拍都至少要回答四个问题：

```text
1. 这一刻主角想要什么？
2. 什么力量阻止他？
3. 这一刻结束后，局面有什么不可逆变化？
4. 这一刻如何推动主角从“错误信念”走向“主题真相”？
```

节拍不是孤立的。最关键的对应关系：

| 前半段节拍 | 后半段对应节拍 | 对应关系 |
|---|---|---|
| 开场画面 | 终场画面 | 改变前 vs 改变后 |
| 主题呈现 | 灵魂黑夜 / 第三幕选择 | 当初没听懂的话终于听懂 |
| 催化剂 | 一无所有 | 第一次打击 vs 最严重打击 |
| 争论 | 灵魂黑夜 | 轻度犹豫 vs 深度绝望 |
| 第二幕衔接点 | 第三幕衔接点 | 用旧我进入新世界 vs 用新我进入最终行动 |
| 娱乐游戏 | 坏蛋逼近 | 兑现前提 vs 前提开始反噬 |
| 中点 | 一无所有 | 伪胜利对应真失败，或伪失败对应真胜利的前夜 |

各节拍的 Agent 输出条目统一见 2.17 节拍生成总模板，不再逐节拍重复。

### 2.1 开场画面

#### 2.1.1 节拍定位

开场画面不是“第一场风景”，而是整部电影的第一张诊断片。它要在最短时间里告诉观众：这是一个什么世界，主角处在什么状态，故事的情绪是什么，最后会从哪里变到哪里。

开场画面可以是一张画面、一组动作、一个小事件，也可以是一段无对白场景。它不一定要解释剧情，但必须建立“改变前”的状态。

#### 2.1.2 必须完成的任务

1. 定基调。
2. 定类型。
3. 定主角起点。
4. 给终场画面做对照。
5. 暗示主角的核心缺陷。
6. 暗示这个世界的规则。
7. 给观众一个继续看的理由。

#### 2.1.3 写作方法

写开场时，不要从“天气、城市、镜头慢慢推进”开始，除非这些信息本身能制造冲突。更有效的方法是：把主角放进一个小型压力测试。

开场压力测试可以是：

| 类型 | 开场测试 |
|---|---|
| 亲情片 | 主角用错误方式照顾亲人 |
| 爱情片 | 主角在亲密关系中逃避或控制 |
| 喜剧片 | 主角严肃处理荒唐问题 |
| 悬疑片 | 一个日常秩序中出现异常细节 |
| 恐怖片 | 规则被无意破坏 |
| 公路片 | 主角被困在不能离开的旧地点 |
| 职场片 | 主角被系统压迫但仍按系统规则自救 |
| 动作片 | 主角的能力、缺陷和危险世界同时出现 |

#### 2.1.4 开场画面应包含的五类信息

| 信息 | 写法 |
|---|---|
| 世界 | 通过行动和空间显示，不用旁白解释 |
| 主角 | 让他做一件暴露性格的事 |
| 缺陷 | 让缺陷造成小后果 |
| 压力 | 让观众知道现状不能一直持续 |
| 反差 | 为终场画面预留对照 |

#### 2.1.5 合格标准

```text
观众看到开场，就能感到：这个人现在这样活下去不行。
```

```text
观众看到开场，就能感到这是什么世界、主角哪里不对、故事会往什么方向走。
```

#### 2.1.6 常见问题

1. 开场只写天气和环境。
2. 开场没有行动。
3. 开场没有主角缺陷。
4. 开场和结尾没有对照。
5. 开场只有世界观，没有人物压力。
6. 开场把背景全讲完，缺少悬念。
7. 开场太“正常”，观众不知道为什么要看。

#### 2.1.7 修复方法

```text
把主角放进一个能暴露缺陷的小冲突里。
```

如果开场太平，按下面方式修改：

```text
原开场：主角起床、出门、上班。
改法：主角起床时已经迟到，但仍坚持把家里所有东西按固定顺序摆好，说明他控制欲强。

原开场：城市航拍，介绍背景。
改法：从城市中一个正在被制度伤害的人切入，让世界规则通过冲突出现。

原开场：主角旁白介绍自己。
改法：让主角做一件他自己以为正常、观众觉得有问题的事。
```

### 2.2 主题呈现

#### 2.2.1 节拍定位

主题呈现不是让角色说一句大道理，而是在故事早期把主角需要学习的问题抛出来。主角通常不会听懂，甚至会反感、误解或忽略。

主题呈现最好由别人说给主角听，也可以由事件、新闻、标语、仪式、职业规则或某个失败场面表达。

#### 2.2.2 主题呈现的作用

1. 告诉观众这部电影真正讨论什么。
2. 给主角的错误信念设置反命题。
3. 让 B 故事后面有东西可以回响。
4. 让结尾的选择有精神依据。
5. 让结构不只是事件推进，而是价值观转变。

#### 2.2.3 写法

1. 让别人对主角说一句不中听的话。
2. 让主角听见但不理解。
3. 让这句话在中点、一无所有或结尾被重新理解。
4. 主题句不要太像标语，要像关系中的刺。
5. 主题最好和主角当下的行为直接冲突。

#### 2.2.4 主题句的常见来源

| 来源 | 例子方向 |
|---|---|
| 爱人 | “你不是保护我，你是不让我进你的生活。” |
| 家人 | “你总替别人安排，却从不问别人想不想要。” |
| 对手 | “你不是没能力，你是怕真正赢一次。” |
| 老师 | “你要掌声，还是要资格？” |
| 孩子 | “你说会回来，为什么每次都像告别？” |
| 旁观者 | “你们这种人最会把害怕说成负责。” |
| 职业规则 | “这个行业不奖励真相，只奖励结果。” |

#### 2.2.5 主题句的好坏判断

弱主题：

```text
家庭很重要。
人要勇敢。
不要逃避过去。
```

强主题：

```text
你每次说“我是为你好”的时候，都刚好省掉了问我。
你不是不敢失败，你是不敢让别人看见你想赢。
你把过去锁起来，不代表它没有在屋里走动。
```

#### 2.2.6 类型片中的主题呈现

| 类型 | 主题问题 |
|---|---|
| 金羊毛 | 主角以为要到达目的地，其实要学会如何走路 |
| 如愿以偿 | 主角以为得到愿望会幸福，其实愿望暴露缺陷 |
| 伙伴之情 | 主角以为自己完整，其实需要另一个人改变 |
| 鬼怪屋 | 怪物逼角色面对原罪 |
| 麻烦家伙 | 普通人被迫发现自己比想象中更强 |
| 被制度化 | 主角必须选择归属还是自由 |
| 愚者成功 | “傻子”揭穿聪明世界的荒唐 |

#### 2.2.7 常见问题

1. 主题太直白。
2. 主题和主角行为无关。
3. 主题只在开头出现一次，后面没有回响。
4. 主题由主角自己说出，显得像自我总结。
5. 主题没有被反方挑战。

#### 2.2.8 修复方法

```text
把主题写成关系冲突中的一句刺耳话。
让主角当场否认它。
在 B 故事中让主题反复以不同形式出现。
在一无所有处证明主角不听主题会付出代价。
在结局让主角用行动承认主题。
```

### 2.3 铺垫

#### 2.3.1 节拍定位

铺垫不是把背景资料塞给观众，而是在前 10 分钟建立一个“如果不改变就会死”的旧世界。这里的“死”可以是现实死亡、精神死亡、关系死亡、梦想死亡、尊严死亡。

铺垫必须让观众理解：催化剂虽然痛苦，但它是必要的。

#### 2.3.2 必须建立

1. 主角旧生活。
2. 主角缺陷。
3. 主角欲望。
4. 主要关系。
5. 压力系统。
6. 将在后面回收的道具或习惯。
7. 主角的错误信念。
8. 主角的“救猫咪”入口。
9. 主要人物关系的初始状态。
10. 反派或压力系统的早期影子。

#### 2.3.3 “需要弥补的 6 件事”

这不是固定必须 6 件，而是指：在开头反复展示主角缺失的能力、关系、情感或价值观，让后面每一次回收都成立。

| 缺失 | 可见表达 |
|---|---|
| 不会沟通 | 总说“以后再说” |
| 逃避责任 | 用玩笑掩盖问题 |
| 控制欲 | 替别人安排所有事 |
| 自卑 | 不敢进入重要场合 |
| 孤独 | 没有人能随时打电话 |
| 错误价值观 | 把钱、成功、复仇当唯一目标 |

#### 2.3.4 铺垫的三层信息

| 层级 | 要写什么 | 避免什么 |
|---|---|---|
| 表层 | 职业、家庭、地点、关系 | 长篇人物小传 |
| 压力层 | 钱、时间、疾病、任务、秘密 | 静态介绍 |
| 主题层 | 主角为什么必须改变 | 直接讲道理 |

#### 2.3.5 铺垫场景设计

前 10 分钟可以设计 3-5 个短场景，每个场景承担不同功能：

```text
场景 1：开场画面，主角在旧世界里做一件暴露缺陷的事。
场景 2：主角和亲密关系/工作关系发生小冲突，主题被刺出。
场景 3：展示压力系统，说明现状不能持续。
场景 4：展示主角想要的东西和真正缺失的东西不同。
场景 5：催化剂前的最后平衡，让打击更明显。
```

#### 2.3.6 铺垫中的“救猫咪”

如果主角有明显缺点，必须给观众一个愿意跟随他的入口。它可以是：

1. 保护弱者。
2. 承担别人不愿承担的责任。
3. 展现幽默感。
4. 在压力下仍保留善意。
5. 暴露脆弱。
6. 被更强系统压迫。
7. 做一件小而具体的好事。

注意：救猫咪不是把主角洗白，而是让观众理解他值得被观察。

#### 2.3.7 常见问题

1. 铺垫太长，催化剂来得太晚。
2. 铺垫只介绍世界，不制造压力。
3. 主角缺陷没有被行动证明。
4. 所有人物一次性出场，观众分不清功能。
5. 道具、习惯、关系没有后续回收。
6. 主角开场生活很好，看不出为什么必须改变。

#### 2.3.8 修复方法

```text
把背景信息压进冲突。
把人物介绍改成选择。
把世界观介绍改成规则惩罚。
把主角缺陷改成一个会造成后果的行为。
在前 10 分钟明确“不改变会怎样死”。
```

### 2.4 催化剂

#### 2.4.1 节拍定位

催化剂是故事第一次真正“发生”。它打破旧生活，让主角无法继续假装一切正常。

它通常不是好消息，哪怕最终会把主角带向更好的人生。对主角来说，它首先是麻烦、羞辱、失去、威胁、召唤或无法忽视的异常。

#### 2.4.2 催化剂必须做到

1. 打碎旧生活。
2. 提出第一幕的核心问题。
3. 让主角开始失去控制。
4. 让观众知道故事不能回到开场状态。
5. 把主角推向必须选择的边缘。

常见形式：

1. 分手。
2. 死亡。
3. 解雇。
4. 发现秘密。
5. 收到任务。
6. 意外事故。
7. 亲人消失。
8. 身份暴露。
9. 灾难来临。
10. 超常能力出现。

#### 2.4.3 催化剂的强度标准

```text
如果催化剂被拿掉，故事就不能发生。
```

更严格的标准：

```text
如果催化剂发生后，主角还能照常生活，那它不够强。
```

#### 2.4.4 催化剂的类型

| 类型 | 写法 | 适合故事 |
|---|---|---|
| 失去型 | 主角失去人、工作、身份、钱、家 | 变迁仪式、亲情、职场 |
| 召唤型 | 任务、信件、求救、委托出现 | 冒险、侦探、公路 |
| 暴露型 | 秘密被揭开，身份被看穿 | 悬疑、犯罪、家庭 |
| 入侵型 | 怪物、敌人、制度闯入旧世界 | 鬼怪屋、动作、惊悚 |
| 魔法型 | 超能力、互换、诅咒、时间循环出现 | 如愿以偿 |
| 死亡型 | 亲人死亡、导师死亡、象征性死亡 | 变迁仪式、超级英雄 |

#### 2.4.5 两次撞击

有些故事一个催化剂不足以推动主角进入第二幕，可以使用“两次撞击”。

```text
第一次撞击：提出召唤或问题。
第二次撞击：切断退路，逼主角行动。
```

适用情况：

1. 主角非常抗拒改变。
2. 世界观复杂，需要逐步启动。
3. 第一次事件只是让问题出现，第二次事件才让问题不可逆。
4. 主角有充分理由拒绝冒险。

#### 2.4.6 常见问题

1. 催化剂太弱，只是普通邀请。
2. 催化剂和主角缺陷无关。
3. 催化剂来得太晚。
4. 催化剂没有改变任何关系。
5. 催化剂只是信息，不是事件。
6. 催化剂没有引发“我该怎么办”的争论。

#### 2.4.7 修复方法

```text
让催化剂带来损失。
让催化剂公开化，增加羞耻或压力。
让催化剂切断一种旧选择。
让催化剂直接击中主角错误信念。
如果一次不够，用第二次撞击切断退路。
```

### 2.5 争论

#### 2.5.1 节拍定位

争论是主角进入新世界前最后一次挣扎。它不是拖时间，而是让观众理解主角为什么不愿改变，以及为什么最终又不得不改变。

争论的核心不是“去不去”，而是：

```text
如果我去了，我会失去什么？
如果我不去，我又会变成什么？
```

争论不一定是口头争论，也可以是行动犹豫。

#### 2.5.2 争论要完成的任务

1. 明确第一幕问题。
2. 展示主角抗拒改变的理由。
3. 让主角尝试旧方法自救。
4. 让旧方法失败或不够。
5. 把主角推向第二幕选择。

#### 2.5.3 争论问题模板

```text
我该不该离开旧世界？
我能不能承担这个任务？
我敢不敢面对真相？
我是否愿意相信这个人？
我是否继续用旧方法活下去？
```

#### 2.5.4 争论的写法

争论段可以包含：

1. 主角拒绝召唤。
2. 亲友劝说或反对。
3. 主角查资料、试图找替代方案。
4. 主角尝试把事情恢复原状。
5. 主角短暂逃避。
6. 第二次撞击。
7. 主角发现不行动代价更大。

#### 2.5.5 按类型处理争论

| 类型 | 争论重点 |
|---|---|
| 金羊毛 | 要不要上路 |
| 如愿以偿 | 要不要使用魔法 / 承认异常 |
| 鬼怪屋 | 要不要相信怪物存在 / 要不要封锁空间 |
| 推理侦探 | 要不要接案 / 深挖真相 |
| 伙伴之情 | 要不要和对方绑定 |
| 被制度化 | 要不要挑战组织 |
| 愚者成功 | 要不要进入看不起自己的精英世界 |
| 变迁仪式 | 要不要承认痛苦无法绕开 |

#### 2.5.6 常见问题

1. 主角没有犹豫，太快进入故事。
2. 主角犹豫太久，节奏拖。
3. 争论没有明确问题。
4. 争论只是重复“不行”，没有新信息。
5. 争论中没有展示旧方法失败。
6. 主角是被别人推走，不是自己选择。

#### 2.5.7 修复方法

```text
给主角一个合理拒绝的理由。
让主角用旧方法尝试解决催化剂。
让旧方法失败。
让不行动的代价变得更大。
让主角在第二幕衔接点主动选择。
```

### 2.6 第二幕衔接点

#### 2.6.1 节拍定位

第二幕衔接点是主角从正题世界进入反题世界的门槛。它必须是一个行动选择，而不是剧情把主角搬到新地点。

关键：主角必须选择，不要只是被拖走。

#### 2.6.2 合格标准

```text
主角用行动回答第一幕的问题。
```

#### 2.6.3 常见行动形式

1. 主角上路。
2. 主角接案。
3. 主角进入学校/公司/战场/旅程。
4. 主角接受魔法规则。
5. 主角决定隐瞒身份。
6. 主角决定追一个人。
7. 主角决定反抗制度。
8. 主角决定保护一个人。
9. 主角决定撒一个会滚大的谎。
10. 主角决定进入怪物所在的空间。

#### 2.6.4 反题世界是什么

反题世界不是只换地点，而是换规则。（三世界的完整说明见《结构C_节奏分场与第三幕.md》第 1 章。）

| 第一幕正题 | 第二幕反题 |
|---|---|
| 主角控制一切 | 主角失去控制 |
| 主角逃避亲密 | 主角被迫绑定他人 |
| 主角靠钱解决问题 | 钱失效 |
| 主角相信制度 | 制度背叛他 |
| 主角身体自由 | 身体受限 |
| 主角被低估 | 进入必须证明自己的舞台 |

#### 2.6.5 写作步骤

```text
1. 让主角看见旧世界已经回不去。
2. 让主角仍有最后一个拒绝机会。
3. 让主角做出明确行动。
4. 让行动带来新地点、新规则、新关系。
5. 进入第二幕后立刻展示反题世界的不同。
```

#### 2.6.6 常见问题

1. 主角被绑架、被拖走、被迫上路，没有主观选择。
2. 第二幕只是换地点，规则没变。
3. 第二幕衔接点不清楚，观众不知道故事正式开始。
4. 主角选择没有代价。
5. 第二幕目标仍然模糊。

#### 2.6.7 修复方法

```text
让主角亲口或用行动选择进入。
给选择增加放弃旧安全区的代价。
进入第二幕后立刻用第一场戏展示新规则。
```

### 2.7 B 故事

#### 2.7.1 节拍定位

B 故事不是可有可无的爱情副线。它是主题学习线。

如果 A 故事是“主角追一个外部目标”，B 故事就是“主角学会为什么这个目标不是全部”。B 故事经常提供第三幕解决方案的精神钥匙。

常见 B 故事角色：

1. 爱人。
2. 搭档。
3. 导师。
4. 孩子。
5. 兄弟。
6. 敌人。
7. 一个和主角相反的人。

#### 2.7.2 B 故事功能

| 功能 | 说明 |
|---|---|
| 暂时离开 A 故事 | 让观众喘气 |
| 展示反题人物 | 给主角另一种活法 |
| 承载主题讨论 | 主角在关系中学习 |
| 提供第三幕钥匙 | 最终解决方案常来自 B 故事 |

#### 2.7.3 B 故事角色怎么选

选择 B 故事人物时，问：

```text
谁最能看穿主角的错误信念？
谁拥有主角缺少的品质？
谁会因为主角不改变而受到伤害？
谁能在灵魂黑夜时让主题回响？
```

#### 2.7.4 B 故事的结构任务

| 节点 | B 故事任务 |
|---|---|
| 第 30 分钟左右 | B 故事人物出现，给主角另一种活法 |
| 娱乐游戏 | 关系发展，主题被轻度讨论 |
| 中点 | A/B 故事交汇，关系公开升级 |
| 坏蛋逼近 | 主角旧缺陷伤害 B 故事关系 |
| 一无所有 | B 故事关系破裂或被牺牲 |
| 灵魂黑夜 | 主角终于理解 B 故事提供的主题 |
| 第三幕 | 主角用 B 故事学到的东西解决 A 故事 |

#### 2.7.5 B 故事不一定是爱情

| 故事类型 | B 故事可以是 |
|---|---|
| 动作片 | 家庭、搭档、被保护对象 |
| 悬疑片 | 受害者家属、线人、过去的自己 |
| 亲情片 | 爱人、兄弟、孩子、病人 |
| 职场片 | 同事、下属、竞争者 |
| 超级英雄 | 普通人、导师、恋人、反派镜像 |
| 公路片 | 旅伴、目的地遇到的人、旧关系 |

#### 2.7.6 常见问题

1. B 故事只是爱情调剂，不影响主题。
2. B 故事人物只负责鼓励主角。
3. B 故事和 A 故事直到结尾才硬合并。
4. B 故事没有自己的变化。
5. B 故事人物没有看穿主角。

#### 2.7.7 修复方法

```text
让 B 故事人物指出主题问题。
让主角因旧缺陷伤害 B 故事人物。
让 B 故事在中点和一无所有处参与主线。
让第三幕解决方案来自 B 故事提供的领悟。
```

### 2.8 娱乐游戏

#### 2.8.1 节拍定位

娱乐游戏是“观众为什么来看这部电影”的部分，也就是兑现大前提的部分。它不一定轻松，但必须让观众看到这个创意最独特、最有类型满足感的场景。

不是每个故事都要搞笑，但每个故事都要兑现前提。

#### 2.8.2 核心任务

1. 展示第二幕新世界规则。
2. 兑现海报、片名、预告片承诺。
3. 让主角用旧方法探索新世界。
4. 让观众享受类型快感。
5. 在轻松或高能表层下埋人物变化。

| 类型 | 娱乐游戏内容 |
|---|---|
| 灵魂互换 | 用对方身体生活，闹出错位和理解 |
| 公路片 | 一站一站遇见新人物、新困境 |
| 恐怖片 | 怪物规则逐步展示 |
| 职场喜剧 | 主角用错方法进入新系统 |
| 灾难片 | 求生办法不断失败又升级 |
| 爱情片 | 两人不断靠近和误解 |
| 悬疑片 | 线索出现、误导和新疑问 |

#### 2.8.3 如何生成娱乐游戏场景

用这个公式：

```text
新世界规则 + 主角旧缺陷 + 类型卖点 = 娱乐游戏场景
```

示例方向：

| 前提 | 娱乐游戏场景 |
|---|---|
| 身体互换 | 用对方身份上班、见家人、面对恋人、体验身体限制 |
| 公路治愈 | 每一站遇到不同价值观的人，迫使主角改变一点点 |
| 超能力 | 主角测试能力、滥用能力、被能力反噬 |
| 职场喜剧 | 主角误解规则，却意外戳破组织荒唐 |
| 怪物片 | 主角逐步发现怪物规则，错误试探导致伤亡 |
| 侦探片 | 错误线索、新证人、谎言、半真相层层出现 |

#### 2.8.4 娱乐游戏的分段

娱乐游戏通常可以设计 5-8 个桥段：

```text
1. 初入新世界：主角不懂规则。
2. 第一次尝试：主角用旧方法应对。
3. 意外成功：旧方法短暂有效。
4. 新规则展示：世界比想象中复杂。
5. 关系推进：B 故事提供另一种视角。
6. 代价预埋：后半段会反噬的缺陷出现。
7. 中点前冲刺：主角以为自己掌握局面。
```

#### 2.8.5 诊断问题

```text
这部分是否像海报和预告片承诺的电影？
如果删掉这部分，观众最期待的卖点是否消失？
每个桥段是否都让主角学到一点或错得更深一点？
是否只是散装笑点、散装奇观、散装线索？
```

#### 2.8.6 常见问题

1. 娱乐游戏没有娱乐，也没有类型满足。
2. 所有桥段都只是换地点。
3. 主角没有在桥段中变化。
4. 桥段之间没有升级。
5. 把真正的卖点拖到太晚才出现。
6. 第二幕前半仍在解释设定，没有让设定运转。

#### 2.8.7 修复方法

```text
列出 10 个只有这个前提才能出现的场景。
删掉任何普通故事也能出现的桥段。
让每个桥段都改变关系、信息、风险或主角自我认知。
在中点前安排一次“我好像掌握了”的公开展示。
```

### 2.9 中点

#### 2.9.1 节拍定位

中点是故事的“神经汇聚点”。它不是普通转折，而是整部电影从“探索前提”转向“承担后果”的位置。中点之后，故事必须变重，主角不能再只是玩、试探、逃避或误打误撞。

它必须做几件事：

1. 结束单纯探索。
2. 让主角公开获得或失去某种东西。
3. 提高赌注。
4. 让敌人或压力系统真正注意到主角。
5. 让 A 故事和 B 故事交汇。
6. 迫使主角宣告新身份或新策略。
7. 让倒计时或赌注明显提高。
8. 让后半段的敌人/压力系统开始精准攻击主角。

中点两种类型：

| 类型 | 表现 | 后果 |
|---|---|---|
| 伪胜利 | 主角得到以为想要的东西 | 后面证明还没学会主题 |
| 伪失败 | 主角失去以为需要的东西 | 后面逼出真正需求 |

#### 2.9.2 中点的四个标志

| 标志 | 说明 |
|---|---|
| 公开展示 | 主角新身份、新能力、新关系被看见 |
| 赌注提高 | 赢/输的代价变大 |
| A/B 交汇 | 外部目标和内部关系发生碰撞 |
| 无法回头 | 主角再也不能假装只是试试看 |

#### 2.9.3 伪胜利怎么写

伪胜利表面上是主角得到想要的东西：

1. 赢得比赛。
2. 得到职位。
3. 进入关系。
4. 掌握能力。
5. 找到线索。
6. 获得认可。
7. 到达目的地。

但它必须暗藏问题：

```text
主角得到的是 want，不是 need。
主角赢了外部目标，却加深内部缺陷。
主角越成功，后面摔得越重。
```

#### 2.9.4 伪失败怎么写

伪失败表面上是主角失去以为重要的东西：

1. 被羞辱。
2. 被拒绝。
3. 被揭穿。
4. 丢掉任务。
5. 失去同伴。
6. 计划失败。

但它必须暗藏机会：

```text
主角失去错误目标，开始接近真正需求。
```

#### 2.9.5 中点检查

```text
中点前后，故事有没有明显变重？
主角还有没有退路？
敌人是否更清楚主角是谁？
B 故事是否给主题加压？
有没有公开展示？
有没有倒计时或赌注升级？
```

#### 2.9.6 常见问题

1. 中点只是又发生一件事。
2. 中点没有改变后半段策略。
3. 中点和 B 故事无关。
4. 中点没有公开性，没人知道主角变化。
5. 中点没有提高赌注。
6. 中点以后仍然重复娱乐游戏。

#### 2.9.7 修复方法

```text
让中点成为一次公开胜利或公开失败。
让主角的新身份被敌人看见。
让主角得到 want 或失去 want。
增加倒计时、金钱、生命、关系或名誉代价。
让 B 故事人物在中点改变主角对主题的理解。
```

### 2.10 坏蛋逼近

#### 2.10.1 节拍定位

坏蛋逼近是中点后到一无所有前的压力收紧段。它的任务不是简单“让坏人更坏”，而是让外部敌人和内部缺陷一起证明：主角在中点得到的东西不稳，他的旧方法撑不到结尾。

坏蛋不一定是人，也可以是：

1. 疾病。
2. 贫穷。
3. 制度。
4. 家庭压力。
5. 时间。
6. 旧创伤。
7. 主角自己的错误信念。

坏蛋逼近必须包含两层：

| 层面 | 内容 |
|---|---|
| 外部 | 反派、任务、灾难、追杀、制度开始收紧 |
| 内部 | 团队分裂、关系破裂、主角旧缺陷反噬 |

#### 2.10.2 坏蛋逼近的压力来源

| 压力 | 写法 |
|---|---|
| 反派调整策略 | 敌人理解主角弱点后精准打击 |
| 时间收紧 | 倒计时出现或缩短 |
| 资源减少 | 钱、工具、盟友、信息逐渐失去 |
| 关系破裂 | 主角旧缺陷伤害 B 故事人物 |
| 秘密暴露 | 谎言开始失控 |
| 内部争夺 | 团队开始互相怀疑 |
| 主题反噬 | 主角拒绝学习主题，代价显现 |

#### 2.10.3 写作步骤

```text
1. 中点后让敌人意识到主角威胁。
2. 让敌人或压力系统改变策略。
3. 让主角继续使用旧方法。
4. 旧方法短期还能撑住，但代价越来越高。
5. 让团队或亲密关系开始裂。
6. 让前面铺垫的缺陷爆炸。
7. 把主角推到一无所有。
```

#### 2.10.4 常见失败

1. 中点后只是重复前半段。
2. 反派没有调整策略。
3. 主角团队没有内部裂缝。
4. 压力没有变具体。
5. 坏蛋逼近只有外部动作，没有内部崩坏。
6. 主角没有犯错，只是被动受害。
7. 一无所有来得突然，没有逐步压迫。

#### 2.10.5 修复方法

```text
给敌人一个中点后的新计划。
让主角的中点胜利招来更大后果。
让 B 故事关系被主角旧缺陷伤害。
让每一场坏蛋逼近都拿走主角一个资源。
```

### 2.11 一无所有

#### 2.11.1 节拍定位

一无所有是旧方法彻底失败的时刻。它不是“情况很糟”，而是主角终于失去继续欺骗自己的条件。

必须带有“死亡气息”，可以是真死亡，也可以是象征性死亡：

1. 导师死去。
2. 关系结束。
3. 梦想破灭。
4. 身份暴露。
5. 被赶出团队。
6. 失去家。
7. 失去身体能力。
8. 最重要的道具被毁。
9. 主角以为自己害死别人。

#### 2.11.2 合格标准

```text
主角不能再用原来的方式继续。
```

更严格的标准：

```text
主角不只是输了，而是他赖以生存的错误信念被事实打碎。
```

#### 2.11.3 死亡气息怎么写

死亡气息不一定要死人。它可以是：

| 死亡类型 | 表现 |
|---|---|
| 现实死亡 | 导师、亲人、同伴死亡 |
| 关系死亡 | 分手、决裂、背叛 |
| 身份死亡 | 被开除、身份暴露、名誉毁掉 |
| 梦想死亡 | 比赛失败、作品被毁、资格取消 |
| 道德死亡 | 主角发现自己成了讨厌的人 |
| 世界死亡 | 家被毁、组织崩塌、旧秩序失效 |
| 象征死亡 | 道具破碎、宠物死亡、照片烧毁 |

#### 2.11.4 一无所有与中点的对应

| 中点 | 一无所有 |
|---|---|
| 伪胜利 | 胜利代价爆炸，主角真正失败 |
| 伪失败 | 主角跌到更深，但看见真正方向的前提出现 |

#### 2.11.5 常见问题

1. 一无所有只是又输了一次。
2. 没有死亡气息。
3. 主角还有太多退路。
4. 一无所有和主角缺陷无关。
5. 失败来自外部运气，不来自主角旧方法。
6. 观众不觉得这是最低点。

#### 2.11.6 修复方法

```text
让主角亲手造成一部分失败。
让 B 故事关系破裂。
拿走主角最依赖的工具、身份或借口。
加入死亡气息。
证明主角开场的信念已经走到尽头。
```

### 2.12 灵魂黑夜

#### 2.12.1 节拍定位

灵魂黑夜是主角真正感受失败的段落。这里不要急着救主角，也不要急着给答案。这个节拍的价值在于让主角停止辩解，第一次看见自己。

不要急着给解决方案。观众需要看到：

1. 主角承认旧方法失败。
2. 主角看见自己真正的缺陷。
3. 主角失去自我辩解。
4. B 故事的主题开始回响。

#### 2.12.2 灵魂黑夜要写什么

1. 主角的沉默。
2. 主角回到开场缺陷的废墟里。
3. 主角看见自己伤害过谁。
4. B 故事人物的话开始回响。
5. 主角第一次承认“我错的不是策略，是我这个人看世界的方式”。

#### 2.12.3 灵魂黑夜的表现方式

| 表现 | 写法 |
|---|---|
| 独处 | 主角在空房间、车里、街边、病房、雨中 |
| 失败回声 | 前面道具、照片、录音、旧话重新出现 |
| 错误重现 | 主角想再用旧方法，但已经没人回应 |
| 主题回响 | B 故事人物的话在此刻变成真相 |
| 小行动 | 主角做一件微小但不同于开场的事 |

#### 2.12.4 常见失败

1. 一无所有后立刻反击，没有消化。
2. 灵魂黑夜只是哭，不产生领悟。
3. 领悟来自别人灌输，不来自主角经历。
4. 灵魂黑夜太短，观众没感到主角真的被打碎。
5. 主角总结得太清楚，像作者发言。
6. 没有 B 故事回响。

#### 2.12.5 修复方法

```text
让主角先沉默，再理解。
用前面铺垫的物件触发领悟。
让主角承认一个以前绝不会承认的事实。
不要让配角替主角说出所有答案。
让解决方案从主题领悟自然出现。
```

---

### 2.13 第三幕衔接点

#### 2.13.1 节拍定位

第三幕衔接点是 A 故事和 B 故事合流，主角找到新办法的时刻。它不是“突然想到办法”，而是主角终于理解主题之后，做出的主动选择。

新办法必须来自：

1. 主角在 B 故事中学到的东西。
2. 主角在第二幕犯错后的反省。
3. 主角放弃旧欲望后看见的真正需求。

#### 2.13.2 合格标准

```text
主角主动选择新方式进入最终行动。
```

#### 2.13.3 第三幕方案必须同时解决两件事

| 层面 | 要解决什么 |
|---|---|
| A 故事 | 外部目标、反派、任务、灾难、案件 |
| B 故事 | 关系、主题、主角错误信念 |

如果第三幕只解决 A 故事，它会空；如果只解决 B 故事，它会散。两者必须合并。

#### 2.13.4 写作步骤

```text
1. 主角从灵魂黑夜中得到主题领悟。
2. 主角意识到旧目标或旧方法不对。
3. B 故事提供一个新角度、工具或勇气。
4. 主角制定最终行动。
5. 主角主动进入第三幕。
```

#### 2.13.5 常见问题

1. 解决方案从天而降。
2. 配角告诉主角该怎么办。
3. 主角没有改变，只是又试一次旧方法。
4. B 故事和第三幕无关。
5. 第三幕行动没有代价。

#### 2.13.6 修复方法

```text
把第三幕方案和主题句绑定。
让主角做一个开场时做不到的选择。
让 B 故事人物或关系提供关键但不替主角完成。
让最终行动需要主角牺牲错误欲望。
```

### 2.14 结局

#### 2.14.1 节拍定位

结局不是大场面堆砌，而是主角的终极考试。观众真正想看的不是主角能不能赢，而是他能不能用新的自己赢。

结局必须证明：

1. 主角真的变了。
2. 主角能用新方式解决旧问题。
3. 主要压力源被处理。
4. 新世界被建立。
5. 观众情绪得到满足。

#### 2.14.2 结局的五要点写法

结局可以按五步组织：

```text
召集团队 -> 执行计划 -> 高塔意外 -> 深入挖掘 -> 新计划成功
```

每一步的功能、写法与示例详见《结构C_节奏分场与第三幕.md》第 2 章「五要点结局」，此处不重复。

#### 2.14.3 结局中的“新世界”

主角不是只打败敌人，还要建立新秩序。

| 类型 | 新世界表现 |
|---|---|
| 家庭片 | 家庭关系换了规则 |
| 职场片 | 主角不再被旧制度定义 |
| 爱情片 | 两人不只是复合，而是用新方式相处 |
| 动作片 | 主角救人方式体现主题 |
| 悬疑片 | 真相改变了世界观 |
| 公路片 | 主角回家，但已经不是原来的人 |
| 超级英雄 | 主角接受能力的责任和代价 |

#### 2.14.4 常见问题

1. 结局靠外力救场。
2. 反派突然犯低级错误。
3. 主角没有使用主题领悟。
4. 大场面很热闹，但人物没变化。
5. B 故事人物被当成奖品。
6. 胜利没有代价。
7. 结局没有处理主要压力源。

#### 2.14.5 修复方法

```text
让最终胜利必须依赖主角新学会的品质。
让主角牺牲开场时最执着的错误欲望。
让 B 故事关系参与解决，但不替主角解决。
让高塔意外摧毁主角的旧计划。
让深入挖掘成为全片最能证明变化的动作。
```

### 2.15 终场画面

#### 2.15.1 节拍定位

终场画面要和开场画面对照。它不是结尾台词，也不是字幕前的漂亮镜头，而是全片变化的证据。

观众看见终场画面时，应立刻感到：

```text
这个世界已经不一样。
这个人已经不一样。
开场的问题已经被回答。
```

| 开场 | 终场 |
|---|---|
| 孤独 | 连接 |
| 控制 | 倾听 |
| 逃避 | 面对 |
| 谎言 | 真相 |
| 旧制度 | 新秩序 |
| 不能上路 | 主动启程 |
| 被困 | 自由 |

#### 2.15.2 终场画面怎么设计

最有效的终场画面通常不是解释，而是一个可视化对照：

| 开场动作 | 终场动作 |
|---|---|
| 主角一个人吃饭 | 主角和他人共享一顿饭 |
| 主角关门 | 主角开门 |
| 主角逃离镜头 | 主角走向镜头 |
| 主角拒绝求助 | 主角主动伸手 |
| 主角隐藏身份 | 主角公开承认 |
| 主角被制度支配 | 主角重新定义规则 |
| 主角无法表达 | 主角用行动表达 |

#### 2.15.3 终场画面和主题的关系

终场画面必须证明主题，不要讲主题。

弱结尾：

```text
主角说：我终于学会爱了。
```

强结尾：

```text
开场时主角总是替别人点菜，终场时他把菜单递给对方，等对方自己选择。
```

#### 2.15.4 常见问题

1. 终场画面只是大家笑。
2. 终场画面没有和开场呼应。
3. 结尾靠台词总结变化。
4. 主角外部成功了，但内在变化看不见。
5. 终场画面没有留情绪余味。

#### 2.15.5 修复方法

```text
回看开场画面，找一个可反转的动作、空间、关系或物件。
让主角用一个小动作证明大变化。
不要解释，让画面说话。
```

### 2.16 节拍写作总检查表

写完 15 节拍后，用下面清单检查：

```text
1. 开场和终场是否形成清楚对照？
2. 主题是否在前 5 分钟被提出，并在结尾被行动证明？
3. 铺垫是否展示“不改变就会死”？
4. 催化剂是否不可逆？
5. 争论是否让主角的抗拒合理？
6. 第二幕是否由主角主动进入？
7. B 故事是否承载主题，而不是装饰？
8. 娱乐游戏是否兑现海报承诺？
9. 中点是否公开、提高赌注、让故事变重？
10. 坏蛋逼近是否同时包含外部压力和内部崩坏？
11. 一无所有是否带有死亡气息？
12. 灵魂黑夜是否让主角看见真正缺陷？
13. 第三幕衔接点是否来自 A/B 故事融合？
14. 结局是否用新自我解决旧问题？
15. 终场画面是否不用解释也能证明变化？
```
