## 1. 把直白情绪改成具体事实

问题版本：

```text
A：你让我很失望。
B：我不是故意的。
A：我真的很难过。
```

问题诊断：情绪名称太多；没有具体事件；B 的反应没有策略；场景没有推进。

改写版本：

```text
A：我给你留了前排的位置。
B：我知道。
A：开场十分钟以后，工作人员问我要不要把那把椅子撤掉。
B：你怎么说？
A：我说不用。它至少比你准时。
```

为什么有效：用“前排位置”和“椅子”承载失望；A 没说难过，但观众能感到难过；最后一句带刺，关系发生变化。

## 2. 把信息交代改成冲突

问题版本：

```text
A：这个芯片可以储存人的记忆。
B：如果损坏，人就会失去过去十年的记忆。
A：所以我们必须保护它。
```

问题诊断：像说明书；没有角色立场；信息没有压力。

改写版本：

```text
B：你把它摔了？
A：只是外壳裂了。
B：外壳裂了，她可能醒来以后不认识自己的孩子。
A：你之前说有备份。
B：我说的是理论上。理论上我也可以现在不揍你。
```

为什么有效：信息通过事故进入；技术后果变成情感后果；“理论上”既交代设定，也制造人物情绪。

## 3. 把互骂改成争吵升级

问题版本：

```text
A：你太自私了。
B：你才自私。
A：你从来不考虑别人。
B：你也一样。
```

问题诊断：指控重复；没有具体行为；没有升级层次。

改写版本：

```text
A：你把我妈的电话挂了。
B：她第三次问我们什么时候结婚。
A：你可以把手机给我。
B：我可以。但你会笑着回答她，然后回来怪我没替你挡。
A：所以你替我决定？
B：不。我只是替你做了你一直想做、又想让我背锅的事。
```

为什么有效：从具体行为开始；争论从电话升级到关系责任；B 的反击揭露 A 的隐藏需求。

## 4. 把假喜剧改成人物喜剧

问题版本：

```text
A：哈哈，这也太搞笑了。
B：是啊，真好笑。
A：我们真倒霉。
```

问题诊断：台词在宣布好笑；没有人物自尊；没有升级。

改写版本：

```text
A：电梯停了。
B：不算停。它只是拒绝参与我们的人生下半场。
A：你能不能别在密闭空间里做文学评论？
B：可以。那我换成工程评论：我们会死在六楼和七楼之间，很有中产气质。
```

为什么有效：B 的幽默来自防御机制；A 承担正常人视角；同一事实被不同声音处理。

## 5. 把反派废话改成价值观压迫

问题版本：

```text
反派：我要毁掉你们所有人。
主角：你不会成功的。
反派：我很强大。
```

问题诊断：反派只有恶意，没有逻辑；主角反驳空泛；没有诱惑和主题。

改写版本：

```text
反派：你救他们，是因为他们无辜？
主角：他们本来就不该死。
反派：没人本来该死。可你每天都在决定先救谁。
主角：那不是一回事。
反派：当然不是。你有制服，所以你的选择叫责任。我的选择叫罪。
```

为什么有效：反派用主角的价值观反压主角；对白提出主题问题；反派不需要喊叫也有危险。

## 6. 把告白改成克制试探

问题版本：

```text
A：我喜欢你。
B：我也喜欢你。
A：我们在一起吧。
```

问题诊断：太早说破；没有风险；没有具体情境。

改写版本：

```text
A：你明天还来吗？
B：你店里咖啡这么难喝，我为什么要来？
A：因为你昨天说难喝，今天还是来了。
B：我这个人对错误比较有耐心。
A：那你能不能再错一阵子？
```

为什么有效：咖啡成为情感载体；B 用嘴硬掩盖靠近；A 的请求没有直说“在一起”，但方向清楚。

## 7. 把家庭争执改成旧伤爆发

问题版本：

```text
父亲：你不听话。
儿子：你总是控制我。
父亲：我是为你好。
```

问题诊断：都是概念词；没有家庭细节；旧伤没有落点。

改写版本：

```text
父亲：票我退了。
儿子：你凭什么？
父亲：那个城市没人照顾你。
儿子：我二十六了。
父亲：你十二岁那年发烧，也是这么说自己没事。
儿子：你每次都这样。只要我想走，你就拿那个晚上把门锁上。
```

为什么有效：“退票”是具体控制行为；父亲的控制里有担心；儿子指出旧事如何被反复使用。

## 8. 把审讯问答改成陷阱

问题版本：

```text
警察：你杀了他吗？
嫌疑人：没有。
警察：你说谎。
```

问题诊断：问题太直；嫌疑人没有暴露空间；警察没有策略。

改写版本：

```text
警察：你认识死者？
嫌疑人：不认识。
警察：那你怎么知道他是男的？
嫌疑人：新闻里说的。
警察：新闻没说性别。
嫌疑人：你刚才说了。
警察：我说的是死者。
```

为什么有效：小问题制造漏洞；嫌疑人的补救继续暴露；警察控制节奏。

## 9. 把谈判改成利益交换

问题版本：

```text
A：你必须帮我。
B：我为什么帮你？
A：因为这是正确的事。
```

问题诊断：只靠道德请求；没有筹码；谈判对象没有真实顾虑。

改写版本：

```text
A：你不需要相信我。
B：很好，我本来也没有计划。
A：你只需要相信他们会先查你的账。
B：威胁？
A：顺序。我排在你后面。
B：你有什么？
A：能让你排到我后面的东西。
```

为什么有效：A 不求信任，给出利益；B 的态度明确；谈判围绕风险顺序展开。

## 10. 把群戏轮流发言改成功能分工

问题版本：

```text
A：我觉得应该报警。
B：我觉得不应该。
C：我也不知道。
D：大家冷静。
```

问题诊断：每个人只是表达观点；没有利益差异；没有阵营变化。

改写版本：

```text
A：报警。
B：报了警，仓库里的货怎么解释？
C：那不报警，人怎么解释？
D：先别说人，说监控。
A：你删了？
D：我保存了。
B：你疯了？
D：我只是比你们早半小时知道，这个房间里没人值得信任。
```

为什么有效：A 推进，B 阻拦，C 提出现实，D 搅局并翻转；每句都有新信息；阵营关系被改变。

## 11. 把动作废话改成危机短句

问题版本：

```text
A：我们现在非常危险，敌人马上要追上来了。
B：我们应该快点逃跑。
A：我同意。
```

问题诊断：描述观众已知信息；没有动作决策；节奏太慢。

改写版本：

```text
A：车钥匙。
B：断了。
A：会开线吗？
B：我只会开会。
A：那闭嘴，推车。
```

为什么有效：短句推动动作；B 的人物喜剧在危机中出现；A 的命令改变下一步行动。

## 12. 把悬疑解释改成半真话

问题版本：

```text
A：我没有杀人。
B：可是你在现场。
A：我是去救他的。
```

问题诊断：防御太直接；没有误导；真相空间太小。

改写版本：

```text
B：你进过他的房间。
A：我站在门口。
B：血在窗边。
A：所以我没进去。
B：你怎么知道血在窗边？
A：因为我听见他从那边倒下。
```

为什么有效：A 的话可能真也可能假；细节推进怀疑；最后一句打开新的画面。

## 13. 把人物介绍改成声音暴露

问题版本：

```text
A：我是一个很聪明但不善社交的程序员。
B：我是他的朋友，比较幽默。
```

问题诊断：角色自我介绍；没有互动；性格没有通过语言体现。

改写版本：

```text
A：你把我的键盘挪了三厘米。
B：你怎么知道？
A：空格键现在面对的是失败的角度。
B：你单身不是没有原因的。
A：我知道。我做过表。
```

为什么有效：A 的精确和怪癖直接呈现；B 的吐槽承担喜剧功能；不需要说明人物标签。

## 14. 把主题台词改成角色利益

问题版本：

```text
A：自由是最重要的。
B：安全才是最重要的。
```

问题诊断：像辩论题；没有具体代价；角色不承担后果。

改写版本：

```text
A：你说安全的时候，钥匙都在你手上。
B：因为我知道门外有什么。
A：我也知道。我只是受够了每次都由你决定我该怕什么。
```

为什么有效：“钥匙”和“门”让抽象主题具体化；双方都讲得通；主题变成关系问题。

## 15. 把道歉改成真正承担

问题版本：

```text
A：对不起。
B：你伤害了我。
A：我以后不会了。
```

问题诊断：道歉没有具体内容；B 只负责受伤；没有信任重建。

改写版本：

```text
A：我不该把那件事告诉他们。
B：你是不该，还是不该让我知道？
A：两个都算。但第二个更像我。
B：至少这次你没把诚实说成勇敢。
A：因为我这次只是害怕。
```

为什么有效：A 承认具体行为；B 精准指出更深问题；A 最后承认动机，关系有微小推进。

## 16. 把高概念设定改成新手犯错

问题版本：

```text
A：这个世界里时间会倒流。
B：但是只有十二分钟。
A：所以我们要利用这个规则。
```

问题诊断：设定没有被体验；没有角色压力；信息像旁白。

改写版本：

```text
B：你刚才说过这句话。
A：我每天都说很多聪明话。
B：不，十二分钟前。你还打翻了杯子。
A：杯子好好的。
B：再等三秒。
（杯子掉下去。）
A：这不是预言。
B：对。是重播。
```

为什么有效：规则通过事件展示；A 的人物声音保留；观众先看见异常，再理解设定。

## 17. 把阶层冲突改成具体账单

问题版本：

```text
A：你们有钱人不懂穷人的痛苦。
B：你不要仇富。
```

问题诊断：口号化；缺少具体物；双方都像观点机器。

改写版本：

```text
A：你刚才把半杯酒倒了。
B：不好喝。
A：那半杯够我妈买三天药。
B：你没必要这么说。
A：我也觉得没必要。可你倒得太轻松了。
```

为什么有效：阶层差异落在半杯酒和药费；B 的轻松成为伤害；A 的愤怒具体可信。

## 18. 把冷暴力改成沉默策略

问题版本：

```text
A：你为什么不理我？
B：我不想说话。
A：你太冷漠了。
```

问题诊断：直接说问题；沉默没有具体行为；缺少关系细节。

改写版本：

```text
A：你把我的杯子收进柜子了。
B：洗好了。
A：以前你都放在外面。
B：外面灰大。
A：我们家什么时候开始怕灰了？
B：从只剩我一个人擦的时候。
```

为什么有效：杯子位置表达关系距离；B 的冷不是无话，而是惩罚；最后一句揭示长期不满。

## 19. 把师徒压迫改成奖惩控制

问题版本：

```text
老师：你太差了。
学生：我会努力。
老师：你不够努力。
```

问题诊断：羞辱不精准；没有认可诱导；学生没有被迫选择。

改写版本：

```text
老师：刚才第三小节，你有两秒像个人。
学生：只有两秒？
老师：你想庆祝，还是想知道剩下的时间你像什么？
学生：我再来一遍。
老师：不是再来一遍。是把那两秒找回来，别让它们觉得投错了人。
```

为什么有效：老师先给极小认可；认可立刻变成羞辱；学生被迫追逐认可。

## 20. 把结尾收干改成留余波

问题版本：

```text
A：我们和好了。
B：是的，以后不要再吵架。
A：好。
```

问题诊断：情绪被说死；没有余波；不像真实关系。

改写版本：

```text
A：粥在锅里。
B：我以为你走了。
A：我走了。又回来关火。
B：那你还走吗？
A：先把粥喝了。冷了就真的只能倒掉。
```

为什么有效：不直接说和好；“关火”和“粥”承载关系修复；结尾保留不确定，但情绪有变化。

## 21. 改写流程模板

Agent 在改写任何用户台词时，按下面步骤输出：

```text
【原稿诊断】
1. 场景目标是否清楚：
2. 人物声音是否区分：
3. 潜台词是否存在：
4. 信息是否自然：
5. 场景是否发生变化：

【改写策略】
1. 保留的信息：
2. 增强的冲突：
3. 增强的人物声音：
4. 增加的潜台词：
5. 结尾变化：

【改写版本】
（给出剧本格式或对白格式）

【说明】
1. 哪些句子承担潜台词：
2. 哪些句子推动冲突：
3. 哪些句子塑造人物：
4. 还可以继续加强的方向：
```

## 22. 多版本改写模板

同一个场景可以要求 Agent 输出三版：

```text
版本A：更喜剧
重点：错位、互损、升级、回调。

版本B：更压迫
重点：少说、问题、沉默、地位差。

版本C：更克制
重点：具体物件、半句话、行动替代情绪。
```

示例场景：角色发现朋友背叛自己。

更喜剧：

```text
A：你把我的方案发给他了？
B：发这个词太主动了。
A：那叫什么？
B：它离开了我的电脑。
A：带着你的署名？
B：它路上可能缺乏安全感。
```

更压迫：

```text
A：他用了我的方案。
B：我不知道。
A：我还没说是谁。
B：你刚才看了我一眼。
A：因为我想知道你什么时候开始提前准备答案。
```

更克制：

```text
A：我今天看到他的演示了。
B：像你的？
A：不。像我没来得及说出口的。
B：我可以解释。
A：你已经替我解释给他听了。
```

## 23. 对白评分表

总分 100。

| 维度 | 分值 | 判断标准 |
|---|---:|---|
| 场景目标 | 10 | 是否明确知道每个角色想要什么 |
| 冲突强度 | 10 | 是否存在真实阻力和不可兼得 |
| 潜台词 | 15 | 是否避免直白说心理，是否有不能说的话 |
| 人物声音 | 15 | 不同角色是否有明显语言差异 |
| 推进效率 | 10 | 每几句是否带来新信息或新变化 |
| 节奏 | 10 | 句长、停顿、打断是否匹配场景 |
| 情景类型完成度 | 10 | 喜剧/压迫/浪漫/悬疑等类型机制是否成立 |
| 信息自然度 | 5 | 背景和设定是否自然进入冲突 |
| 结尾后果 | 10 | 场景结束后关系、信息或决定是否改变 |
| 可拍性 | 5 | 是否能被演员表演，是否有动作和反应 |

评分解释：

```text
90-100：可进入剧本初稿，人物声音和场景功能都成立。
75-89：方向正确，需要压缩、增强转折或区分人物。
60-74：有基本冲突，但台词仍偏直白或重复。
```
