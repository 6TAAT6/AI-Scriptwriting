## 1. 一句话故事线

### 1.1 好故事线的功能

故事线不是广告语，而是创作检查工具。它必须帮助你判断：

1. 主角是谁。
2. 主角在什么边缘状态。
3. 什么事件打破现状。
4. 主角进入什么新世界。
5. 他想要什么。
6. 阻力是什么。
7. 故事的特殊卖点是什么。
8. 主题变化是什么。

### 1.2 基础模板

```text
当【催化事件】打破【主角】原本【停滞/错误/缺陷】的生活后，
他/她必须进入【反题世界】，
在【外部目标】的追逐中，
面对【主要阻力】，
最终学会【主题真相】。
```

### 1.3 加强模板

```text
在一个【停滞 = 死亡】的边缘时刻，
一个【有缺陷的主角】因为【催化剂】被迫进入【第二幕新世界】，
并在【B 故事人物/关系】的影响下，
于【中点】获得伪胜利或伪失败；
当【坏人/压力系统】逼近并导致【一无所有】后，
主角必须领会【主题】，
用新的方式完成【最终行动】。
```

### 1.4 故事线诊断表

| 问题 | 合格标准 | 常见失败 |
|---|---|---|
| 主角清楚吗 | 一句话能知道跟谁走 | 只讲世界观，不讲人 |
| 目标清楚吗 | 能看到角色要追什么 | 只有情绪，没有行动 |
| 阻力清楚吗 | 有人/事/制度阻止主角 | 冲突太软 |
| 卖点清楚吗 | 有海报感或强情境 | 像普通生活记录 |
| 类型清楚吗 | 能进入某个故事家族 | 混合但无主类型 |
| 变化清楚吗 | 主角会从 A 变成 B | 只有事件，没有弧光 |

### 1.5 三种失败故事线

#### 太平淡

表现：

```text
一个年轻人经历挫折后重新找到自己。
```

问题：任何故事都可以这么说，没有特殊困境、类型承诺和外部目标。

修复：

```text
给主角一个具体身份、一个不可逃避的外部目标、一个有时间压力的阻力。
```

#### 太复杂

表现：

```text
一部关于多维宇宙、家族血统、政治阴谋、古老预言和人工智能觉醒的史诗。
```

问题：设定很多，但观众不知道跟谁走。

修复：

```text
先回答：谁在什么压力下必须做什么选择？
```

#### 刻意保守秘密

表现：

```text
一个男人发现自己的人生并不是他想的那样。
```

问题：为了不剧透，把故事真正卖点藏掉了。

修复：

```text
至少说出故事类型、核心反转的方向和主角要面对的选择。
```

## 2. 主角选择

### 2.1 谁是最适合的主角

最适合的主角不是最酷的人，而是：

1. 被这个故事伤得最深的人。
2. 在这个故事中变化最大的人。
3. 最需要学习主题的人。
4. 最能体现外部冲突和内部缺陷的人。
5. 不行动就会失去最多的人。

### 2.2 主角四问

| 问题 | 说明 |
|---|---|
| 他想要什么 | 外部目标，观众能看见 |
| 他缺什么 | 内部需求，主角自己未必知道 |
| 他害怕什么 | 让他拒绝改变的东西 |
| 他必须牺牲什么 | 第三幕证明变化的代价 |

### 2.3 错误主角警报

如果出现以下情况，可能选错主角：

1. 最精彩的变化发生在配角身上。
2. 主角只是旁观事件。
3. 主角没有做关键选择。
4. 主角在结尾没有比开场更不同。
5. 观众更想知道另一个人的故事。

### 2.4 双主角处理

双主角故事也要判断“结构主角”：

| 类型 | 判断方法 |
|---|---|
| 搭档片 | 谁因对方改变最大，谁就是结构主角 |
| 爱情片 | 谁的错误信念被关系改写，谁更接近结构主角 |
| 兄弟/亲情片 | 谁从自我保护走向理解对方，谁承担核心弧光 |
| 群戏 | 找主题承载者，或按不同节拍分配 POV |

## 3. 十种故事类型

类型不是题材标签，而是故事运转方式。写作时先判断深层类型，再决定表面题材。表面题材与深层类型常常错位，例如：公路片的深层类型多为金羊毛；灵魂互换是如愿以偿；亲情修复是伙伴之情或变迁仪式；灾难逃生是麻烦家伙；校园喜剧是愚者成功或被制度化；悬疑犯罪是推理侦探或鬼怪屋；超级英雄片可能是超级英雄、麻烦家伙或被制度化。

以下 3.1-3.10 只保留各类型的公式、核心情绪与核心诊断问题；必备元素、典型节拍、常见失败与修复动作统一见 3.11 总表。

### 3.1 鬼怪屋

公式：

```text
怪物 + 封闭空间 + 原罪
```

核心情绪：逃不掉的恐惧。

适合生成方向：密室恐怖、家庭怪物、校园怪谈、科幻怪物、心理压迫型惊悚。

同类片例检索：`python3 scripts/search_library.py "鬼怪屋" --detail l1`

核心诊断问题：

```text
怪物是不是太弱？
房子是不是太容易逃？
原罪是不是不清楚？
怪物和主题是否有关？
主角是否因面对怪物而改变？
```

### 3.2 金羊毛

公式：

```text
道路 + 团队 + 奖品
```

核心情绪：表面在找奖品，真正是在路上变成另一个人。

适合项目方向：亲情公路片、跨国旅行、寻找亲人、送物任务、比赛之旅、流亡逃亡、治疗之旅。

同类片例检索：`python3 scripts/search_library.py "金羊毛" --detail l1`

核心诊断问题：

```text
每一站是否改变主角，而不只是换地点？
团队成员是否各有功能？
奖品是否足够具体？
旅程是否从外部任务变成内部成长？
```

### 3.3 如愿以偿

公式：

```text
愿望 / 魔法 / 超常机会 + 人物缺陷 + 代价教训
```

核心情绪：得到想要的东西后，才发现真正需要的不是它。

常见变体：

| 变体 | 写法 |
|---|---|
| 身体互换 | 通过对方身体理解对方人生 |
| 时间循环 | 被迫重复直到学会改变 |
| 超能力 | 欲望被放大，缺陷被暴露 |
| 读心 / 预知 | 控制信息反而破坏关系 |
| 身份变化 | 得到新身份，却失去真我 |

同类片例检索：`python3 scripts/search_library.py "如愿以偿" --detail l1`

核心诊断问题：

```text
魔法规则是否简单？
愿望是否来自主角缺陷？
魔法是否在中点后变成诅咒？
主角最后是否主动放弃错误愿望？
```

### 3.4 麻烦家伙

公式：

```text
普通人 + 突然大麻烦 + 求生行动
```

核心情绪：如果是我遇到这种事，我怎么办？

同类片例检索：`python3 scripts/search_library.py "麻烦家伙" --detail l1`

核心诊断问题：

```text
主角是否真的被逼到不能不行动？
麻烦是否从外部事件升级为人格考验？
观众是否会自然代入“我会怎么办”？
```

### 3.5 变迁仪式

公式：

```text
人生痛苦阶段 + 错误抵抗 + 接受真相
```

核心情绪：成长、衰老、失去、成瘾、离别、失败、亲人死亡等无法绕开的现实。

同类片例检索：`python3 scripts/search_library.py "变迁仪式" --detail l1`

核心诊断问题：

```text
主角抗拒的是什么？
痛苦是否足够具体？
结尾是否过度廉价治愈？
主角是否学会与痛苦共处？
```

### 3.6 伙伴之情

公式：

```text
两个不完整的人 + 冲突关系 + 彼此改变
```

核心情绪：我需要你，但我不想承认。

关系范围：爱情、兄弟、父子、搭档、师徒、人与非人伙伴。

同类片例检索：`python3 scripts/search_library.py "伙伴之情" --detail l1`

核心诊断问题：

```text
两人开场是否互相缺少？
他们为什么不能轻易分开？
中点是否让关系公开升级？
一无所有是否发生分离或背叛？
结尾是否由关系变化解决 A 故事？
```

### 3.7 推理侦探

公式：

```text
案件 / 谜团 + 调查者 + 人性黑暗真相
```

核心情绪：重点不是谁干的，而是为什么世界会允许这件事发生。

同类片例检索：`python3 scripts/search_library.py "推理侦探" --detail l1`

核心诊断问题：

```text
谜团是否服务主题？
调查者是否被真相改变？
结尾是否改写前面所有信息？
是否把悬疑写成信息拖延？
```

### 3.8 愚者成功

公式：

```text
被低估的人 + 强大制度 / 精英世界 + 反常胜利
```

核心情绪：所谓聪明世界被一个“傻子”的真诚、直觉或偏执击败。

同类片例检索：`python3 scripts/search_library.py "愚者成功" --detail l1`

核心诊断问题：

```text
主角被低估的原因是否具体？
制度是否足够傲慢？
主角胜利是否来自其独特性，而不是突然变聪明？
```

### 3.9 被制度化

公式：

```text
个体 + 群体 / 组织 / 家庭 / 公司 / 监狱 + 归属与自由的冲突
```

核心情绪：留在体制里会死，离开体制也会痛。

同类片例检索：`python3 scripts/search_library.py "被制度化" --detail l1`

核心诊断问题：

```text
制度规则是否具体？
制度给主角什么好处，为什么难以离开？
谁代表制度诱惑？谁代表制度惩罚？
主角最后是逃离、改变，还是被吞噬？
```

### 3.10 超级英雄

公式：

```text
非凡者 + 普通世界 + 天赋的代价
```

核心情绪：拥有特殊能力的人如何承担孤独、责任和嫉妒。

同类片例检索：`python3 scripts/search_library.py "超级英雄" --detail l1`

核心诊断问题：

```text
主角的天赋是否带来痛苦？
普通世界为什么害怕或利用他？
反派是否是主角能力的阴影版本？
结尾是否体现责任，而不只是胜利？
```

### 3.11 十种类型规则总表（核心资产）

这个表用于快速判断一个创意是否真正兑现了深层故事类型。使用时先选主类型，再看副类型；主类型必须承担 A 故事的外部行动和结尾兑现，副类型主要补足人物关系、主题和情感厚度。

| 故事类型 | 必备元素 | 典型节拍 | 常见失败 | 修复动作 |
|---|---|---|---|---|
| 鬼怪屋 | 强大怪物；封闭空间；角色无法轻易离开；怪物与原罪、越界、贪婪或无知有关 | 开场展示规则被破坏；催化剂让怪物显形或留下不可否认的痕迹；娱乐游戏逐步展示怪物规则；中点出现“安全假象”或更大真相；一无所有让怪物夺走最重要的人、身份或退路；结局必须直面怪物和原罪 | 怪物太弱；空间太容易逃；角色只是等死；原罪和主题无关；结尾靠外力消灭怪物 | 加强怪物不可战胜感；封死退路并提高离开代价；把怪物规则和主角缺陷绑定；让结尾胜利来自主角承认或修正原罪 |
| 金羊毛 | 明确奖品、目的地或任务；阶段性旅程；团队或路上关系；奖品最终让位于成长 | 开场让主角困在旧地或旧身份；催化剂给出任务/奖品；第二幕上路；娱乐游戏每一站改变主角；中点接近奖品或发现奖品失真；一无所有让旅程断裂或团队分离；结局证明真正奖品是改变后的主角 | 只换地点不换压力；奖品不具体；团队成员没有功能；旅程和主角变化脱节 | 为每一站设置不同考验和代价；让队友分别代表诱惑、阻力、镜像和主题；在中点推翻奖品意义；让结尾选择牺牲奖品或重新定义奖品 |
| 如愿以偿 | 愿望、魔法或超常机会；简单清楚的规则；主角缺陷被放大；获得愿望必须付出代价 | 开场展示强烈缺失和错误欲望；催化剂让愿望机制出现；娱乐游戏享受新能力、新身份或新机会；中点愿望短暂满足；坏蛋逼近让愿望反噬；一无所有失去真正重要的东西；结局主动放弃错误愿望并选择真实关系或责任 | 魔法规则复杂；愿望不是来自缺陷；中段只展示好玩设定；结尾靠规则自动恢复；主角没有主动放弃 | 简化规则到一句话；让每次使用愿望都伤害关系或身份；中点后把礼物变成诅咒；让主角用牺牲完成恢复，而不是被动恢复 |
| 麻烦家伙 | 普通但不平庸的主角；突发大麻烦；持续升级的求生行动；麻烦逼出潜在能力 | 开场建立普通世界和主角小缺陷；催化剂用危机打断日常；第二幕主角被迫行动；娱乐游戏尝试旧方法求生；中点发现麻烦比想象更大；坏蛋逼近压缩时间、空间和资源；一无所有让旧方法彻底失效；结局用新能力主动反击或救人 | 麻烦不够大；主角可以轻易退出；危机只靠巧合推进；主角一直被动逃；外部事件没有变成人格考验 | 提高危机对生命、尊严、亲人或未来的威胁；设置退出代价；让每次求生选择暴露主角缺陷；把最后行动设计成主角主动承担风险 |
| 变迁仪式 | 无法逃避的人生痛苦阶段；主角错误抵抗；第二幕不断证明抵抗无效；结尾是接受真相而非消灭痛苦 | 开场展示主角正在否认变化；催化剂让痛苦无法再绕开；娱乐游戏尝试逃避、转移或控制；中点短暂以为可以回到过去；坏蛋逼近让旧抵抗伤害自己和他人；一无所有承认失去不可逆；结局以新行为和痛苦共处 | 痛苦太抽象；结尾廉价治愈；主角只是难过没有错误方法；外部事件太弱，不能逼他面对 | 把痛苦落到具体关系、身体、时间、债务或身份；写出主角错误抵抗的行动；让抗拒每次都制造新代价；结尾用新的生活方式而不是一句感悟收束 |
| 伙伴之情 | 两个不完整的人；关系中有冲突、互补和旧账；他们不能轻易分开；彼此改变 A 故事 | 开场分别展示两人的缺失；催化剂强迫绑定；娱乐游戏冲突、互补、误解和短暂默契；中点关系公开升级；坏蛋逼近让旧伤、秘密或价值观破坏关系；一无所有分离、背叛或失去信任；结局一方用学到的东西救另一方或让对方自由 | 两人只是一起行动；没有互补缺失；中点关系不升级；分离没有代价；结尾靠表白或道歉，不靠行动 | 给两人相反错误信念和互补能力；设置不能分开的外部机制；让每次合作都改变权力关系；一无所有必须打断关系；结尾用行动证明改变 |
| 推理侦探 | 有吸引力的案件或谜团；调查者；线索和误导；真相揭开人性、制度或道德腐败 | 开场展示表面秩序；催化剂出现异常、案件或委托；娱乐游戏收集线索、证人和假设；中点关键证据改变调查方向；坏蛋逼近让调查者被威胁或被真相污染；一无所有证明旧判断错误或调查者也在局中；结局揭开真相并改变世界观 | 只拖延信息；凶手答案和主题无关；调查者不被改变；线索靠临时解释；结尾只是公布答案 | 让每条线索同时解释旧疑点并制造新疑点；把案件主题和调查者旧伤连接；中点推翻核心假设；让真相带来道德代价，而不只是智力快感 |
| 愚者成功 | 被低估的主角；傲慢的精英世界或制度；主角独特弱点最终变成优势；胜利揭穿聪明世界的荒唐 | 开场展示主角被轻视但有独特性；催化剂把他推入精英规则；娱乐游戏用笨办法误打误撞破局；中点获得短暂认可或暴露更大嘲笑；坏蛋逼近精英世界反扑；一无所有主角几乎接受自己失败；结局用独特性赢下规则或改写规则 | 主角只是运气好；精英世界不够强；胜利来自突然变聪明；喜剧只靠出丑；结尾没有证明制度荒唐 | 明确主角被低估的具体原因；让精英规则看似合理但价值观虚伪；把主角弱点提前铺成能力；让最终胜利来自他一直被嘲笑的特质 |
| 被制度化 | 个体与组织、家庭、公司、监狱或群体的绑定；制度提供好处也吞噬自由；诱惑者和惩罚者；归属与自由冲突 | 开场展示制度如何定义主角；催化剂让主角看见裂缝；第二幕挑战或进入制度核心；娱乐游戏展示规则、诱惑和荒谬；中点短暂影响制度或被制度吞没；坏蛋逼近制度反扑并孤立个体；一无所有失去身份、归属或自由；结局逃离、改变、揭穿或被吞噬 | 制度规则不具体；只有坏人没有系统；主角为什么留下不清楚；反抗没有代价；结尾只是打败一个人 | 写清制度奖励、惩罚和日常流程；设置诱惑者与惩罚者；让主角从制度获得真实好处；每次反抗都失去资源或关系；结尾处理系统而不只处理反派 |
| 超级英雄 | 非凡者；普通世界；天赋的代价；反派是能力或价值观的阴影版本；责任高于胜利 | 开场展示天赋和孤独；催化剂迫使主角暴露或使用能力；第二幕进入使命；娱乐游戏测试能力边界；中点短暂被崇拜、被利用或误以为掌控力量；坏蛋逼近让能力伤害关系或公共信任；一无所有天赋变成诅咒；结局承担责任并付出代价 | 主角太强没有痛苦；能力只负责炫技；普通世界没有反应；反派和主角无镜像关系；结尾只是打赢 | 给能力设置代价、限制和公众误解；让普通世界利用、恐惧或嫉妒主角；把反派设计成主角错误道路的极端版本；让胜利必须牺牲身份、关系或自由 |

使用规则（含混合类型判断）：

```text
1. 先判断主类型：哪一类最能解释 A 故事的外部行动、中点和结局？
2. 再判断副类型：哪一类最能解释 B 故事、人物关系和主题变化？
3. 主类型至少要满足“必备元素”和“典型节拍”两列中的核心条件。
4. 如果故事中段无力，先查“常见失败”，再按“修复动作”重建中点、一无所有和结局。
5. 混合类型不能平均用力。主类型负责观众期待，副类型负责情感深度。
```

## 4. 类型与节拍的结合

节拍逐项写法见《结构B_15节拍写作手册.md》。以下为五种常用类型在关键节拍上的侧重。

### 4.1 金羊毛节拍重点

| 节拍 | 写法 |
|---|---|
| 开场 | 主角困在旧地或旧身份 |
| 催化剂 | 奖品/任务/目的地出现 |
| 第二幕 | 主角上路 |
| 娱乐游戏 | 每一站都是新考验 |
| 中点 | 主角以为快拿到奖品，或发现奖品不如想象 |
| 一无所有 | 旅程断裂、团队分离、目标失效 |
| 第三幕 | 主角发现真正奖品是改变后的自己 |

### 4.2 如愿以偿节拍重点

| 节拍 | 写法 |
|---|---|
| 开场 | 主角强烈缺失或错误欲望 |
| 催化剂 | 魔法/愿望/交换出现 |
| 娱乐游戏 | 主角享受新能力或新身份 |
| 中点 | 新身份公开或欲望短暂满足 |
| 坏蛋逼近 | 魔法开始反噬 |
| 一无所有 | 主角失去真正重要的东西 |
| 第三幕 | 主角放弃错误愿望，选择真实关系或责任 |

### 4.3 伙伴之情节拍重点

| 节拍 | 写法 |
|---|---|
| 开场 | 两人各自不完整 |
| 催化剂 | 两人被迫绑定 |
| 娱乐游戏 | 互相冲突、互补、误解 |
| 中点 | 关系公开升级，暂时更亲近或更敌对 |
| 坏蛋逼近 | 旧伤或秘密破坏关系 |
| 一无所有 | 分离、背叛、失去信任 |
| 第三幕 | 一方用学到的东西救另一方或让对方自由 |

### 4.4 被制度化节拍重点

| 节拍 | 写法 |
|---|---|
| 开场 | 展示制度如何定义主角 |
| 催化剂 | 主角看见制度裂缝 |
| 第二幕 | 主角挑战或进入制度核心 |
| 娱乐游戏 | 制度规则、诱惑、荒谬被展示 |
| 中点 | 主角短暂影响制度或被制度吞没 |
| 坏蛋逼近 | 制度反扑，个体被孤立 |
| 一无所有 | 主角失去身份、归属或自由 |
| 第三幕 | 主角逃离、改变或公开揭穿制度 |

### 4.5 推理侦探节拍重点

| 节拍 | 写法 |
|---|---|
| 开场 | 世界表面秩序 |
| 催化剂 | 案件或异常出现 |
| 娱乐游戏 | 线索、误导、证人、调查 |
| 中点 | 关键证据改变调查方向 |
| 坏蛋逼近 | 调查者被威胁，真相开始污染他 |
| 一无所有 | 错误判断导致代价，或调查者发现自己也在局中 |
| 第三幕 | 真相揭开，但代价改变世界观 |
