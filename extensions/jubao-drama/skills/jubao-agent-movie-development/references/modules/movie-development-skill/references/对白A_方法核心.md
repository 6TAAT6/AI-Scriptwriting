## 1. 对白总公式

高质量对白不是“角色说话”，而是：

**对白 = 欲望 + 障碍 + 伪装 + 节奏 + 转折**

| 组成 | 要问的问题 | 写作要求 |
|---|---|---|
| 欲望 | 角色此刻想从对方那里拿到什么？ | 每句台词都要服务于一个小目标 |
| 障碍 | 对方为什么不给？环境为什么不允许？ | 没有阻力就没有戏 |
| 伪装 | 角色为什么不能直说？他用什么方式隐藏？ | 潜台词来自“不能说” |
| 节奏 | 台词是快、慢、断、绕、压、爆，还是沉默？ | 节奏要匹配情绪压力 |
| 转折 | 这场话说完以后发生了什么变化？ | 信息、关系、权力、决定至少变一项 |

### 1.1 一句台词必须承担至少一种功能

常见功能：

1. 攻击：削弱对方地位。
2. 防守：隐藏弱点、拒绝承认。
3. 试探：用轻话题摸对方底线。
4. 交换：拿信息换安全，拿情感换承诺。
5. 诱导：让对方自己说出关键内容。
6. 遮掩：用玩笑、礼貌、专业术语藏住真实情绪。
7. 反击：把对方的问题变成对方的问题。
8. 拖延：争取时间，回避选择。
9. 证明：向自己、对方或旁观者证明身份。
10. 伤害：准确戳中对方最怕的地方。
11. 修复：试图恢复关系，但不完全服软。
12. 变调：让场景从轻松转紧张，或从紧张转荒诞。

### 1.2 对白场景的五个坐标

写任何对白前，先填这五项：

| 坐标 | 说明 | 对白影响 |
|---|---|---|
| 目标 | 每个角色当下要什么 | 决定台词方向 |
| 地位 | 谁掌握资源、信息、暴力、道德优势 | 决定谁能少说、谁必须解释 |
| 秘密 | 谁知道别人不知道的事 | 决定潜台词和误导 |
| 禁忌 | 什么话不能说出口 | 决定回避、暗示、爆发点 |
| 时限 | 不说成会损失什么 | 决定节奏和压迫感 |

## 2. 对白写作的基础流程

### 2.1 场景诊断模板

让 Agent 在写台词前先回答：

```text
场景类型：
角色A的表面目标：
角色A的真实需求：
角色A不能说出口的话：
角色B的表面目标：
角色B的真实需求：
角色B不能说出口的话：
双方地位差：
观众知道但角色不知道的信息：
本场必须发生的转折：
台词风格关键词：
```

### 2.2 五步创作流程

1. 定义场景功能：这场对白要改变什么？
2. 定义角色策略：每个人用什么方法达成目标？
3. 设计潜台词：他们真正想说但不能说的话是什么？
4. 写对白草稿：先写出冲突和推进，不追求精致。
5. 压缩和变调：删解释、加反应、加沉默、加错位、加转折。

### 2.3 一场对白的最小结构

```text
开场钩子：一句话暴露目标、异常或关系不稳。
试探：一方先用低风险话题接近核心。
抵抗：另一方回避、反问、转移或攻击。
升级：有人说出更具体、更危险或更私人的话。
变招：原策略失败，改用威胁、玩笑、示弱、交换或沉默。
转折：信息、权力、关系或情绪发生变化。
收口：留一个余波，让观众知道下一场戏被推动了。
```

## 3. 人物塑造型对白

人物不是靠自我介绍成立的，而是靠“如何说同一件事”成立。

### 3.1 人物声音的七个维度

| 维度 | 问题 | 写法 |
|---|---|---|
| 词汇来源 | 他常用哪类词？ | 专业词、家庭词、宗教词、商业词、街头词、文学词 |
| 句子长度 | 他短促还是绕？ | 急性子短句，操控者慢句，知识分子长句 |
| 礼貌程度 | 他是否客气？ | 礼貌可以是尊重，也可以是威胁 |
| 情绪出口 | 他愤怒时怎么说？ | 冷笑、沉默、讲道理、翻旧账、开玩笑 |
| 观察角度 | 他会注意什么？ | 钱、秩序、身体、地位、细节、风险、情绪 |
| 防御机制 | 他如何保护自己？ | 否认、讽刺、卖惨、炫耀、专业化、道德化 |
| 关系称呼 | 他怎么叫别人？ | 名字、外号、职位、亲属称谓、贬称、敬称 |

### 3.2 四种常用人物声音

| 类型 | 说话方式 | 适合场景 | 风险 |
|---|---|---|---|
| 控制型 | 少说、慢说、问问题、不给解释 | 权力、黑帮、家族、审讯 | 写成装腔 |
| 焦虑型 | 解释过多、修正自己、语速快 | 喜剧、职场、失败者主角 | 写成啰嗦 |
| 伤害型 | 精准攻击、抓弱点、不给台阶 | 师徒压迫、亲密争吵 | 写成单纯嘴毒 |
| 防御型 | 玩笑、转移、敷衍、假装不在乎 | 青春、浪漫、创伤人物 | 写成无目标闲聊 |

更细分的 30 种人物声音（含常用句型与禁忌）见《对白C_人物声音库.md》。

### 3.3 人物塑造规则

1. 让角色先暴露“看世界的角度”，再暴露经历。
2. 强人物不一定说狠话，常常是让别人说更多。
3. 弱人物不一定沉默，常常是解释太多。
4. 聪明人物的台词不等于复杂，而是能提前布局。
5. 喜剧人物的台词要暴露自我认知缺陷。
6. 悲剧人物的台词要暴露“他正在坚持一个会害死自己的信念”。

### 3.4 人物声音模板

```text
角色名：
社会位置：
最大欲望：
最大恐惧：
常用词汇：
禁用词汇：
句子节奏：
攻击方式：
示弱方式：
说谎方式：
面对爱人时：
面对上级时：
面对敌人时：
面对失败时：
一句话声音样本：
```

## 4. 喜剧情节对白

喜剧对白的核心不是“说笑话”，而是让角色在严肃追求目标时暴露荒谬。

### 4.1 喜剧对白公式

**喜剧对白 = 真实目标 + 错误自尊 + 语境错位 + 升级**

| 元素 | 写法 |
|---|---|
| 真实目标 | 角色必须认真想赢、想藏、想证明、想逃 |
| 错误自尊 | 角色对自己有错误判断，比如觉得自己很聪明、很体面、很重要 |
| 语境错位 | 用过度正式的话说低级事，或用低级话处理重大事 |
| 升级 | 每轮对话让尴尬更具体、代价更大、旁观者更多 |

### 4.2 从《硅谷》类职场喜剧得到的规则

1. 专业术语可以制造喜剧，但必须服务人物地位。
2. 喜剧人物常把“商业愿景”说得很宏大，但行动很小气。
3. 群体互损要有分工：自恋者吹牛，技术宅纠错，旁观者补刀，焦虑者试图拉回正题。
4. 笑点常来自“角色以为自己在解决大问题，其实暴露了更大的无能”。
5. 不要让每个人都讲段子；让一部分人认真，另一部分人的认真才会好笑。

### 4.3 喜剧台词技法库

| 技法 | 说明 | 原创示例方向 |
|---|---|---|
| 过度具体 | 把简单情绪说成复杂参数 | “我不是紧张，我只是心率在用创业模式融资。” |
| 错误类比 | 用不合适的比喻解释自己 | 把分手比成服务器迁移 |
| 礼貌羞辱 | 表面客气，实际贬低 | “你这个方案很勇敢，尤其勇敢在完全不考虑后果。” |
| 递进否认 | 连续否认，越否认越暴露 | “我没偷看。我只是替你的手机确认它还亮着。” |
| 语域错位 | 正式场合说粗俗话，低级场合说宏大愿景 | 董事会讨论厕所排队战略 |
| 假装成熟 | 角色用成熟语气掩盖幼稚 | “我尊重你的选择，所以我准备在群里公开尊重。” |
| 回调 | 后面让早先的小细节变成新笑点 | 前面提到的荒唐规则，在危机时被严肃执行 |
| 反向夸奖 | 夸奖本身构成伤害 | “你最大的优点是从不让人产生不切实际的期待。” |
| 旁观补刀 | 第三人用短句完成笑点 | “他已经尽力了。问题是他的尽力也参与了破坏。” |

### 4.4 喜剧场景流程

```text
1. 给角色一个正经目标。
2. 给他一个错误自我认知。
3. 让他用错误方法处理目标。
4. 让旁观者指出问题，但他不接受。
5. 让他加倍执行错误方法。
6. 让结果短暂看似成功。
7. 让成功立刻暴露更大的荒谬。
```

### 4.5 喜剧对白检查表

1. 角色是不是认真在追求目标？
2. 笑点是不是来自人物，而不是作者硬塞？
3. 是否至少有一次升级？
4. 是否有人承担“正常人视角”？
5. 是否避免所有角色都在同一频率贫嘴？
6. 是否有回调或反转？
7. 台词删掉解释后，笑点是否还成立？

## 5. 压迫情节对白

压迫感来自不平等：信息不平等、权力不平等、资源不平等、情绪不平等。

### 5.1 压迫对白公式

**压迫对白 = 不平等地位 + 不可逃空间 + 精准问题 + 代价**

| 压迫来源 | 写法 |
|---|---|
| 权力 | 强者可以少说，弱者必须解释 |
| 信息 | 强者知道弱者的秘密，或假装知道 |
| 空间 | 门关上、车停不下、会议没结束、餐桌不能离开 |
| 道德 | 强者逼弱者承认自己不是好人 |
| 时间 | 倒计时、任务失败、外面有人等 |

### 5.2 压迫对白的写作规则

1. 越强的人越少解释。
2. 真正的威胁不急着喊出来，而是先让对方意识到自己没有选择。
3. 压迫者常用问题控制节奏。
4. 被压迫者越解释，越暴露弱点。
5. 沉默是压迫的一部分，不是空白。
6. 礼貌可以比辱骂更可怕。
7. 压迫场景必须逐步缩小选择范围。

### 5.3 压迫型台词功能

| 功能 | 写法 |
|---|---|
| 设陷阱 | 问一个对方怎么答都不舒服的问题 |
| 定义对方 | 替对方说出他最不愿承认的身份 |
| 剥夺解释权 | 打断、纠正、要求只回答是或不是 |
| 制造孤立 | 暗示没人会相信他、没人会救他 |
| 奖惩诱导 | 给一点认可，再立刻收回 |
| 延迟爆发 | 不马上发怒，让对方自己崩溃 |

### 5.4 压迫场景流程

```text
开场：强者提出一个看似普通的问题。
收窄：问题越来越具体，对方开始解释。
否定：强者不接受解释，只接受服从或承认。
翻旧账：强者拿出对方隐藏的事实或弱点。
诱导：给对方一个看似可以脱身的选择。
反锁：这个选择本身就是陷阱。
结尾：弱者失去某种东西：尊严、秘密、关系、机会或行动自由。
```

### 5.5 原创示例：压迫对白骨架

```text
A：你迟到了七分钟。
B：路上堵车。
A：我没问路。
B：我只是解释一下。
A：我知道你在解释。我在等你说真话。
B：真话就是堵车。
A：那我们就从你为什么提前二十分钟出门，却刚好迟到七分钟开始。
```

要点：A 不骂人，不喊叫，只用精确时间和问题压缩 B 的空间。

## 6. 争吵与冲突对白

争吵不是音量变大，而是双方目标发生正面碰撞。

### 6.1 争吵场景的核心

每个角色都必须相信自己有理。最差的争吵是一个人正确、另一个人只负责无理取闹。

高质量争吵具备：

1. 双方各有正当理由。
2. 争论对象会不断变化：事实、动机、责任、旧伤、未来。
3. 每次攻击都更接近核心禁忌。
4. 争吵中有人试图结束，但失败。
5. 最后说出口的不是最大声的话，而是最不能收回的话。

### 6.2 争吵升级阶梯

```text
事实争议：你做了什么？
解释争议：你为什么这么做？
责任争议：这是谁造成的？
人格争议：你一直都是这样的人。
关系争议：我们还要不要继续？
不可逆句：说出口以后关系回不到原状。
```

### 6.3 争吵对白技法

| 技法 | 写法 |
|---|---|
| 抓词 | 一方抓住对方某个词反击 |
| 翻旧账 | 当前事件引爆旧伤 |
| 假道歉 | “对不起，但……”继续攻击 |
| 把问题升级 | 从小错误上升到人格或关系 |
| 把问题降级 | 故意说成小事，激怒对方 |
| 第三方压力 | 有旁人在场，双方不能完全失控 |
| 沉默惩罚 | 不回答本身就是攻击 |

### 6.4 争吵改写原则

弱版本：

```text
A：你总是不理解我。
B：我怎么不理解你了？
A：你就是不理解。
```

强化方向：

```text
A：你不是不理解，你是每次都等我解释完，再挑一个最容易反驳的字。
B：因为你每次解释都像在给自己申请无罪释放。
A：至少我还知道自己在受审。你连法官是谁都装不知道。
```

要点：不要重复抽象指控，要让角色用具体行为攻击对方。

## 7. 审讯、谈判与心理博弈对白

审讯和谈判的共同点：台词不是表达，而是取物。角色用语言换信息、换承认、换时间、换安全。

### 7.1 审讯对白

审讯不是问答题，而是节奏控制。

常用结构：

```text
建立规则：我问，你答。
低压事实：先问对方愿意承认的小事实。
制造矛盾：把两个小事实拼成漏洞。
打断解释：不让对方展开叙述。
引入证据：证据不一定是真的，但要让对方相信可能是真的。
给出出口：让对方以为承认一部分可以保护另一部分。
反转出口：承认一部分后，新的问题出现。
```

### 7.2 谈判对白

谈判的关键不是报价，而是判断对方真正怕什么。

| 阶段 | 台词任务 |
|---|---|
| 开场 | 显示自己有选择，不急 |
| 探底 | 问对方不能失去什么 |
| 交换 | 给小让步，换大信息 |
| 威胁 | 不说“我要毁了你”，而说“如果没有协议，会发生什么” |
| 留面子 | 给对方一个能接受的说法 |
| 锁定 | 把模糊同意变成具体行动 |

### 7.3 心理博弈台词

1. 不直接攻击结论，攻击对方得出结论的方式。
2. 不急着揭穿谎言，先让对方多讲。
3. 用错误信息测试对方反应。
4. 用沉默迫使对方补充。
5. 把对方的防御话术变成证据。

## 8. 浪漫、亲密与告白对白

亲密对白最忌讳把主题说满。真正动人的亲密来自试探、错过、退让、再靠近。

### 8.1 浪漫对白公式

**浪漫对白 = 共同注意力 + 小型测试 + 自我暴露 + 未完成**

| 元素 | 写法 |
|---|---|
| 共同注意力 | 两个人一起看某个东西、讨论某个小话题 |
| 小型测试 | 一方轻轻试探对方价值观或边界 |
| 自我暴露 | 说一点真话，但不说完 |
| 未完成 | 留下没说出的可能性 |

### 8.2 亲密场景的常见错误

1. 直接说“我喜欢你”太早。
2. 两个人都过度诗意，缺少生活细节。
3. 没有风险，告白像信息通知。
4. 没有回避，所有情绪都被讲明。
5. 缺少关系前史，台词浮在空中。

### 8.3 写法

1. 让人物先谈不重要的事。
2. 让不重要的事逐渐指向重要情绪。
3. 让一方误解或故意装不懂。
4. 让另一方退一步。
5. 最后用一个具体动作或半句话完成情绪。

### 8.4 原创示例：克制告白

```text
A：你明天几点走？
B：六点。你不会起那么早。
A：我可以设闹钟。
B：你上次设闹钟，是为了抢演唱会票。
A：那次也很重要。
B：这次呢？
A：这次我怕错过的不是票。
```

要点：不直接说爱，先用日常细节建立关系，再把“错过”转成情感。

## 9. 信息交代型对白

信息交代是剧本对白中最容易写坏的部分。好的信息交代不是说明书，而是带着压力的信息交换。

### 9.1 信息交代公式

**信息交代 = 角色需要知道 + 角色不愿相信 + 立刻要做决定**

### 9.2 好的信息交代条件

1. 信息必须改变角色选择。
2. 信息必须有人不愿意说，或有人不愿意听。
3. 信息最好由冲突、训练、审讯、交易、犯错、失败引出。
4. 信息不能只给观众听，也要对角色造成影响。
5. 专业设定要翻译成可感知的风险。

### 9.3 设定型对白写法

弱写法：

```text
A：这个装置可以让人进入梦境。
B：原来如此，它通过同步脑波实现意识共享。
```

强化方向：

```text
A：你如果现在拔线，他醒不过来。
B：你刚才说这只是测试。
A：测试就是为了知道哪种错误会杀人。
```

要点：先给风险，再给原理。观众会因为危险而愿意听解释。

### 9.4 专业术语使用规则

1. 术语要少，但要准。
2. 术语第一次出现时，必须有情境意义。
3. 术语可以用来区分身份：专家、骗子、外行、领导、客户。
4. 喜剧中可以让角色滥用术语暴露虚伪。
5. 压迫场景中可以让术语变成权力工具。

## 10. 反派与危险人物对白

反派对白的关键不是“坏”，而是他有一套自洽的世界观，并用这套世界观压迫别人。

### 10.1 反派对白公式

**反派对白 = 世界观 + 规则 + 诱惑 + 代价**

| 元素 | 写法 |
|---|---|
| 世界观 | 他相信世界本来就应该这样运转 |
| 规则 | 他给对方设定游戏规则 |
| 诱惑 | 他让对方觉得服从也许更轻松 |
| 代价 | 不服从会失去什么 |

### 10.2 反派常用说话方式

1. 冷静解释残酷逻辑。
2. 把暴力说成秩序。
3. 把自己的欲望说成规律。
4. 给对方选择，但每个选择都服务他。
5. 礼貌地剥夺对方尊严。
6. 说话像在教育，而不是威胁。

### 10.3 避免俗套

不要让反派说：

```text
我要毁灭世界。
你们都不是我的对手。
我从小就很痛苦，所以我要报复所有人。
```

改成：

```text
他指出主角也依赖同一套残酷规则。
他让主角承认自己并不纯洁。
他把暴力包装成效率、审判、自由、秩序或公平。
```

## 11. 群戏对白

群戏不是让很多人轮流说话，而是让每个人在场景中承担不同功能。

### 11.1 群戏角色分工

| 功能 | 作用 |
|---|---|
| 推进者 | 把话题往目标推 |
| 阻拦者 | 拒绝、怀疑、制造障碍 |
| 翻译者 | 把复杂信息说给外行听 |
| 搅局者 | 用情绪、玩笑或私利打乱节奏 |
| 旁观者 | 给观众反应点，补充现实感 |
| 权威者 | 决定讨论是否有效 |
| 沉默者 | 不说话本身制造悬念 |

### 11.2 群戏写作规则

1. 每个人发言前，先确定他为什么必须说。
2. 不要让每个人都表达完整观点。
3. 让角色互相打断、补充、误解、站队。
4. 群戏需要权力流动：谁暂时赢了，谁被孤立，谁改变阵营。
5. 大群戏要有小焦点：观众此刻主要关心一个问题。

### 11.3 群戏节奏

```text
多人混乱开场
一个问题把众人聚焦
不同立场快速呈现
某人提出新证据或新风险
阵营重组
权威者或关键角色做决定
留下不满或后果
```

---

## 12. 动作、危机与倒计时对白

动作场景中的对白要短、准、有用，但不能只是喊口令。

### 12.1 危机对白功能

1. 传递战术信息。
2. 暴露恐惧。
3. 建立信任或不信任。
4. 在压力下制造幽默。
5. 让角色做道德选择。
6. 用短句显示关系变化。

### 12.2 写作规则

1. 危机越大，解释越少。
2. 角色不要描述观众已经看到的动作。
3. 技术信息必须直接影响下一步行动。
4. 幽默要来自压力下的防御，不要破坏危险感。
5. 动作场景中一句私人话，往往比长告白更有力量。

### 12.3 危机对白模板

```text
目标：他们必须在几分钟内完成什么？
阻碍：谁受伤、谁不信任谁、设备哪里坏了？
信息差：谁知道真正风险？
情感钩子：这次行动触发了谁的旧伤或关系问题？
台词长度：每句不超过 12 个字，关键句可以更短。
```

## 13. 家庭、阶层与社会关系对白

家庭和阶层场景里，很多话不能直接说，因为关系太近、利益太深、礼貌太重。

### 13.1 家庭对白

家庭对白常见潜台词：

1. 我需要你，但我不能承认。
2. 我恨你对我的定义。
3. 我想离开这个家，但我怕背叛。
4. 我不是在谈这件事，我是在谈过去十年。
5. 我希望你道歉，但我不能先低头。

写法：

1. 用小事引爆旧伤。
2. 用称呼显示距离变化。
3. 用饭桌、车内、病房、门口等无法轻易离开的空间。
4. 让亲人比外人更知道怎么伤害对方。

### 13.2 阶层对白

阶层对白不是让角色说“我是穷人/富人”，而是让他们对钱、时间、空间、风险的理解不同。

| 维度 | 高资源角色 | 低资源角色 |
|---|---|---|
| 时间 | 可以等待、安排别人 | 必须立刻解决 |
| 空间 | 可以拥有私人空间 | 经常被迫共享空间 |
| 风险 | 失败可重来 | 失败会摧毁生活 |
| 礼貌 | 礼貌是修养或武器 | 礼貌是求生策略 |
| 钱 | 抽象数字 | 具体账单 |

### 13.3 社会关系场景规则

1. 地位低者常常更会读空气。
2. 地位高者可以把命令包装成建议。
3. 礼貌话要带刺。
4. 阶层冲突最好通过具体物件、空间和服务关系体现。

## 14. 悬疑、误导与真相揭示对白

悬疑对白的关键是控制信息：让观众知道一点、怀疑一点、误解一点。

### 14.1 悬疑对白技巧

| 技法 | 说明 |
|---|---|
| 半真话 | 角色说的是真的，但缺少关键上下文 |
| 错误重点 | 让观众关注无关细节 |
| 延迟回答 | 问题出现后不立刻回答 |
| 反问遮掩 | 用质问替代解释 |
| 重复异常 | 某个词或细节多次出现，后来变成线索 |
| 不可靠叙述 | 讲述者的记忆、动机或身份有问题 |
| 证据错位 | 证据是真的，但解释是错的 |

### 14.2 真相揭示规则

1. 揭示前必须埋过公平线索。
2. 真相不能只是新信息，还要改写旧场景意义。
3. 揭示台词要少，留给角色反应和观众回想。
4. 如果角色解释太多，悬疑会变成讲解。
5. 最好的揭示是让观众意识到“原来刚才那句话不是那个意思”。

## 15. 角色关系类型与对白写法

| 关系 | 核心张力 | 对白写法 |
|---|---|---|
| 师徒 | 认可与控制 | 老师给奖励再收回，徒弟解释、反抗或讨好 |
| 父子/母女 | 期待与亏欠 | 当前小事引出长期定义 |
| 情侣 | 靠近与逃避 | 说日常事，绕核心情绪 |
| 前任 | 熟悉与防御 | 彼此知道按钮在哪里，但假装不在乎 |
| 敌人 | 尊重与毁灭 | 表面客气，底层互相测试 |
| 搭档 | 信任与分歧 | 一人冒险，一人控制风险 |
| 上下级 | 资源与服从 | 上级定义问题，下级争取解释权 |
| 群体成员 | 归属与排斥 | 语言显示谁在圈内、谁被排除 |

## 16. 台词节奏

### 16.1 节奏类型

| 节奏 | 适合场景 | 写法 |
|---|---|---|
| 快速短打 | 争吵、喜剧、危机 | 短句、打断、反问 |
| 慢速压迫 | 审讯、威胁、权力场 | 停顿、问题、少量关键字 |
| 绕行试探 | 浪漫、家庭、秘密 | 小话题、转移、半句话 |
| 专业密集 | 职场、科幻、调查 | 术语与现实风险交替 |
| 诗性独白 | 主题表达、高潮 | 具体意象、节奏递进、避免空泛 |

### 16.2 台词压缩方法

初稿：

```text
我真的很生气，因为你昨天答应过我会来，但是你没有出现，这让我觉得你根本不重视我。
```

压缩：

```text
我等到餐厅打烊。
```

再压缩带潜台词：

```text
服务员都开始替你找理由了。
```

原则：用具体事实承载情绪，少说情绪名称。

## 17. 潜台词写法

### 17.1 潜台词来源

1. 角色不敢说。
2. 角色不愿承认。
3. 角色说了会失去地位。
4. 角色自己还没意识到。
5. 现场有第三个人。
6. 关系不允许直说。
7. 说真话会立刻引发后果。

### 17.2 潜台词工具

| 工具 | 写法 |
|---|---|
| 转移话题 | 真问题逼近时聊无关事 |
| 过度解释 | 用细节掩盖核心 |
| 反问 | 把压力扔回去 |
| 玩笑 | 把痛苦变轻，但观众看见重量 |
| 纠正小错 | 避免回应大问题 |
| 重复称呼 | 用名字、职位或外号改变关系 |
| 沉默 | 拒绝给对方想要的反应 |
| 行动替代 | 倒水、收拾东西、关门、点烟、看手机 |

### 17.3 潜台词练习

直白句：

```text
我不想让你走。
```

潜台词版本：

```text
你那把伞还在门后。
```

直白句：

```text
我知道你骗了我。
```

潜台词版本：

```text
你今天讲这个故事，比上次多了一个人。
```

直白句：

```text
我需要你认可我。
```

潜台词版本：

```text
你刚才点头，是因为同意，还是因为想让我闭嘴？
```

## 18. 烂对白诊断与修复

### 18.1 常见问题

| 问题 | 症状 | 修复 |
|---|---|---|
| 太直白 | 角色直接说出主题和情绪 | 改成具体行为、误解、回避 |
| 没有目标 | 像聊天记录 | 给每个人一个当下需求 |
| 人物同声 | 每个人都像作者 | 建人物词库和禁用词 |
| 信息倾倒 | 互相讲已知背景 | 把信息放进冲突和选择 |
| 冲突重复 | 一直争同一点 | 每轮争吵升级到新层面 |
| 缺少反应 | 角色轮流发表 | 加打断、误听、沉默、动作 |
| 太完整 | 每句话都语法完美 | 加省略、半句、修正、停顿 |
| 无后果 | 说完什么都没变 | 让关系、信息或决定改变 |

### 18.2 改写顺序

1. 删掉角色自己已经知道的信息。
2. 删掉情绪标签，换成具体事实。
3. 给每个人不同策略。
4. 把解释改成问题、反问、行动或沉默。
5. 每 6-10 句设置一次转折。
6. 结尾留下后果，不要把情绪收干净。

### 18.3 快速修复模板

```text
原台词问题：
1. 哪些句子太直白？
2. 哪些信息角色已经知道？
3. 谁没有明确目标？
4. 谁的声音和别人重复？
5. 场景结束后什么没有变化？

改写目标：
1. 保留哪些剧情信息？
2. 增强哪种情绪？
3. 增强哪种关系张力？
4. 增加哪一次转折？
```

完整的前后对照改写案例（20 组）与对白评分表见《对白D_改写案例库.md》。

## 20. 终极原则

1. 台词不是为了让角色表达自己，而是为了让角色改变局面。
2. 每个人都应该带着目标进入对白。
3. 最好听的台词通常不是最真实的话，而是角色此刻能承受的最接近真实的话。
4. 喜剧来自严肃目标和错误方法。
5. 压迫来自选择被缩小。
6. 人物来自重复的语言习惯和关键时刻的破例。
7. 信息交代必须带来行动后果。
8. 群戏需要功能分工，不需要人人平均发言。
9. 反派要有逻辑，不只是有恶意。
