# 群像、支线与暗线设计指南

本指南用于把经典剧本中的群像、支线和暗线机制转成可执行的创作规则。它不复述经典剧情，也不复制台词，只提炼角色分工、支线推进、暗线埋设和回收方法。

使用场景：

- 用户说人物太散、配角没用、群像不成立。
- 用户说主线单薄，需要 B 故事、爱情线、家庭线、职场线、调查线或反派线。
- 用户说故事缺少暗线、伏笔、悬念、反转、隐藏真相或结尾回收。
- 用户给的是多主角、多家庭、多阵营、多时空、多任务线故事。
- 用户要把一个普通主线扩展成更丰富的长片结构。

核心原则：

```text
群像负责把主题拆成不同的人。
支线负责让主线不断付代价。
暗线负责让前面的细节在结尾变重。
```

## 0. 总公式

```text
主问题 -> 群像分工 -> 支线运动 -> 暗线种子 -> 中点并线 -> 低谷暴露 -> 高潮回收
```

### 0.1 三者的区别

| 结构层 | 回答的问题 | 最小合格标准 | 常见失败 |
| --- | --- | --- | --- |
| 群像 | 这个故事为什么需要不止一个重要人物 | 每个重要人物都代表一种欲望、代价、诱惑、阻力、镜像或主题反证 | 人很多，但只是在不同场景里说话 |
| 支线 | 主线之外的行动如何改变主线 | 每条支线至少三次出现，并在中点后改变主线压力或人物选择 | 支线只是插曲，删掉也不影响结局 |
| 暗线 | 哪些信息先作为症状出现，后面才解释 | 观众前面看见过证据，结尾能重新理解 | 结尾硬反转，前面没有可见依据 |

### 0.2 先问三个问题

1. 群像问题：每个重要人物是否都让主角、主题或世界多一层压力？
2. 支线问题：这条线在中点之后是否让主线变难、变贵或变脏？
3. 暗线问题：结尾回收的信息，前面是否已经以动作、空间、道具、台词回避或关系异常出现过？

### 0.3 不同故事规模的推荐配置

| 故事规模 | 群像数量 | 支线数量 | 暗线数量 | 说明 |
| --- | --- | --- | --- | --- |
| 单主角类型片 | 主角 + 3-5 个功能角色 | 1 条 B 故事 + 1 条反派线 | 1 条真相或道具暗线 | 保证清楚、集中、好跟随 |
| 家庭/职场/犯罪长片 | 5-8 个重要角色 | 2-4 条支线 | 2-3 条暗线 | 适合多层代价和中段交叉 |
| 城市/社区/时代群像 | 8-12 个功能角色 | 4-6 条支线 | 3 条以上主题暗线 | 必须有统一场域或统一事件压住 |
| 多时空/史诗结构 | 每个时空 3-5 个核心角色 | 每条时空线 1-2 条支线 | 身份、因果、主题暗线并行 | 必须让每条线都服务同一个主问题 |

## 1. 群像设计

群像不是平均分戏，而是功能分工。观众可以喜欢很多人，但故事不能让每个人都抢方向。每个重要人物都要回答：他让主线多了什么压力？

### 1.1 群像的六种常用结构

| 群像结构 | 适用故事 | 设计重点 | 经典机制参考 |
| --- | --- | --- | --- |
| 中心太阳型 | 家族、黑帮、传记、成长、权力交接 | 一个主角在中心，其他人是他的未来、过去、诱惑、代价或道德目光 | 《教父》用家族成员把 Michael 推向新教父 |
| 镜像双核型 | 警匪、竞技、复仇、执念、双雄 | 两个核心人物追同一主题，但用相反方法 | 《盗火线》用警察和罪犯互照职业吞噬 |
| 三主角分岔型 | 犯罪调查、职场、政治、制度题材 | 三个人从不同入口碰到同一个系统真相 | 《洛城机密》让三名警察各自查案，最后并到腐败系统 |
| 任务小组型 | 调查、救援、竞赛、职场项目 | 每个人负责一种能力或一种道德角度 | 《聚焦》用记者分工推进机构真相 |
| 场域切片型 | 社区、校园、城市、家庭聚会、一夜故事 | 一个空间或时间段压住所有人，人物像社会截面 | 《为所应为》用一条街和一天高温压出群体冲突 |
| 拼图叙事型 | 非线性、章节体、多线犯罪、记忆结构 | 每个角色掌握一块信息，观众靠重组理解全貌 | 《低俗小说》用错序章节让人物命运互相改写 |

### 1.2 群像角色功能表

设计群像时，不要先写职业和性格，先分配功能。

| 功能 | 作用 | 场景表现 | 常见角色位置 |
| --- | --- | --- | --- |
| 欲望发动者 | 把故事推上路 | 他提出目标、制造交易、引爆事件 | 主角、反派、委托人、野心家 |
| 代价承担者 | 让胜利有成本 | 他受伤、失去关系、被牺牲或承担后果 | 家人、朋友、弱者、团队新人 |
| 镜像人物 | 证明主角也可能走向另一种命运 | 他和主角有相同伤口，但选择相反方法 | 对手、双雄、兄弟、同事 |
| 诱惑人物 | 让主角旧方法看起来有效 | 他提供捷径、权力、钱、名声、欲望满足 | 恶友、情人、导师变体、资本方 |
| 主题反证 | 用失败人生证明主题的反面 | 他坚持错误信念到底，并付出代价 | 反派、失败前辈、家族长辈 |
| 道德目光 | 让主角不能只按利益行动 | 他看见主角的变坏、撒谎、逃避或背叛 | 爱侣、孩子、朋友、旁观者 |
| 系统代言人 | 让压力不是一个人，而是一套规则 | 他执行制度、规矩、阶层、公司或家族逻辑 | 上司、警察、法官、媒体、族长 |
| 隐藏真相持有者 | 暗线的活容器 | 他知道关键事实，但因恐惧、利益或旧债不说 | 母亲、旧友、证人、反派、幸存者 |
| 情绪调节者 | 改变节奏和观众入口 | 他带来幽默、温度、日常感或荒诞感 | 喜剧配角、孩子、同事、邻居 |
| 未来自我 | 让主角看见可能成为的人 | 他代表成功后的空洞或失败后的清醒 | 前辈、老年角色、同类赢家 |

### 1.3 群像设计九宫格

为每个重要人物填一次，不合格的角色要合并或删除。

| 项目 | 必须写成可拍内容 |
| --- | --- |
| 他想要什么 | 具体目标：钱、位置、爱、自由、复仇、体面、安全、真相 |
| 他最怕什么 | 会被事件触发的恐惧：被抛弃、失控、失败、羞辱、暴露 |
| 他靠什么解决问题 | 暴力、讨好、算计、逃避、照顾、规则、魅力、撒谎、牺牲 |
| 他和主角是什么压力关系 | 推动、诱惑、阻拦、照见、保护、审判、利用、背叛 |
| 他代表主题的哪一面 | 正面、反面、未成熟版本、腐败版本、理想版本 |
| 他带来哪条支线 | 情感线、调查线、反派线、家庭线、工作线、社会线 |
| 他掌握什么信息 | 公开信息、秘密、证据、误解、错误解释 |
| 他至少改变一次什么 | 立场、关系、代价、忠诚、身份、权力位置 |
| 结尾如何回收他 | 获得、失去、牺牲、背叛、暴露、离开、继承、被主角超越 |

### 1.4 群像出场的五种方法

| 出场方法 | 写法 | 适合 |
| --- | --- | --- |
| 仪式出场 | 婚礼、葬礼、会议、饭局、庆典、比赛，把关系一次性摆出来 | 家族、社区、权力结构 |
| 任务出场 | 所有人围绕一个外部目标集合，各自露出能力和缺陷 | 调查、抢劫、救援、职场 |
| 冲突出场 | 第一场就让角色为资源、尊严、位置或秘密发生冲突 | 犯罪、家庭、办公室、群戏 |
| 日常切片 | 用生活细节展示每个人如何处理同一个世界压力 | 社区、青春、现实主义 |
| 非线性拼图 | 先给结果或碎片，再逐步补人物动机和因果 | 悬疑、黑色电影、多线犯罪 |

### 1.5 群像戏份分配规则

不要按“每个人几场戏”平均分，而是按功能分层。

| 层级 | 戏份标准 | 必须完成的任务 |
| --- | --- | --- |
| A 层核心人物 | 贯穿三幕，至少有一次重大选择 | 推动主线、承担主题、改变结局 |
| B 层支线人物 | 至少三次有效出现 | 建立支线、升级代价、中后段并线或回收 |
| C 层功能人物 | 一到两场高功能场景 | 提供信息、制造压力、改变局面或呈现世界规则 |

判断标准：

```text
如果删掉这个人物，只少了气氛，不改变主线因果 -> 删除或合并。
如果删掉这个人物，主角少一次诱惑、代价、阻力或真相 -> 保留。
```

### 1.6 经典群像机制提炼

| 作品 | 群像机制 | 可迁移做法 |
| --- | --- | --- |
| 《教父》 | 家族成员不是背景，而是 Michael 的四种可能命运 | 给主角安排暴力版、软弱版、理性版、道德审判版 |
| 《教父2》 | 两代人互为镜像，一条线讲权力建立，一条线讲权力腐蚀 | 多时空故事要让两条线回答同一个主题，不只做对照剪辑 |
| 《十二怒汉》 | 一个房间里每个人代表一种偏见、恐惧或理性程度 | 群像可用“立场变化”替代外部动作 |
| 《盗火线》 | 警与匪都被职业吞噬，家庭线证明他们无法正常生活 | 镜像敌人要在工作能力和私人失败上同时相似 |
| 《洛城机密》 | 三个警察从不同道德缺口进入同一个腐败系统 | 多主角不要抢同一功能，每人负责一种调查入口 |
| 《聚焦》 | 团队群像靠分工推进，不靠每个人悲情背景 | 任务小组里每个人要有独特信息渠道或采访对象 |
| 《为所应为》 | 一条街的所有人都在同一天被尊严和高温推向爆点 | 社区群像要有统一的时间压力和公共空间 |
| 《不羁夜》 | 行业家庭先提供归属，后暴露剥削和空洞 | 群像可先像乌托邦，再在中点后变成代价系统 |
| 《小妇人》 | 姐妹各代表一种女性选择和人生价格 | 家庭群像要让每个成员追求不同版本的幸福 |
| 《寄生虫》 | 两个家庭不是普通对比，而是空间、气味、工作和尊严的阶层对照 | 群像对照要落到可拍的空间和身体细节 |

### 1.7 群像常见失败与修复

| 失败 | 症状 | 修复 |
| --- | --- | --- |
| 人物太多 | 观众记不住，场场都在介绍人 | 每个角色写一句“他给主线制造的不可替代压力”，写不出就合并 |
| 配角工具化 | 只负责递信息、说笑话或陪主角聊天 | 给配角一个独立欲望，并让它至少一次阻碍主角 |
| 群像平均用力 | 每个人都有小传，但主线方向变散 | 把人物分 A/B/C 层，只有 A 层拥有完整弧光 |
| 没有主题分工 | 人物性格不同，但不回答同一个问题 | 让每个人代表主题的一种答案或失败方式 |
| 中段人物失踪 | 第一幕热闹，中段只剩主角跑剧情 | 给每个 B 层角色安排“中点后并线任务” |
| 群像结尾散 | 结尾只解决主角，不回收其他人 | 高潮前列出每个角色的获得、失去、暴露或选择 |

## 2. 支线设计

支线不是给故事加料，而是让主线更难、更贵、更有情感重量。真正有效的支线即使看似离题，也会在中点后改变主线的目标、代价或解释。

### 2.1 支线的最小公式

```text
支线人物欲望 -> 与主线发生交换 -> 制造新代价 -> 中点后并线 -> 高潮前回收
```

如果一条支线只提供气氛，不提供代价、反转、信息或选择，它不是支线，是装饰。

### 2.2 十种常用支线

| 支线类型 | 功能 | 适合问题 | 回收方式 |
| --- | --- | --- | --- |
| B 故事情感线 | 让主角面对真正需求 | 主角只会追外部目标 | 主角用新行为保护、承认、放手或共同承担 |
| 镜像人物线 | 展示另一种命运 | 主角选择缺少对照 | 镜像人物失败、堕落、牺牲或觉醒 |
| 家庭线 | 把外部冲突转成私人代价 | 类型片太冷、太任务化 | 家庭成员成为一无所有或第三幕选择的代价 |
| 反派线 | 让压力持续主动逼近 | 反派只在结尾出现 | 反派每次行动都夺走主角一个资源 |
| 调查线 | 逐步改变观众对世界的理解 | 悬疑、犯罪、制度题材 | 证据从小案并到大系统 |
| 职场/任务线 | 让人物能力和伦理同时受考验 | 团队、行业、竞赛 | 成功方式逼人物牺牲底线或改变规则 |
| 社会系统线 | 让单个事件背后出现结构性压力 | 现实主义、政治、阶层 | 揭示问题不是单一坏人，而是一套规则 |
| 喜剧调节线 | 改变节奏，但仍服务主问题 | 中段太沉或信息太密 | 笑点最终变成代价、误会或关键行动 |
| 物件/证据线 | 把抽象真相变成可追踪对象 | 悬疑、冒险、黑色电影 | 物件位置或含义在结尾改写局面 |
| 时间线/过去线 | 解释当前错误信念或家族债 | 多时空、传记、家族史 | 过去线证明现在的选择不是偶然 |

### 2.3 支线五段式

| 阶段 | 任务 | 不合格写法 | 合格写法 |
| --- | --- | --- | --- |
| 入场钩子 | 支线人物有自己的目标，不是等主角召唤 | 配角出现只是听主角倾诉 | 配角正在追自己的事，主角介入会改变他 |
| 独立运动 | 支线有自己的小因果 | 每次出现都重复同一种关系状态 | 每次出现都让关系、信息或风险前进一步 |
| 主线交换 | 支线拿走或给予主线资源 | 支线和主线平行不相干 | 支线让主角得到线索、失去机会、暴露秘密或改变计划 |
| 中点并线 | 支线改变主线的意义 | 中点后支线继续原地小打小闹 | 支线证明主角以为的目标不完整、不干净或更危险 |
| 结尾回收 | 支线用行动兑现主题 | 结尾靠一句解释收尾 | 支线人物做出选择、付出代价或暴露真相 |

### 2.4 支线和主线的连接方式

| 连接方式 | 用法 | 示例机制 |
| --- | --- | --- |
| 因果连接 | 支线事件直接导致主线下一步 | 情感失信导致任务失败，调查发现导致主角改计划 |
| 信息连接 | 支线提供主线缺失真相 | 证人、旧照片、账本、旧友、孩子一句话 |
| 代价连接 | 主线胜利伤害支线人物 | 主角升职但失去朋友，破案但伤害家庭 |
| 主题连接 | 支线证明主线主题的另一面 | 主角逃避，配角承担；主角控制，配角离开 |
| 空间连接 | 支线发生在同一场域，压力相互传染 | 饭店、社区、办公室、学校、医院、派出所 |
| 反讽连接 | 支线看似轻，后面变成重后果 | 玩笑变成证据，误会变成背叛，谎言变成危机 |

### 2.5 支线节奏规则

一条重要支线至少要有三次有效出现：

```text
第一次：建立欲望或矛盾。
第二次：让主线付出代价或获得错误帮助。
第三次：并线、反转或回收。
```

更完整的长片支线可按七步：

```text
1. 入场：支线人物有独立目标。
2. 交换：主角和支线人物互相利用或误解。
3. 小胜：支线暂时帮主角推进。
4. 裂缝：支线暴露主角旧方法的问题。
5. 中点后并线：支线牵出更大代价。
6. 一无所有：支线人物受伤、离开、背叛或说出真相。
7. 高潮回收：主角用新方法处理这条关系或信息。
```

### 2.6 支线经典机制提炼

| 作品 | 支线机制 | 可迁移做法 |
| --- | --- | --- |
| 《寄生虫》 | 四个家庭成员的求职支线逐一推进，最后全部并成豪宅入侵和地下室危机 | 支线可以像阶梯，每一条成功都为下一条创造条件，同时埋更大风险 |
| 《洛城机密》 | 三个警察的职业欲望线最后合并成制度腐败线 | 多主角支线要从不同入口进入同一个真相 |
| 《社交网络》 | Erica、Eduardo、Sean 分别是旧伤、人性成本和成功诱惑 | 情感支线要变成主角价值观的审判，不只是恋爱或友情 |
| 《盗火线》 | 警匪各自的家庭/爱情线证明他们都无法正常亲密 | 动作或犯罪片的关系支线要攻击主角的职业信条 |
| 《美国丽人》 | 家庭、邻居、欲望、青春线互相误读，推动结尾悲剧 | 多条日常支线可以通过误解和秘密互相引爆 |
| 《聚焦》 | 采访线、档案线、律师线、教会线逐步证明系统性掩盖 | 调查支线要从个案扩展到结构，不只增加线索数量 |
| 《低俗小说》 | 每个章节像独立支线，但人物命运互相改写 | 非线性支线必须在因果或主题上互相咬合 |
| 《小妇人》 | 姐妹线分别测试婚姻、创作、家庭、疾病和女性选择 | 家庭支线要让每个人追求不同幸福，并付不同价格 |

### 2.7 支线常见失败与修复

| 失败 | 症状 | 修复 |
| --- | --- | --- |
| 支线可删 | 删除后主线照样成立 | 让支线拿走主角一个资源，或提供一个主线必需真相 |
| 支线只煽情 | 情绪很满，但不改变事件 | 把支线情绪变成主角下一步行动的代价 |
| 支线抢主线 | 配角线更好看，主角失焦 | 明确主问题，支线只能回答主问题的一个侧面 |
| 支线结尾没回收 | 人物后半段消失 | 给每条支线写一个“结尾动作”，不是结尾说明 |
| 情感线功能单薄 | 爱情/友情只是陪伴 | 让对方掌握主角最不愿承认的真相 |
| 反派线被动 | 反派等主角找上门 | 反派每 10-15 分钟夺走主角一个选择 |

## 3. 暗线设计

暗线不是故意藏答案，而是先把真相伪装成生活细节、行为异常、空间规则或关系回避。观众第一次看见时不知道它的意义，回头看会发现它一直在。

### 3.1 暗线的最小公式

```text
可见症状 -> 暂时误解 -> 重复变体 -> 中点加压 -> 真相暴露 -> 反向解释前文
```

暗线必须先可见，再可解释。没有可见症状的反转，是硬拧。

### 3.2 暗线和伏笔、悬念、反转的区别

| 概念 | 作用 | 关键问题 |
| --- | --- | --- |
| 伏笔 | 提前放一个未来会用的东西 | 这个东西后面是否改变局面 |
| 悬念 | 让观众想知道接下来发生什么 | 观众现在担心什么 |
| 暗线 | 让观众先看见症状，后面才明白原因 | 前面的异常能否被重新解释 |
| 反转 | 改变观众对事实或人物的判断 | 反转后是否能解释前面的细节 |
| 隐喻线 | 用物件、空间或身体感受重复主题 | 它是否随着剧情升级改变含义 |

### 3.3 十种常用暗线

| 暗线类型 | 前期表现 | 后期回收 |
| --- | --- | --- |
| 真相暗线 | 小案、谎言、细节不一致 | 证明真正问题更大、更近或更脏 |
| 身份暗线 | 行为异常、知识过多、回避某人 | 暴露双重身份、替身、冒名、真实关系 |
| 系统暗线 | 个体事件反复被压下 | 揭示制度、组织、家族或行业在保护问题 |
| 空间暗线 | 楼梯、地下室、门、房间、路线重复出现 | 空间成为阶层、秘密、逃亡或权力的证据 |
| 道具暗线 | 一个物件多次换手或被忽视 | 物件在高潮改变身份、证据或选择 |
| 身体暗线 | 气味、伤口、病症、习惯动作 | 身体细节暴露阶层、罪证、旧伤或恐惧 |
| 语言暗线 | 反复出现的称呼、口头禅、禁语 | 语言在结尾改变关系或揭露真实权力 |
| 关系旧账暗线 | 人物避谈过去，反应过度 | 旧债解释当前选择，并逼人物付代价 |
| 主题意象暗线 | 天气、声音、广播、照片、广告反复出现 | 意象在高潮从背景变成审判 |
| 错误解释暗线 | 前面给观众一个合理但错误的答案 | 结尾推翻它，同时保留前文逻辑 |

### 3.4 暗线六步埋设法

| 步骤 | 写法 | 检查问题 |
| --- | --- | --- |
| 1. 种症状 | 先放一个可见异常，不解释 | 观众能不能看见或听见它 |
| 2. 正常化 | 让人物用日常理由掩盖它 | 为什么观众暂时不会追问到底 |
| 3. 重复变体 | 第二次、第三次以不同场景出现 | 是否越来越具体，而不是重复同一信息 |
| 4. 错误解释 | 给观众一个看似合理的答案 | 这个解释是否能撑到中点后 |
| 5. 压力暴露 | 让人物无法继续遮掩 | 是谁逼他暴露，代价是什么 |
| 6. 反向解释 | 结尾让前面细节获得新含义 | 回头看是否觉得公平，而不是被骗 |

### 3.5 暗线在三幕中的位置

| 位置 | 暗线任务 | 写法 |
| --- | --- | --- |
| 开场 1-10 分钟 | 放第一个症状 | 用空间、动作、道具或一句绕开的台词，不要解释 |
| 催化剂前后 | 让症状进入主线 | 主角因为它做出一个小误判 |
| 第二幕前半 | 重复并扩大 | 观众以为是性格、巧合或环境问题 |
| 中点 | 给一个错误答案或局部真相 | 观众以为懂了，其实只懂一层 |
| 坏蛋逼近 | 暗线开始伤人 | 旧秘密影响当前关系、任务或生死 |
| 一无所有 | 暗线真相砸中人物信念 | 不只是知道真相，而是旧方法崩塌 |
| 第三幕 | 用新行为回收暗线 | 主角不再按错误解释行动 |

### 3.6 暗线经典机制提炼

| 作品 | 暗线机制 | 可迁移做法 |
| --- | --- | --- |
| 《唐人街》 | 水、土地和家庭秘密从调查线变成城市腐败与私人罪恶的同构 | 让公共事件和私人创伤共享同一套隐藏逻辑 |
| 《致命魔术》 | 舞台魔术、日记和身份异常不断提示“双重生活”的代价 | 身份暗线要通过职业技能、亲密关系和身体代价同时出现 |
| 《非常嫌疑犯》 | 叙述者给出的信息不断被相信，结尾改写信息来源 | 叙事暗线要让观众信的是讲述方式，不只是事实内容 |
| 《寄生虫》 | 气味、楼梯、地下空间反复出现，最后成为阶层无法跨越的证据 | 主题暗线最好落到身体和空间，不只靠台词讲阶层 |
| 《聚焦》 | 个案不断被“处理”，后面证明是系统性遮盖 | 系统暗线要让每个阻拦者看起来都有正常理由 |
| 《为所应为》 | 高温、广播、照片墙、披萨店空间反复推高尊严冲突 | 社区暗线要让环境意象参与升级，而不是做背景装饰 |
| 《七宗罪》 | 每个案件既是线索，也是凶手世界观的章节 | 犯罪暗线可让反派行动本身构成主题论证 |
| 《老无所依》 | 钱箱、追踪、命运感和警长旁观线构成无法阻止的世界变化 | 暗线也可以不是谜底，而是世界秩序正在失效 |

### 3.7 暗线常见失败与修复

| 失败 | 症状 | 修复 |
| --- | --- | --- |
| 只藏不露 | 观众到结尾才第一次知道关键信息 | 在第一幕放可见症状，第二幕放变体 |
| 伏笔太直 | 观众一眼看出答案 | 给它一个日常功能，让它先服务当前场景 |
| 回收太巧 | 道具或真相突然救场 | 至少让它出现两次，并由人物选择触发回收 |
| 暗线和主题无关 | 反转很惊，但不改变人物 | 让暗线真相击穿主角错误信念 |
| 解释过度 | 结尾用长台词讲明所有事 | 用动作、关系变化或空间揭露替代解释 |
| 前后不公平 | 反转推翻了前面规则 | 回看前文时每个异常都应能成立 |

## 4. 群像、支线、暗线的联动

三者不能分开设计。最稳的做法是：让群像人物分别携带支线，让支线推进暗线，让暗线回头改变人物关系。

### 4.1 联动公式

```text
人物功能 -> 支线欲望 -> 暗线信息 -> 中点误解 -> 低谷真相 -> 高潮新选择
```

例子：

| 人物功能 | 支线 | 暗线 | 最终作用 |
| --- | --- | --- | --- |
| 镜像人物 | 他用主角旧方法获得短暂成功 | 他其实已经付出主角害怕的代价 | 证明主角不能继续旧方法 |
| 道德目光 | 他不断质疑主角选择 | 他知道主角不愿面对的旧伤 | 逼主角在低谷承认真相 |
| 系统代言人 | 他执行规则阻止主角 | 他背后不是个人恶意，而是组织利益 | 把反派从个人扩展成系统 |
| 情感对象 | 他有自己的目标，不只是爱主角 | 他掌握主角被爱的条件或误解 | 让第三幕情感兑现有行动基础 |
| 隐藏真相持有者 | 他反复回避关键话题 | 他知道真正因果 | 中点后改写主线目标 |

### 4.2 从一个单线故事扩成多线故事

按顺序做，不要一开始乱加人物。

1. 写清主线：谁在什么压力下追什么目标，最后必须学会什么。
2. 写出主题反面：如果主角坚持旧方法到底，会变成谁。
3. 增加镜像人物：让他走主题反面。
4. 增加 B 故事人物：让他看见主角真正需求。
5. 增加系统压力人物：让主线阻力有规则和资源。
6. 增加隐藏真相持有者：让暗线有活人承载。
7. 给每个新增人物一条三次出现的支线。
8. 把所有支线在中点后并到同一个更大问题。

### 4.3 中点并线的四种方式

| 并线方式 | 写法 | 效果 |
| --- | --- | --- |
| 真相并线 | 多条线发现自己查的是同一件事 | 故事变大，世界更复杂 |
| 代价并线 | 主线成功直接伤害支线人物 | 胜利变脏，人物被迫选择 |
| 空间并线 | 所有人被困到同一空间或事件 | 群像冲突集中爆发 |
| 身份并线 | 支线人物真实身份改变主线关系 | 情感和悬疑同时升级 |

### 4.4 高潮回收顺序

高潮不是把每条线都解释一遍，而是按代价顺序回收。

```text
先回收外部目标：事情能不能成。
再回收关系代价：谁被保护、背叛、放手或承认。
再回收暗线真相：观众重新理解前文。
最后回收主题选择：主角做出开场时做不到的行动。
```

### 4.5 群像多线故事的分场检查

每一场戏至少回答一个问题：

| 问题 | 合格表现 |
| --- | --- |
| 这场属于哪条线 | 主线、B 故事、反派线、调查线、家庭线、系统线、暗线 |
| 这场由谁主动 | 不是每场都由主角推动，支线人物也要主动 |
| 这场改变什么 | 目标、关系、信息、权力、代价、空间或时间压力 |
| 这场是否带出暗线 | 有无可见症状、异常反应、道具或回避 |
| 下一场为什么不能不发生 | 本场结尾造成新的必然行动 |

## 5. 诊断清单

### 5.1 群像诊断

```text
1. 列出所有重要人物。
2. 给每个人写一个叙事功能：欲望、代价、诱惑、镜像、阻力、道德目光、系统、暗线持有者。
3. 标出 A/B/C 层。
4. 检查每个 B 层人物是否至少三次有效出现。
5. 检查每个人结尾是否有获得、失去、暴露、选择或离开。
6. 删除或合并只提供气氛、不改变因果的人物。
```

### 5.2 支线诊断

```text
1. 给每条支线命名。
2. 写清支线人物自己的欲望。
3. 标出第一次出现、第二次升级、中点后并线、结尾回收。
4. 检查支线是否改变主线的目标、代价、信息或关系。
5. 检查支线是否服务同一个主问题。
6. 删除只重复情绪、不改变行动的场景。
```

### 5.3 暗线诊断

```text
1. 写出最终要揭示的真相或意义。
2. 回到第一幕，找出至少一个可见症状。
3. 在第二幕前半安排一次变体。
4. 在中点给出错误解释或局部真相。
5. 在一无所有前让暗线开始伤人。
6. 在第三幕用动作回收，不只用台词说明。
```

### 5.4 失败剧本快速定位

| 症状 | 优先检查 |
| --- | --- |
| 人物多但记不住 | 群像功能表和 A/B/C 层 |
| 中段散 | 支线是否中点并线 |
| 结尾反转突兀 | 暗线是否第一幕可见 |
| 主线单薄 | B 故事和系统压力是否存在 |
| 配角没用 | 每个配角是否制造不可替代压力 |
| 主题说教 | 群像是否用不同命运证明主题 |
| 悬疑弱 | 暗线是否有错误解释和重复变体 |
| 情感线飘 | 情感支线是否改变主角行动 |

【群像结构】
中心太阳型 / 镜像双核型 / 三主角分岔型 / 任务小组型 / 场域切片型 / 拼图叙事型。

【人物功能表】
人物 | 表面目标 | 内在恐惧 | 叙事功能 | 携带支线 | 掌握暗线 | 结尾回收

### 6.2 支线设计模板

【支线清单】
支线名 | 支线人物欲望 | 第一次出现 | 第二次升级 | 中点并线 | 结尾回收

```

2. 支线是否改变主线因果。

【修复方案】

【下一步】

```

## 7. 写作禁忌

1. 不要为了“群像感”增加没有叙事功能的人。
2. 不要让所有配角都围着主角提供情绪价值。
3. 不要把支线写成与主线无因果关系的小品。
4. 不要用结尾解释替代前文暗线。
5. 不要让暗线只存在于设定文档里，必须出现在场景动作中。
6. 不要让每条线都完整成长，只有 A 层人物需要完整弧光。
7. 不要让多线故事只靠剪辑交叉，必须有目标、信息、代价或主题的交叉。
8. 不要把反转当成暗线的唯一目的，暗线最终要改变人物选择或主题重量。

## 8. 一句话规则

```text
群像要分工，不要平摊。
支线要并线，不要散养。
暗线要可见，不要硬藏。
中点要改写关系，低谷要暴露代价，高潮要用行动回收。
```
