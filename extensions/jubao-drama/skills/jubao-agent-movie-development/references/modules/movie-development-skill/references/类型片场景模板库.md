这个文件帮助 Agent 判断一个故事应该兑现什么类型快感、需要哪些人物关系、如何升级中段、怎样让结尾完成情感兑现。使用时不要先问"这是什么题材"，而要先问"观众为什么愿意继续看"。

## 0. Agent 使用原则

```text
先判断主类型，再判断副类型。
主类型负责观众购票理由，副类型负责人物情感厚度。
每个类型至少要有 5-8 个关键场景，否则类型承诺不足。
每个场景必须同时改变事件、关系或信念中的至少一项。
```

**关键场景库通用要求**（适用于下文所有类型的"关键场景库"中的每一场戏）：这场戏不能只完成事件推进，还要让主角的旧方法暴露一次缺陷；场景结尾必须让下一场更难写，而不是更容易。

## 1. 公路片

### 1.1 类型核心快感

人物在移动中被迫改变关系和自我认知。核心快感不是到达目的地，而是每一站都让旧身份失效。

### 1.2 必备人物关系

- 临时同行者
- 目标地的象征人物
- 阻止上路的人
- 路上诱惑者
- 追赶者或时间压力

### 1.3 主角常见错误信念

- 我只要到达目的地就能解决问题
- 关系可以先搁置
- 逃离原地等于获得自由

### 1.4 常见冲突

- 路线阻断
- 车/钱/证件丢失
- 临时同伴价值观冲突
- 必须绕路帮助别人
- 目的地意义被推翻

### 1.5 中段升级方式

- 每站增加一个现实问题
- 每站揭开一点旧账
- 把轻松风景变成选择压力
- 让路线从地理移动变成心理逼近

### 1.6 关键场景库

上路决定 / 第一站小失败 / 陌生人镜像 / 夜晚袒露 / 交通资金危机 / 目的地幻灭 / 回头救人 / 新关系上路

### 1.7 结尾情感兑现

结尾应让主角明白真正目的不是抵达，而是愿意带着改变后的关系继续生活。

## 2. 亲情治愈

### 2.1 类型核心快感

观众想看旧伤被看见，而不是听人物快速说和解。核心快感是亲人终于承认彼此承受过什么。

### 2.2 必备人物关系

- 控制者与被控制者
- 沉默照顾者
- 逃离家庭的人
- 替代性家人
- 孩子/老人作为情感镜子

### 2.3 主角常见错误信念

- 我这样做都是为你好
- 只要不说就不会伤害
- 家人应该自动理解我

### 2.4 常见冲突

- 饭桌旧账
- 照顾责任分配
- 钱和医疗决定
- 成长选择被否定
- 秘密被外人说破

### 2.5 中段升级方式

- 把爱变成控制
- 把照顾变成债务
- 让小事触发多年委屈
- 让外部危机迫使家人合作

### 2.6 关键场景库

饭桌压迫 / 医院、学校、警局签字 / 翻旧物 / 错过重要时刻 / 替对方撒谎 / 第一次说真话 / 不完美和解

### 2.7 结尾情感兑现

结尾不应只说"我爱你"，而应出现新的行为：尊重选择、归还权力、主动承担、停止控制。

## 3. 犯罪片

### 3.1 类型核心快感

核心快感是利益、忠诚和暴力规则互相吞噬。人物每一步都应让自己更难退出。

### 3.2 必备人物关系

- 老大与继承人
- 警察/调查者
- 背叛者
- 律师/中间人
- 家属作为道德代价

### 3.3 主角常见错误信念

- 我可以只拿好处不付代价
- 忠诚可以买到安全
- 暴力能解决复杂问题

### 3.4 常见冲突

- 分赃不均
- 证据泄露
- 卧底怀疑
- 家人被卷入
- 上级逼迫清理门户

### 3.5 中段升级方式

- 每次成功都留下把柄
- 让同伙互相猜疑
- 把私人关系变成组织风险
- 让小罪升级成不可回头的大罪

### 3.6 关键场景库

第一次越界 / 分赃谈判 / 清理证人 / 警察逼问 / 家庭晚餐双重身份 / 背叛验证 / 最后清算

### 3.7 结尾情感兑现

结尾应兑现犯罪选择的代价：权力、自由、亲情、身份或灵魂至少失去一种。

## 4. 悬疑片

### 4.1 类型核心快感

核心快感是观众不断重组事实。好悬疑不是藏答案，而是让每个答案制造更深的问题。

### 4.2 必备人物关系

- 调查者
- 受害者/幸存者
- 嫌疑人群
- 掌握关键记忆的人
- 误导性盟友

### 4.3 主角常见错误信念

- 只要找到凶手就结束
- 事实是客观的
- 我能保持旁观

### 4.4 常见冲突

- 证词矛盾
- 物证反向解释
- 目击者撒谎
- 调查者被牵连
- 真相比答案更伤人

### 4.5 中段升级方式

- 每 15 分钟推翻一次假设
- 让新线索同时解释旧疑点和制造新疑点
- 把调查者私人旧伤接入案件

### 4.6 关键场景库

发现尸体或异常 / 第一次嫌疑 / 证据反转 / 假凶手落网 / 调查者被误导 / 核心秘密暴露 / 代价选择

### 4.7 结尾情感兑现

结尾不只揭凶手，还要揭示为什么所有人都愿意相信错误版本。

## 5. 爱情片

### 5.1 类型核心快感

核心快感是两个人在相互吸引和自我防御之间反复试探。爱情线必须改变人物，而不是奖励人物。

### 5.2 必备人物关系

- 价值观相反的恋人
- 前任/竞争者
- 朋友旁观者
- 家庭阻力
- 事业目标对立者

### 5.3 主角常见错误信念

- 被爱就等于被拯救
- 保持体面比暴露脆弱重要
- 爱情不能影响我的人生计划

### 5.4 常见冲突

- 误解
- 时间错位
- 阶层差异
- 前任阴影
- 事业与关系冲突

### 5.5 中段升级方式

- 用小承诺测试大信任
- 让甜蜜场景埋下价值观冲突
- 让告白失败后关系进入新阶段

### 5.6 关键场景库

初遇误判 / 被迫合作 / 第一次看见脆弱 / 亲密后撤退 / 公开选择失败 / 追赶或错过 / 成熟告别或重逢

### 5.7 结尾情感兑现

结尾要兑现两人的改变：在一起、分开或错过都可以，但必须让人物不再用开场方式爱人。

## 6. 职场喜剧

### 6.1 类型核心快感

核心快感是专业目标被人性、制度和荒唐流程不断扭曲。笑点来自角色认真地做错事。

### 6.2 必备人物关系

- 技术/专业理想主义者
- 自恋老板
- 实用主义合伙人
- 规则执行者
- 竞争公司/部门

### 6.3 主角常见错误信念

- 能力强就能赢
- 只要逻辑正确别人就会听
- 公司目标和个人尊严可以分开

### 6.4 常见冲突

- 预算、股权、审批、KPI、办公室政治、客户误解、法律条款

### 6.5 中段升级方式

- 让小流程变成大灾难
- 让解决方案制造更大问题
- 让每个人都从自身利益出发说对但做错

### 6.6 关键场景库

会议失控 / 演示翻车 / 投资人误解 / 内部甩锅 / 客户现场灾难 / 荒唐合规 / 误打误撞成功

### 6.7 结尾情感兑现

结尾通常是暂时胜利：问题解决一半，同时埋下下一集/下一段更大的制度麻烦。

## 7. 成长片

### 7.1 类型核心快感

核心快感是主角第一次意识到世界不会按自己的幼稚理解运转。成长来自代价，不来自说教。

### 7.2 必备人物关系

- 同龄伙伴
- 严厉导师
- 诱惑型朋友
- 不理解的父母
- 让主角羞耻的对手

### 7.3 主角常见错误信念

- 我只要证明自己就会被接纳
- 大人都是敌人
- 失败说明我不值得

### 7.4 常见冲突

- 考试/比赛/表演
- 友情背叛
- 家庭期待
- 自尊受损
- 第一次承担后果

### 7.5 中段升级方式

- 让小目标变成身份问题
- 让朋友关系比胜负更痛
- 让主角第一次伤害别人

### 7.6 关键场景库

目标宣言 / 第一次失败 / 秘密训练 / 友情裂痕 / 公开羞辱 / 放弃旧证明方式 / 成熟选择

### 7.7 结尾情感兑现

结尾应让主角获得新行动能力，不一定赢比赛，但要停止用外部认可定义自己。

## 8. 动作冒险

### 8.1 类型核心快感

核心快感是目标清晰、障碍升级、空间不断变化、主角在危机中做选择。动作必须推动关系和信息。

### 8.2 必备人物关系

- 行动主角
- 技术/知识助手
- 反派执行者
- 被保护者
- 竞争性盟友

### 8.3 主角常见错误信念

- 我可以单靠能力解决
- 保护别人就是替别人做决定
- 任务比关系重要

### 8.4 常见冲突

- 追逐
- 夺取关键物
- 环境限制
- 队友被困
- 时间倒计时
- 反派反制

### 8.5 中段升级方式

- 每场动作改变地图/资源/关系
- 让动作失败带来新线索
- 让保护对象反过来救主角

### 8.6 关键场景库

任务发布 / 第一次追逐 / 潜入失败 / 中点夺物 / 队友牺牲或失踪 / 回头救人 / 高潮倒计时

### 8.7 结尾情感兑现

结尾应让主角用新的价值观完成动作，而不是只靠更大爆炸。

## 9. 科幻设定片

### 9.1 类型核心快感

核心快感是新规则带来新问题。设定必须服务人物困境，而不是展示百科。

### 9.2 必备人物关系

- 进入规则的新手
- 掌握规则的导师
- 规则受害者
- 制度维护者
- 超越规则的反派

### 9.3 主角常见错误信念

- 理解规则就能控制世界
- 技术中立
- 逃进虚拟/未来就能逃避现实

### 9.4 常见冲突

- 规则误用
- 伦理代价
- 身份不确定
- 时间/记忆/现实崩塌
- 系统惩罚

### 9.5 中段升级方式

- 用小实验教规则
- 让规则产生情感代价
- 中点揭示规则背后的谎言

### 9.6 关键场景库

新手犯错 / 规则训练 / 第一次违规成功 / 规则反噬 / 身份真相 / 关闭或改写系统 / 带着代价回归

### 9.7 结尾情感兑现

结尾要回答：这个设定让人物对人性、自由、记忆、爱或死亡有什么新理解。

## 10. 黑色幽默片

### 10.1 类型核心快感

核心快感是人物越认真维护体面，局面越残酷地揭穿体面。笑点和痛感必须同时存在。

### 10.2 必备人物关系

- 体面伪装者
- 规则破坏者
- 旁观补刀者
- 权力滑稽者
- 受害但清醒的人

### 10.3 主角常见错误信念

- 只要维持表面秩序就没事
- 别人看不见我的虚伪
- 世界会奖励聪明人

### 10.4 常见冲突

- 小谎言滚大
- 荒唐制度惩罚诚实者
- 暴力突然闯入日常
- 笑话后面是阶层/道德痛点

### 10.5 中段升级方式

- 让小尴尬升级成公开灾难
- 让正确语言遮盖错误行为
- 让观众笑完意识到残酷

### 10.6 关键场景库

体面开场 / 小谎言 / 集体圆谎 / 突发暴力或灾难 / 公开羞辱 / 荒唐清算 / 冷尾声

### 10.7 结尾情感兑现

结尾不必温暖，但要有讽刺回响：人物或社会暴露出更真实、更荒凉的面目。

## 12. 类型片 Agent 检查表

```text
1. 这个故事的主类型是什么？副类型是什么？
2. 主类型的观众期待是否有 5 个以上可见场景？
3. 主角错误信念是否和类型核心快感相冲突？
4. 中点是否改变类型游戏规则？
5. 反派/压力是否代表一种价值观或系统？
6. 结尾是否兑现类型快感，同时完成人物变化？
7. 哪些场景可以删，因为它们没有目标、冲突、转折或关系变化？
```

## 13. 通用：类型场景的写烂模式、修复步骤、桥段迁移与生成模板

以下内容适用于全部 10 个类型，使用任一类型时直接套用，类型章节内不再重复。

### 13.1 容易写烂的问题

- 只复制类型表面元素，没有兑现核心快感。
- 中段只换地点，不换压力。
- 人物关系没有旧账，冲突像临时吵架。
- 结尾靠解释和道歉收束，没有新行为。
- 反派或阻力只是工具人，不能代表一种价值观。

### 13.2 改写修复方法

```text
1. 先写一句类型承诺：观众来看这类故事，是为了看到什么？
2. 列出 8 个必备场景，删掉只解释背景的场景。
3. 给主角一个与类型相反的错误信念。
4. 让中点证明：主角以为自己赢了，其实进入更危险的规则。
5. 让结尾选择同时解决外部目标和内部错误信念。
```

### 13.3 可迁移到国产电影/短剧/网剧的桥段

- 把宏大目标改成更具体的本土压力：房子、户口、彩礼、债务、病房签字、职场 KPI、家族面子、同学会比较。
- 把外部敌人改成更日常的权力系统：父母、老板、老师、平台规则、亲戚舆论、地方熟人社会。
- 把类型大场面压缩成高密度场景：饭桌、车内、医院走廊、办公室、派出所、婚礼现场、直播间、评审会。

### 13.4 Agent 生成模板

把【类型名】替换为本文件中的任一类型（如公路片、亲情治愈、犯罪片等）：

```text
请按【类型名】类型开发这个故事。
输出：
1. 类型核心快感。
2. 主角错误信念。
3. 必备人物关系。
4. 8 个关键场景。
5. 中点升级方式。
6. 最低谷。
7. 结尾情感兑现。
8. 容易写烂的问题和修复建议。
要求：每场戏都写出目标、冲突、转折、关系变化。
```
