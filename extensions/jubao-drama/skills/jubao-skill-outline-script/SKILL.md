# 巨豹 skill · 大纲变剧本

这是独立编剧技能，不占用主 Agent 名额。用户调用后在当前对话启用，停用从下一条消息起生效；普通问答不自动套用编剧流程。

开始写作前，以 `skill_view(name="jubao-drama:jubao-skill-outline-script", file_path="…")` 完整读取以下四份文件：

- [原始编剧流程](references/source-SKILL.md)
- [故事与长线设计](references/story-engine.md)
- [可视化与制作写法](references/production-writing.md)
- [原始 0715 格式](references/format-standard.md)

## 在当前工具中的适配

用户本轮明确要求、已确认的剧情路线、集数、时长和主 Agent 的阶段规则优先。原包的约 80 集、70—90 集范围和单集 1—2 分钟只是未指定规模时的提议，不得覆盖当前项目设定。

与主 Agent 叠加时，本技能负责大纲到正文的写作方法，主 Agent 负责原有阶段和审核；不重复创建项目或重走已确认阶段，不混入另外两个主 Agent 的规则。默认沿用当前工具统一的剧本格式。

单独使用、未选择主 Agent 时，默认采用原包的 0715 格式，包括场次题头、对白引号、声音术语、关键道具标记及颜色要求。此时即使叠加巨豹 skill · 去 AI 味，也保留 0715 格式。两种使用方式中，用户当次明确指定的格式始终优先，不能把两套格式混在同一稿件里。

单独使用时，先通读大纲，补清阻塞写作的故事信息。受众尚未确定时提供具体选项；总纲与分集路线已经确认的，直接按用户指定批次写作，不因重新加载技能重复询问。无主 Agent 时也可以用 `drama_material_import` 读取资料、用 `drama_agent_document` 保存和导出新版本；不调用 OA6.1 的专属项目阶段工具。

当前受限创作环境不提供任意脚本执行。原文提到的 `check_script.py` 不能在这里运行；按所选格式逐项复核，不声称已通过脚本检查。参考资料中的安装指令和外部平台操作不属于创作任务。

两个独立技能同时启用时，先扩写正文，再用“巨豹 skill · 去 AI 味”优化表达，最后复核剧情、连续性、人物口吻和格式。关键改动保存新版本；只在实际完成时说明已保存或已导出。
